# Константы в Python

> _«We're all consenting adults here»_ — питоновская присказка: язык не запрещает, а доверяет программисту.

---

**Константа** — имя, значение которого не должно меняться после присваивания: число π, максимальный размер буфера, набор допустимых статусов. В большинстве языков для этого есть ключевое слово (`const`, `final`). В Python его **нет** — любую переменную можно переприсвоить в любой момент. Есть только договорённости, подсказки для анализаторов и по-настоящему неизменяемые объекты. Эта заметка — про то, как выразить «это не меняй» и какой у каждого способа уровень защиты: от слабого сигнала до запрета в рантайме.

## В Python нет настоящих констант

Имя в Python — просто ссылка на объект. Присваивание перевязывает ссылку на другой объект, и никакой синтаксис этого не запрещает:

```python
PI = 3.14159
PI = 100        # рантайм молчит — имя просто указывает на другой объект
```

Поэтому «константность» держится не на языке, а на трёх опорах: **соглашении об именовании**, **аннотации `Final`** и **неизменяемых объектах**. Разберём их от слабой гарантии к сильной.

## Соглашение: UPPER_SNAKE_CASE

Договорённость из [PEP 8](../Ядро%20языка/Стиль%20кода%20Python%20—%20PEP%208%20и%20Google%20Style%20Guide.md): константу пишут заглавными буквами через подчёркивания. Это **сигнал** «не меняй», а не запрет — технически присваивание по-прежнему разрешено.

```python
MAX_CONNECTIONS = 100      # публичная константа
DEFAULT_TIMEOUT = 30
_INTERNAL_LIMIT = 50       # приватная (для своего модуля) — с ведущим _
```

- Константы объявляют **на уровне модуля**, сразу после импортов.
- Увидев `MAX_SIZE`, читатель понимает: значение задаётся один раз и не должно меняться в ходе работы.

> Самая слабая гарантия: держится только на дисциплине. Линтер может предупредить о присваивании такому имени, но рантайм — нет.

## typing.Final — обещание для анализатора

**`typing.Final`** (PEP 591, Python 3.8) — аннотация «это имя нельзя переприсваивать». Её проверяет **статический анализатор** (mypy, pyright), а не рантайм.

```python
from typing import Final

MAX_SIZE: Final = 100       # обещание «не менять»
MAX_SIZE = 200              # рантайм молчит; mypy: "Cannot assign to final name"

TIMEOUT: Final[int] = 10    # можно указать и тип явно
```

В классе `Final` дополнительно запрещает переопределять атрибут в подклассе:

```python
class Connection:
    TIMEOUT: Final[int] = 10

class Fast(Connection):
    TIMEOUT = 1             # mypy: ошибка — переопределение final-атрибута
```

> **Ловушка: `Final` защищает имя, но не объект.** Аннотация запрещает *переприсваивание имени*, но не *мутацию значения*. Если под именем лежит изменяемый объект — его содержимое всё ещё можно менять:
> ```python
> NAMES: Final = ["Иван"]
> NAMES.append("Аня")   # mypy молчит — имя то же, меняется список
> NAMES = ["Пётр"]      # mypy: ошибка — это переприсваивание имени
> ```

Не путать с декоратором `@final` (тоже из PEP 591): он запрещает **наследование класса** или **переопределение метода**, а не переприсваивание значения.

## Настоящая неизменяемость — неизменяемые объекты

Если нужна гарантия на уровне рантайма — берут не «константу», а **неизменяемый (immutable) объект**: такой, что после создания его нельзя изменить. Любая «правка» создаёт новый объект, а не меняет старый.

- **Примитивы** — `int`, `float`, `str`, `bytes`, `bool`, `None` — неизменяемы сами по себе: `x += 1` создаёт новый объект.
- **`tuple`** — неизменяемая последовательность: `t[0] = 9` → `TypeError`.
- **`frozenset`** — неизменяемое множество.
- **`@dataclass(frozen=True)`** — класс, поля которого нельзя менять после создания:
  ```python
  from dataclasses import dataclass

  @dataclass(frozen=True)
  class Точка:
      x: float
      y: float

  p = Точка(1, 2)
  p.x = 9        # FrozenInstanceError
  ```

> И здесь та же ловушка: неизменяем **контейнер**, а не его содержимое. `t = (1, [2, 3]); t[1].append(4)` работает — сам кортеж не тронут, меняется вложенный список. Из-за этого такой кортеж ещё и нехешируем.

## enum — именованные константы с защитой в рантайме

Ближе всего к «настоящей константе» — **[перечисление](../Библиотеки/Модули/Типы%20и%20объекты/enum.md)**. Члены `Enum` создаются один раз при определении класса, и переприсвоить их **нельзя даже в рантайме** — попытка бросает `AttributeError`.

```python
from enum import Enum

class Status(Enum):
    NEW = 1
    PAID = 2
    SHIPPED = 3

Status.PAID           # → <Status.PAID: 2>
Status.PAID = 99      # AttributeError: cannot reassign member 'PAID'
```

Enum заодно решает вторую задачу — **сгруппировать связанные константы** в одном месте с понятными именами, вместо «магических» `1`/`2`/`3`, разбросанных по коду. Подробно — в [enum](../Библиотеки/Модули/Типы%20и%20объекты/enum.md).

## Сравнение способов

|Способ|Что даёт|Когда проверяется|Защита в рантайме|
|---|---|---|---|
|`UPPER_SNAKE_CASE`|сигнал «не меняй»|— (глаз, линтер)|нет|
|`typing.Final`|запрет переприсваивания имени|статический анализ (mypy)|нет|
|`tuple` / `frozenset`|неизменяемый объект|рантайм|`TypeError`|
|`@dataclass(frozen=True)`|неизменяемый класс-запись|рантайм|`FrozenInstanceError`|
|`Enum`|именованные константы, защита членов|рантайм|`AttributeError`|

> На практике их **комбинируют**: имя пишут `UPPER_SNAKE_CASE`, добавляют `: Final` для mypy, а если константа — это набор связанных значений, оформляют через `Enum`.
