# Работа с файлами Python

> Чтение и запись файлов — как программа общается с диском: прочитать конфиг, разобрать данные, сохранить результат. Точка входа одна — встроенная функция `open`, а `with` гарантирует, что файл закроется даже при ошибке.

---

Данные редко живут только в памяти: их читают из файлов (тексты, CSV, логи) и пишут обратно. В Python это делается без библиотек — встроенной `open`. Главное правило — открывать файл через `with`, чтобы он гарантированно закрылся и не «утёк».

## open — открыть файл

`open(path, mode, encoding)` возвращает файловый объект. Для текста **всегда указывай `encoding`** — иначе Python возьмёт кодировку системы, и на Windows кириллица из UTF-8 файла превратится в кашу.

```python
f = open("data.txt", "r", encoding="utf-8")   # открыть на чтение
# ... работа ...
f.close()                                       # закрыть вручную — легко забыть
```

## Режимы открытия

```python
open("f.txt", "r")    # чтение (по умолчанию), файла нет → FileNotFoundError
open("f.txt", "w")    # запись: создаёт новый / ОБНУЛЯЕТ существующий
open("f.txt", "a")    # дозапись в конец, файл не стирается
open("f.txt", "x")    # создать; если файл есть → FileExistsError
open("f.txt", "rb")   # бинарный режим (b) — байты, не текст
open("f.txt", "r+")   # чтение + запись
```

| Режим | Что делает | Если файла нет | Если файл есть |
|---|---|---|---|
| `r` | чтение | ошибка | читает |
| `w` | запись | создаёт | **стирает** |
| `a` | дозапись | создаёт | пишет в конец |
| `x` | создать | создаёт | ошибка |
| `b` | + к режиму: байты | | |

> **Ловушка `w`:** режим `w` молча обнуляет существующий файл при открытии — до всякой записи. Нужно дописать, а не затереть — бери `a`.

## with — контекстный менеджер

`with` закрывает файл автоматически на выходе из блока — даже если внутри произошло исключение. Это питонический способ, `close()` вручную почти не пишут:

```python
with open("data.txt", encoding="utf-8") as f:
    содержимое = f.read()
# здесь файл уже закрыт — гарантированно
```

Механику `with` (`__enter__`/`__exit__`) см. в [Магические методы Python](../Ядро%20языка/Магические%20методы%20Python.md#контекстные-менеджеры) и [contextlib](../Библиотеки/Модули/Отладка%20и%20утилиты/contextlib.md).

## Чтение

```python
with open("data.txt", encoding="utf-8") as f:
    f.read()              # весь файл одной строкой
    f.readline()          # одна строка (со знаком \n)
    f.readlines()         # список строк (с \n на концах)
```

**Разбить на строки без `\n`** — `splitlines()`:

```python
lines = f.read().splitlines()   # ['первая', 'вторая'] — без \n на концах
```

**Итерация по файлу** — самый экономный способ: файл читается **построчно**, не загружаясь целиком в память (важно для больших файлов):

```python
with open("огромный.log", encoding="utf-8") as f:
    for строка in f:                 # по одной строке за раз
        print(строка.strip())        # strip() убирает \n
```

## Запись

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("одна строка\n")          # write НЕ добавляет \n сам
    f.writelines(["a\n", "b\n"])       # список строк, тоже без авто-\n
```

> `write` не ставит перенос строки автоматически — `\n` добавляй сам.

## Бинарные файлы

Для картинок, архивов и прочих не-текстовых данных — режим `b`, работа с `bytes`, без `encoding`:

```python
with open("photo.jpg", "wb") as f:
    f.write(данные_в_байтах)          # напр. requests.get(url).content
```

Пример скачивания файла из сети — в [requests](../Библиотеки/Сторонние/Работа%20с%20WEB/requests.md#скачать-файл-бинарные-данные).

## Сквозной пример 1 — парсер кулинарной книги

Задача: файл `recipes.txt` формата «название → число ингредиентов → строки `имя|кол-во|мера`», собрать в словарь. Приём — **ручной курсор `i`** по списку строк: читаем заголовок, число, затем ровно столько строк ингредиентов.

```python
def recipes_in_book(book):
    """Возвращает словарь рецептов из файла."""
    cook_book = {}
    with open(book, encoding='utf-8') as f:
        lines = f.read().splitlines()      # строки без \n

    i = 0
    while i < len(lines):
        if not lines[i]:                    # пропустить пустую строку-разделитель
            i += 1
            continue

        dish = lines[i]; i += 1             # название блюда
        count_ingredients = int(lines[i]); i += 1   # сколько ингредиентов

        recipe = []
        for _ in range(count_ingredients):
            name, qty, msr = lines[i].split('|')     # 'Яйцо|3|шт' → 3 части
            recipe.append({'ingredient_name': name,
                           'quantity': int(qty),
                           'measure': msr})
            i += 1
        cook_book[dish] = recipe
        i += 1                              # шаг через пустую строку
    return cook_book
```

Как читать: `splitlines()` даёт список строк, курсор `i` движется вручную, потому что число строк каждого рецепта заранее неизвестно — его диктует поле «количество ингредиентов». На основе `cook_book` дальше строят список покупок (умножая количества на число персон).

## Сквозной пример 2 — объединить файлы, отсортировав по числу строк

Задача: слить несколько текстовых файлов в `result.txt`, по возрастанию длины, помечая номер строки и файла. Здесь читаем все файлы, сортируем по `len` (число строк), пишем результат через [`enumerate`](../Ядро%20языка/Циклы%20Python.md#enumerate--индекс--элемент).

```python
def merge_files(files):
    texts = []
    for filename in files:
        with open(filename, encoding='utf-8') as f:
            texts.append(f.read().splitlines())

    texts.sort(key=len)                     # короткие файлы — первыми

    with open('result.txt', 'w', encoding='utf-8') as f:
        for file_num, txt in enumerate(texts, start=1):
            for line_num, line in enumerate(txt, start=1):
                f.write(f'Строка номер {line_num} файла номер {file_num}\n')
                f.write(f'{line}\n')

merge_files(['1.txt', '2.txt', '3.txt'])
```

Читаем каждый файл в список строк, `sort(key=len)` упорядочивает файлы по количеству строк, вложенные `enumerate` дают номера файла и строки для заголовков.

## Ловушки

```python
# НЕПРАВИЛЬНО — без encoding кириллица ломается на Windows:
open("рецепты.txt")                 # берёт cp1251 → UnicodeDecodeError / каша

# ПРАВИЛЬНО:
open("рецепты.txt", encoding="utf-8")

# НЕПРАВИЛЬНО — 'w' затирает файл, который хотели дополнить:
open("лог.txt", "w")                # весь старый лог потерян

# ПРАВИЛЬНО — дозапись:
open("лог.txt", "a", encoding="utf-8")
```

> Для больших файлов не делай `f.read()` целиком — итерируй по строкам (`for строка in f`), иначе весь файл окажется в памяти.
