# Функции Python

> Функция — объект первого класса. В Python функцию можно передать в другую функцию, вернуть из функции, положить в список, присвоить переменной — всё то же самое что с числом или строкой. Подробнее о концепции — в Функциональное программирование.

---

## Что такое функция

**Функция** — именованный блок кода, который выполняется при вызове. Принимает входные данные (аргументы), выполняет логику, возвращает результат.

В CPython функция — это объект типа `function`, экземпляр класса `PyFunctionObject`. Хранит в себе:

- **`__code__`** — объект `PyCodeObject` с байткодом тела функции
- **`__globals__`** — ссылку на глобальное пространство имён модуля
- **`__defaults__`** — кортеж значений по умолчанию для позиционных аргументов
- **`__kwdefaults__`** — словарь значений по умолчанию для keyword-only аргументов
- **`__closure__`** — кортеж ячеек (`cell`) с захваченными переменными замыкания
- **`__name__`** — имя функции
- **`__annotations__`** — аннотации типов

```python
def сложить(a, b):
    return a + b

type(сложить)               # → <class 'function'>
сложить.__code__            # → <code object сложить ...>
сложить.__code__.co_varnames  # → ('a', 'b') — имена локальных переменных
сложить.__code__.co_consts    # → (None,)
сложить.__globals__ is globals()  # → True
```

## def и return

### def

`def` — инструкция создания функции. При выполнении `def` Python:

1. Компилирует тело функции в байткод (`PyCodeObject`) — это происходит при загрузке модуля
2. Создаёт объект `function`, связывая байткод с текущим окружением
3. Привязывает имя функции к этому объекту в текущем пространстве имён

```python
def приветствие(имя):
    return f"Привет, {имя}!"

# def — это инструкция, а не декларация.
# Функция создаётся в момент выполнения строки def:
if True:
    def версия_а():
        return "А"
else:
    def версия_б():
        return "Б"

# версия_а существует, версия_б — нет
```

### return

`return` — завершает выполнение функции и возвращает значение вызывающему коду.

```python
def максимум(a, b):
    if a > b:
        return a    # выход из функции здесь
    return b        # или здесь

# return без значения:
def проверить(x):
    if x < 0:
        return      # → None
    print(x)

# функция без return тоже возвращает None:
def ничего():
    pass

ничего() is None    # → True
```

**Несколько return — множественные значения через tuple:**

```python
def минмакс(lst):
    return min(lst), max(lst)   # возвращает кортеж

mn, mx = минмакс([3, 1, 4, 1, 5])  # распаковка
print(mn, mx)   # → 1 5
```

### Как работает вызов функции в CPython

При вызове `f(args)` Python:

1. Создаёт новый **фрейм выполнения** (`PyFrameObject`) — изолированное пространство с локальными переменными
2. Кладёт фрейм на **стек вызовов**
3. Начинает выполнять байткод тела функции
4. При `return` — снимает фрейм со стека, возвращает значение

```python
import inspect

def внешняя():
    def внутренняя():
        # посмотреть стек вызовов:
        for frame_info in inspect.stack():
            print(frame_info.function)
    внутренняя()

внешняя()
# → внутренняя
# → внешняя
# → <module>
```

## Аргументы функции

### Позиционные аргументы

Передаются по порядку. Самый базовый вид.

```python
def степень(основание, показатель):
    return основание ** показатель

степень(2, 10)      # → 1024
степень(10, 2)      # → 100  — порядок важен
```

### Ключевые аргументы (keyword arguments)

Передаются по имени — порядок не важен.

```python
степень(показатель=10, основание=2)     # → 1024
степень(2, показатель=10)               # → 1024 — можно смешивать

# но позиционные всегда раньше ключевых:
степень(показатель=10, 2)               # SyntaxError!
```

### Значения по умолчанию

```python
def подключить(хост, порт=5432, ssl=False):
    return f"{хост}:{порт} ssl={ssl}"

подключить("localhost")              # → "localhost:5432 ssl=False"
подключить("localhost", 3306)        # → "localhost:3306 ssl=False"
подключить("localhost", ssl=True)    # → "localhost:5432 ssl=True"
```

**Как хранятся в CPython:** значения по умолчанию вычисляются **один раз** при выполнении `def` и сохраняются в `__defaults__`:

```python
def f(x=10):
    pass

f.__defaults__      # → (10,)

# ГЛАВНАЯ ЛОВУШКА — изменяемый дефолт:
def добавить(элемент, список=[]):
    список.append(элемент)
    return список

добавить(1)     # → [1]
добавить(2)     # → [1, 2]  — тот же список!
добавить(3)     # → [1, 2, 3]

# [] создался один раз при def и живёт в __defaults__
добавить.__defaults__   # → ([1, 2, 3],)

# ПРАВИЛЬНО — None как сторож:
def добавить(элемент, список=None):
    if список is None:
        список = []
    список.append(элемент)
    return список
```

### `*args` — произвольное число позиционных аргументов

`*args` собирает все лишние позиционные аргументы в **кортеж**.

```python
def сумма(*числа):
    print(type(числа))  # → <class 'tuple'>
    return sum(числа)

сумма(1, 2, 3)          # → 6
сумма(1, 2, 3, 4, 5)    # → 15
сумма()                 # → 0

# смешивание:
def первый_и_остальные(первый, *остальные):
    print(первый)       # → 1
    print(остальные)    # → (2, 3, 4)

первый_и_остальные(1, 2, 3, 4)
```

**Распаковка при вызове** через `*`:

```python
числа = [1, 2, 3, 4, 5]
сумма(*числа)           # → 15 — распаковывает список в позиционные аргументы

# можно распаковывать несколько:
сумма(*[1, 2], *[3, 4])  # → 10
```

### `**kwargs` — произвольное число ключевых аргументов

`**kwargs` собирает все лишние ключевые аргументы в **словарь**.

```python
def настройки(**опции):
    print(type(опции))   # → <class 'dict'>
    for ключ, значение in опции.items():
        print(f"{ключ} = {значение}")

настройки(цвет="синий", размер=12, жирный=True)
# цвет = синий
# размер = 12
# жирный = True

# смешивание:
def создать_пользователя(имя, возраст, **дополнительно):
    print(имя, возраст)
    print(дополнительно)  # → {'email': '...', 'город': '...'}

создать_пользователя("Иван", 25, email="i@i.ru", город="Москва")
```

**Распаковка при вызове** через `**`:

```python
параметры = {"цвет": "синий", "размер": 12}
настройки(**параметры)  # → распаковывает словарь в ключевые аргументы

# объединение словарей при вызове:
настройки(**параметры, **{"жирный": True})
```

### Порядок всех видов аргументов

```
def f(позиц, позиц2, /, обычный, *args, keyword_only, **kwargs):
```

Правило: позиционные → обычные → `*args` → keyword-only → `**kwargs`.

```python
def полная(a, b, /, c, d=10, *args, е, ж=20, **kwargs):
    pass
		#  │  │     │  │    │    │    │          │
		#  positional-only  │  *args  │        **kwargs
		#  (до /)           │         keyword-only
		#                обычные      (после *)
```

### Positional-only аргументы (`/`)

Аргументы **до** `/` можно передать только позиционно — никак не по имени. Добавлены в Python 3.8.

```python
def округлить(число, /, знаков=0):
    return round(число, знаков)

округлить(3.14159, 2)           # → 3.14  — OK
округлить(3.14159, знаков=2)    # → 3.14  — OK
округлить(число=3.14159, знаков=2)  # TypeError! число — positional-only

# встроенные функции давно используют это:
# len(obj) — obj нельзя передать как len(obj=...)
```

### Keyword-only аргументы (`*`)

Аргументы **после** `*` или `*args` можно передать **только по имени**.

```python
def копировать(источник, назначение, *, перезаписать=False, тихо=False):
    pass

копировать("a.txt", "b.txt")                    # OK
копировать("a.txt", "b.txt", перезаписать=True)  # OK
копировать("a.txt", "b.txt", True)              # TypeError! перезаписать — keyword-only

# одиночная * без имени — только разделитель:
def f(a, b, *, c, d):
    pass
```

### Полная картина передачи аргументов

```python
def f(a, b=2, /, c=3, *args, d, e=5, **kwargs):
    print(f"a={a}, b={b}, c={c}, args={args}, d={d}, e={e}, kwargs={kwargs}")

f(1, d=4)
# a=1, b=2, c=3, args=(), d=4, e=5, kwargs={}

f(1, 10, 20, 30, 40, d=4, x=99)
# a=1, b=10, c=20, args=(30, 40), d=4, e=5, kwargs={'x': 99}
```

### По ссылке или по значению — ложная дихотомия

Классический вопрос секции. Правильный ответ: **ни то, ни другое — Python передаёт ссылку на объект** (*call by sharing*, «передача по разделяемому объекту»). Параметр становится **новым именем для того же объекта**, и всё поведение выводится из одной этой фразы.

```python
def переприсвоить(lst):
    lst = [9, 9]              # новый объект, ЛОКАЛЬНОЕ имя смотрит на него
    return lst

def мутировать(lst):
    lst.append(9)             # тот же объект, изменён на месте

данные = [1, 2]
переприсвоить(данные)         # снаружи: [1, 2]      — не изменилось
мутировать(данные)            # снаружи: [1, 2, 9]   — изменилось
```

**Разница не в типе аргумента, а в операции:**

| Операция внутри функции | Видно снаружи | Почему |
|---|---|---|
| **Переприсваивание** `lst = ...` | нет | связывает **локальное имя** с другим объектом; объект вызывающего не тронут |
| **Мутация** `lst.append(...)`, `d[k] = v`, `obj.attr = v` | **да** | объект один и тот же, изменяется он сам |

Отсюда и ощущение, будто «числа и строки передаются по значению, а списки по ссылке»: механизм **один**, просто неизменяемые объекты мутировать нечем — над `int` и `str` доступно только переприсваивание, поэтому изменения снаружи не видны никогда.

```python
def испортить(число, текст, список):
    число += 1                # int неизменяем → это переприсваивание
    текст += "!"              # str неизменяем → тоже переприсваивание
    список += [1]             # list: += это МУТАЦИЯ (extend), не переприсваивание!
    
n, s, l = 0, "a", []
испортить(n, s, l)
n, s, l                       # → (0, 'a', [1])   изменился только список
```

> 🔴 **`+=` — самое коварное место.** На неизменяемом объекте это `x = x + y` (переприсваивание, снаружи не видно), на списке — вызов `__iadd__`, то есть `extend` на месте (снаружи видно). Один и тот же оператор ведёт себя по-разному в зависимости от типа, и на этом ловят.

**Как безопасно принимать изменяемый аргумент** — не мутировать чужое без явного контракта:

```python
# НЕПРАВИЛЬНО — тихо портим список вызывающего:
def добавить(lst, x):
    lst.append(x)
    return lst

# ПРАВИЛЬНО — работаем с копией, возвращаем новое:
def добавить(lst, x):
    return [*lst, x]                  # или lst.copy() → append → return
```

Мутировать переданный объект можно — но тогда это должно быть **обещанием функции**, отражённым в её имени (`sort_in_place`, `update_config`), а не побочным эффектом. Подробнее — [ниже](../Ядро%20языка/Функции%20Python.md#чистые-функции-и-побочные-эффекты); для вложенных структур копия должна быть глубокой ([deepcopy](../Библиотеки/Модули/Типы%20и%20объекты/copy.md)).

## Область видимости и LEGB

При обращении к имени Python ищет его по правилу **LEGB** — четыре уровня вложенности:

- **L** — Local: текущая функция
- **E** — Enclosing: объемлющие функции (снаружи к внутри)
- **G** — Global: модуль
- **B** — Built-in: встроенные имена (`len`, `print`, `range`...)

```python
x = "global"

def внешняя():
    x = "enclosing"

    def внутренняя():
        x = "local"
        print(x)    # → "local"  (L)

    внутренняя()
    print(x)        # → "enclosing"  (E)

внешняя()
print(x)            # → "global"  (G)
```

### global

`global` объявляет что имя относится к глобальному уровню — не создаёт локальную переменную, а изменяет глобальную.

```python
счётчик = 0

def увеличить():
    global счётчик
    счётчик += 1    # без global — UnboundLocalError

увеличить()
увеличить()
print(счётчик)      # → 2
```

### nonlocal

`nonlocal` — то же что `global`, но для переменной из объемлющей (enclosing) функции.

```python
def создать_счётчик():
    значение = 0

    def увеличить():
        nonlocal значение
        значение += 1
        return значение

    return увеличить

счётчик = создать_счётчик()
счётчик()   # → 1
счётчик()   # → 2
счётчик()   # → 3
```

### Как CPython хранит локальные переменные

Локальные переменные хранятся не в словаре, а в **массиве** (`fastlocals`) внутри фрейма. Это быстрее словаря — доступ по индексу `O(1)`. Индексы известны заранее из байткода:

```python
def f():
    x = 1
    y = 2
    return x + y

import dis
dis.dis(f)
# LOAD_CONST  1  (1)
# STORE_FAST  0  (x)   ← индекс 0
# LOAD_CONST  2  (2)
# STORE_FAST  1  (y)   ← индекс 1
# LOAD_FAST   0  (x)
# LOAD_FAST   1  (y)
# BINARY_OP   +
# RETURN_VALUE
```

## Вложенные функции и замыкания

**Замыкание** — функция, которая захватывает переменные из объемлющей области видимости и помнит их после того как та завершила работу.

```python
def создать_умножитель(n):
    def умножить(x):
        return x * n      # n — из объемлющей функции
    return умножить

удвоить = создать_умножитель(2)
утроить = создать_умножитель(3)

удвоить(5)   # → 10
утроить(5)   # → 15

# объемлющая создать_умножитель давно завершилась,
# но n живёт в замыкании:
удвоить.__closure__             # → (<cell at 0x...>,)
удвоить.__closure__[0].cell_contents  # → 2
утроить.__closure__[0].cell_contents  # → 3
```

### Как CPython реализует замыкания

Захваченные переменные хранятся в объектах **`cell`**. Объемлющая и вложенная функция разделяют одну и ту же ячейку — это не копия значения, а общая ссылка:

```python
def внешняя():
    x = 10

    def внутренняя():
        return x

    x = 20      # меняем x после создания внутренней
    return внутренняя

f = внешняя()
f()     # → 20, не 10 — захватывается переменная, не значение
```

### Классическая ловушка с замыканием в цикле

```python
# НЕПРАВИЛЬНО — все функции захватят одну переменную i:
функции = []
for i in range(5):
    функции.append(lambda: i)

[f() for f in функции]  # → [4, 4, 4, 4, 4]
# к моменту вызова i уже равно 4

# ПРАВИЛЬНО — захватить значение через дефолтный аргумент:
функции = []
for i in range(5):
    функции.append(lambda i=i: i)

[f() for f in функции]  # → [0, 1, 2, 3, 4]
```

## lambda-функции

**lambda** — анонимная функция в одно выражение. Не может содержать инструкции (`if/else` как выражение — можно, `return` — нельзя, пишется неявно).

```python
# синтаксис:
lambda аргументы: выражение

# обычная функция:
def квадрат(x):
    return x ** 2

# lambda-эквивалент:
квадрат = lambda x: x ** 2
квадрат(5)      # → 25
```

### Аргументы lambda

Lambda поддерживает все виды аргументов что и `def`:

```python
lambda x, y: x + y                     # два позиционных
lambda x, y=10: x + y                  # с дефолтом
lambda *args: sum(args)                 # *args
lambda **kwargs: kwargs                 # **kwargs
lambda x, *, y: x + y                  # keyword-only
lambda x, y=0, *args, **kwargs: ...     # всё вместе
```

### Где используется

Lambda имеет смысл как **одноразовая** функция, передаваемая аргументом:

```python
# сортировка по ключу:
люди = [("Иван", 25), ("Аня", 30), ("Коля", 20)]
sorted(люди, key=lambda x: x[1])        # по возрасту
sorted(люди, key=lambda x: x[0])        # по имени

# filter, map:
чётные = list(filter(lambda x: x % 2 == 0, range(10)))
квадраты = list(map(lambda x: x ** 2, range(10)))

# в словаре операций:
операции = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
    "*": lambda a, b: a * b,
}
операции["+"](3, 4)   # → 7
```

### lambda vs def — когда что

```python
# lambda — коротко и выразительно для простого ключа:
sorted(данные, key=lambda x: x.возраст)

# def — когда логика сложнее одного выражения:
def ключ_сортировки(x):
    если_нет = x.возраст if x.возраст else 0
    return (если_нет, x.имя)

sorted(данные, key=ключ_сортировки)
```

**Плюсы lambda:**

- Компактность там где функция нужна один раз
- Не загрязняет пространство имён

**Минусы lambda:**

- Нет имени → трудно отлаживать (`<lambda>` в трейсбеке)
- Только одно выражение → сложную логику не запишешь
- PEP 8 не рекомендует присваивать lambda переменной — лучше `def`

```python
# PEP 8 не одобряет:
f = lambda x: x * 2

# лучше так:
def f(x):
    return x * 2
```

## Чистые функции и побочные эффекты

**Чистая функция** — функция, которая для одних и тех же аргументов всегда возвращает один результат и не имеет **побочных эффектов**. Её результат зависит только от входа.

**Побочный эффект (side effect)** — любое влияние функции на мир за пределами возвращаемого значения: печать, запись в файл/БД, изменение глобальной переменной или переданного изменяемого объекта, обращение к сети/времени/случайности.

```python
# чистая: результат только из аргументов, снаружи ничего не трогает
def add(a, b):
    return a + b

# грязная: печатает (I/O) и меняет внешний список — побочные эффекты
log = []
def add_loud(a, b):
    log.append((a, b))      # мутация внешнего состояния
    print(a + b)            # I/O
    return a + b
```

Почему чистые функции ценят: их легко **тестировать** (вход → выход, без окружения), **кэшировать** (`@lru_cache` корректен только для чистых), переставлять и распараллеливать. Побочные эффекты неизбежны (программа без них бесполезна) — их **локализуют** на краях, а ядро логики держат чистым.

> Мутация переданного изменяемого аргумента — тоже побочный эффект: `def f(lst): lst.append(1)` меняет список вызывающего. Та же природа, что у ловушки изменяемого дефолта `def f(x=[])`.

## Функции высшего порядка

**Функция высшего порядка** — функция, которая принимает другую функцию как аргумент или возвращает функцию как результат. Подробнее о концепции — в Функциональное программирование.

```python
# принимает функцию:
def применить(fn, данные):
    return [fn(x) for x in данные]

применить(str.upper, ["hello", "world"])  # → ["HELLO", "WORLD"]
применить(lambda x: x**2, [1, 2, 3])     # → [1, 4, 9]

# возвращает функцию:
def создать_валидатор(минимум, максимум):
    def валидировать(значение):
        return минимум <= значение <= максимум
    return валидировать

валидный_возраст = создать_валидатор(0, 150)
валидный_возраст(25)    # → True
валидный_возраст(200)   # → False
```

### Встроенные функции высшего порядка

```python
# map — применить функцию к каждому элементу:
list(map(str, [1, 2, 3]))           # → ["1", "2", "3"]
list(map(lambda x: x*2, range(5)))  # → [0, 2, 4, 6, 8]

# filter — оставить элементы где функция вернула True:
list(filter(None, [0, 1, "", "a", False, True]))  # → [1, "a", True]
list(filter(lambda x: x > 0, [-1, 0, 1, 2]))      # → [1, 2]

# sorted с key:
sorted(["банан", "яблоко", "кот"], key=len)    # → ["кот", "банан", "яблоко"]
sorted(["Б", "а", "В"], key=str.lower)         # → ["а", "Б", "В"]

# max/min с key:
max(["банан", "яблоко", "кот"], key=len)        # → "яблоко"

# reduce (functools):
from functools import reduce
reduce(lambda acc, x: acc + x, [1, 2, 3, 4])   # → 10
reduce(lambda acc, x: acc * x, [1, 2, 3, 4])   # → 24
```

#### Всегда ли print выводит сразу — нет, буферизация

`print` пишет в `sys.stdout`, а поток **буферизуется**: текст копится в буфере и выталкивается при переводе строки (в терминале), при заполнении буфера или при завершении программы. Поэтому `print(..., end="")` в цикле может «замолчать» и вывалиться разом в конце.

```python
import time
for i in range(5):
    print(i, end=" ")               # в терминале обычно ждёт \n или конца программы
    time.sleep(1)

for i in range(5):
    print(i, end=" ", flush=True)   # flush — вытолкнуть сразу, видно по одному
    time.sleep(1)
```

- **`stdout`** буферизуется (терминал — построчно; перенаправление в файл/пайп — блоками);
- **`stderr`** не буферизуется — пишет немедленно;
- поэтому, смешивая вывод в `stdout` и `stderr` без `\n`, легко получить порядок вперемешку. Форсировать вывод — `flush=True` (или `sys.stdout.flush()`).

|`exec(code)`|Выполнить код из строки|`str` с Python-кодом|
|`globals()` / `locals()`|Словари пространств имён|— (возвращают `dict`)|
|`slice(start, stop, step)`|Объект среза|`int` аргументы; применяется к `list`, `tuple`, `str`|

## Аннотации типов

Аннотации не проверяются Python во время выполнения — только для статических анализаторов (mypy, pyright) и IDE. Подробнее — в [Специальные типы данных Python](../Данные/Специальные%20типы%20данных%20Python.md#аннотации-типов).

```python
def сложить(a: int, b: int) -> int:
    return a + b

def приветствие(имя: str, раз: int = 1) -> str:
    return f"Привет, {имя}! " * раз

def обработать(данные: list[int]) -> dict[str, int]:
    return {"сумма": sum(данные), "макс": max(данные)}
```

Аннотации хранятся в `__annotations__`:

```python
сложить.__annotations__     # → {'a': <class 'int'>, 'b': <class 'int'>, 'return': <class 'int'>}
```

## Документация функции

**Docstring** — строка сразу после `def`. Хранится в `__doc__`.

```python
def факториал(n: int) -> int:
    """
    Вычислить факториал числа n.

    Args:
        n: Неотрицательное целое число.

    Returns:
        n! — произведение всех чисел от 1 до n.

    Raises:
        ValueError: Если n отрицательное.

    Examples:
        >>> факториал(5)
        120
    """
    if n < 0:
        raise ValueError(f"n должен быть >= 0, получено {n}")
    if n == 0:
        return 1
    return n * факториал(n - 1)

help(факториал)             # выводит docstring
факториал.__doc__           # строка документации
```

## Рекурсия

**Рекурсия** — функция вызывает сама себя. Каждый вызов создаёт новый фрейм на стеке вызовов. Подробнее о стеке — в Стек вызовов.

```python
def факториал(n):
    if n == 0:          # базовый случай — остановка
        return 1
    return n * факториал(n - 1)  # рекурсивный случай

факториал(5)    # → 120
# стек: факториал(5) → факториал(4) → факториал(3) → факториал(2) → факториал(1) → факториал(0)
```

### Предел рекурсии

CPython ограничивает глубину стека — по умолчанию **1000 вызовов**:

```python
import sys
sys.getrecursionlimit()     # → 1000
sys.setrecursionlimit(5000) # изменить лимит

# при превышении:
def бесконечная(n):
    return бесконечная(n + 1)

бесконечная(0)   # → RecursionError: maximum recursion depth exceeded
```

### Хвостовая рекурсия

Python **не оптимизирует** хвостовую рекурсию (в отличие от Haskell, Erlang). Каждый вызов — новый фрейм. Для глубокой рекурсии лучше переписать итеративно:

```python
# рекурсивно — O(n) по памяти стека:
def факториал_рек(n):
    if n == 0:
        return 1
    return n * факториал_рек(n - 1)

# итеративно — O(1) по памяти:
def факториал_ит(n):
    результат = 1
    for i in range(2, n + 1):
        результат *= i
    return результат
```

### Мемоизация рекурсии

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def фибоначчи(n):
    if n < 2:
        return n
    return фибоначчи(n - 1) + фибоначчи(n - 2)

фибоначчи(100)  # → мгновенно, без мемоизации — годы
фибоначчи.cache_info()  # → CacheInfo(hits=98, misses=101, ...)
```

## Атрибуты функции

Функция — объект, у неё есть атрибуты. Можно добавлять свои:

```python
def счётчик():
    счётчик.вызовов += 1
    return счётчик.вызовов

счётчик.вызовов = 0     # атрибут на функции

счётчик()   # → 1
счётчик()   # → 2
счётчик()   # → 3
```

### Полный список встроенных атрибутов

|Атрибут|Что хранит|
|---|---|
|`__name__`|Имя функции|
|`__qualname__`|Полное квалифицированное имя (`Класс.метод`)|
|`__doc__`|Строка документации|
|`__module__`|Имя модуля где определена|
|`__annotations__`|Аннотации типов|
|`__defaults__`|Дефолты позиционных аргументов (кортеж или `None`)|
|`__kwdefaults__`|Дефолты keyword-only аргументов (словарь или `None`)|
|`__code__`|Объект байткода|
|`__globals__`|Глобальное пространство имён модуля|
|`__closure__`|Кортеж cell-объектов замыкания или `None`|
|`__dict__`|Пространство имён для пользовательских атрибутов|
|`__wrapped__`|Оригинальная функция если обёрнута декоратором|

## Практика

> Декораторы (`@wraps`, параметрические, на генераторы) вынесены в отдельную заметку — [Декораторы Python](../Ядро%20языка/Декораторы%20Python.md).

```python
# универсальный логгер-декоратор:
from functools import wraps
import time

def логировать(fn):
    @wraps(fn)
    def обёртка(*args, **kwargs):
        начало = time.perf_counter()
        результат = fn(*args, **kwargs)
        конец = time.perf_counter()
        print(f"{fn.__name__} выполнена за {конец-начало:.4f}с")
        return результат
    return обёртка

@логировать
def медленная(n):
    return sum(range(n))

медленная(1_000_000)

# каррирование через замыкание:
def curry(fn):
    from inspect import signature
    n = len(signature(fn).parameters)
    def накопить(args):
        if len(args) >= n:
            return fn(*args)
        return lambda *новые: накопить(args + новые)
    return lambda *args: накопить(args)

@curry
def сложить_три(a, b, c):
    return a + b + c

сложить_три(1)(2)(3)    # → 6
сложить_три(1, 2)(3)    # → 6

# функция с валидацией через аннотации:
def валидировать_типы(fn):
    @wraps(fn)
    def обёртка(*args, **kwargs):
        подсказки = fn.__annotations__
        все_аргументы = dict(zip(fn.__code__.co_varnames, args))
        все_аргументы.update(kwargs)
        for имя, значение in все_аргументы.items():
            if имя in подсказки and not isinstance(значение, подсказки[имя]):
                raise TypeError(
                    f"Аргумент {имя!r}: ожидался {подсказки[имя].__name__}, "
                    f"получен {type(значение).__name__}"
                )
        return fn(*args, **kwargs)
    return обёртка

@валидировать_типы
def сложить(a: int, b: int) -> int:
    return a + b

сложить(1, 2)       # → 3
сложить(1, "2")     # TypeError: Аргумент 'b': ожидался int, получен str
```
