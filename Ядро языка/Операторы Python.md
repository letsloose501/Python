# Операторы Python

> Каждый оператор в Python — это синтаксический сахар над вызовом [магического метода](../Ядро%20языка/Магические%20методы%20Python.md). `a + b` — это просто удобная запись `a.__add__(b)`.

---

## Что такое оператор

**Оператор** — специальный символ или слово, которое выполняет операцию над одним или несколькими значениями (**операндами**) и возвращает результат.

```python
2 + 3        # оператор + , операнды: 2 и 3, результат: 5
not True     # оператор not, операнд: True, результат: False
(x := 10)    # оператор :=, операнд: 10, результат: 10 (присваивает x); скобки обязательны
```

### Виды по количеству операндов

- **Унарный** — один операнд: `-x`, `not x`, `~x`
- **Бинарный** — два операнда: `a + b`, `a == b`
- **Тернарный** — три: `a if условие else b`

### Приоритет операторов

Операторы выполняются не слева направо, а по **приоритету**. Чем выше — тем раньше.

| Приоритет | Операторы                                                                 |
| --------- | ------------------------------------------------------------------------- |
| Высший    | `()` скобки                                                               |
|           | `**`                                                                      |
|           | `+x`, `-x`, `~x` (унарные)                                                |
|           | `*`, `/`, `//`, `%`, `@`                                                  |
|           | `+`, `-`                                                                  |
|           | `<<`, `>>`                                                                |
|           | `&`                                                                       |
|           | `^`                                                                       |
|           | `\|`                                                                      |
|           | **==** , ` != `, `<`, `>`, ` <= `, ` >= `, `is`, `is not`, `in`, `not in` |
|           | `not`                                                                     |
|           | `and`                                                                     |
|           | `or`                                                                      |
|           | `A if C else B` (тернарный)                                               |
| Низший    | `:=` (walrus)                                                             |

```python
2 + 3 * 4     # → 14, не 20: * выполняется раньше +
(2 + 3) * 4   # → 20: скобки поднимают приоритет
```

## Арифметические операторы

### `+` — сложение

**Что делает:** складывает два операнда. Для строк и списков — **конкатенация**.

**Конкатенация** — операция соединения нескольких строк символов в одну.

**Магический метод:** `__add__(self, other)`. Если левый операнд не знает как сложиться с правым — Python пробует `other.__radd__(self)`.

```python
# числа
2 + 3           # → 5
2.5 + 1.5       # → 4.0

# строки — конкатенация
"hello" + " world"  # → "hello world"

# списки — объединение
[1, 2] + [3, 4]     # → [1, 2, 3, 4]

# свой класс
class Деньги:
    def __init__(self, сумма):
        self.сумма = сумма
    def __add__(self, other):
        return Деньги(self.сумма + other.сумма)
    def __str__(self):
        return f"{self.сумма}₽"

print(Деньги(100) + Деньги(50))  # → 150₽
```

**Плюсы:** работает для любого типа, реализовавшего `__add__`. Интуитивен.

**Минусы:** конкатенация строк в цикле через `+` — медленно (`O(n²)`). Для этого есть `"".join(список)`.

**Аналог в других языках:** `+` в Java, C++, JavaScript — то же самое.

---

### `-` — вычитание

**Что делает:** вычитает правый операнд из левого.

**Магический метод:** `__sub__(self, other)` / `__rsub__` / унарный `__neg__`.

```python
10 - 3      # → 7
5.0 - 2.5   # → 2.5

# унарный минус
x = 5
-x          # → -5  (вызывает x.__neg__())

# на множествах — разность
{1, 2, 3} - {2, 3}  # → {1}

# практика: температура
class Температура:
    def __init__(self, celsius):
        self.celsius = celsius
    def __sub__(self, other):
        return Температура(self.celsius - other.celsius)
    def __neg__(self):
        return Температура(-self.celsius)
```

**Минусы:** для чисел с плавающей точкой возможны погрешности: `0.3 - 0.1 → 0.19999999999999998`.

---

### `*` — умножение

**Что делает:** умножает операнды. Для строк и списков — повторение.

**Магический метод:** `__mul__(self, other)` / `__rmul__`.

```python
3 * 4           # → 12
2.5 * 2         # → 5.0

# повторение строки
"ab" * 3        # → "ababab"
3 * "ab"        # → "ababab"  (вызывает "ab".__rmul__(3))

# повторение списка
[0] * 5         # → [0, 0, 0, 0, 0]

# матричное умножение (отдельный оператор @, PEP 465)
import numpy as np
A @ B           # матричное произведение через __matmul__
```

**Минус:** `[[0] * 3] * 3` создаёт список из трёх ссылок на **один и тот же** вложенный список — частая ловушка.

```python
# ловушка
m = [[0] * 3] * 3
m[0][0] = 1
print(m)  # → [[1,0,0],[1,0,0],[1,0,0]] — изменились все строки!

# правильно
m = [[0] * 3 for _ in range(3)]
```

---

### `/` — деление (float)

**Что делает:** делит и **всегда** возвращает `float`.

**Магический метод:** `__truediv__(self, other)`.

```python
10 / 2      # → 5.0  (не 5!)
7 / 2       # → 3.5
1 / 3       # → 0.3333333333333333
```

**Важно:** в Python 2 `10 / 2` давало `5` (целое). В Python 3 — всегда `float`. Это одно из главных изменений между версиями — подробнее в [Python](../Python.md#python-2-vs-python-3).

**Минус:** деление на ноль — `ZeroDivisionError`.

```python
1 / 0       # ZeroDivisionError: division by zero
```

---

### `//` — целочисленное деление (floor division)

**Что делает:** делит и округляет результат **вниз** до целого (floor, не truncate).

**Магический метод:** `__floordiv__(self, other)`.

```python
7 // 2      # → 3
-7 // 2     # → -4  (не -3! округление вниз, а не к нулю)
7.5 // 2    # → 3.0 (float остаётся float)
```

**Нюанс с отрицательными:** `//` округляет **вниз** (к минус бесконечности), а не к нулю.

```python
-7 // 2     # → -4  (floor: -3.5 → -4)
int(-7 / 2) # → -3  (truncate: просто отбрасывает дробь)
```

**Аналог:** `Math.floor(a / b)` в JavaScript, `a / b` (для int) в Java/C.

---

### `%` — остаток от деления (modulo)

**Что делает:** возвращает остаток от деления. Знак результата совпадает со знаком **делителя** (правого операнда).

**Магический метод:** `__mod__(self, other)`.

```python
10 % 3      # → 1
-10 % 3     # → 2  (не -1! знак = знак делителя)
10 % -3     # → -2

# проверка чётности
5 % 2 == 0  # → False (нечётное)
4 % 2 == 0  # → True  (чётное)

# форматирование строк (устаревший стиль)
"Hello, %s!" % "мир"  # → "Hello, мир!"
```

**Практика — цикличный счётчик:**

```python
# индекс всегда остаётся в диапазоне 0..n-1
i = (i + 1) % n
```

**Аналог:** `%` в C/Java/JavaScript — но там знак остатка совпадает со знаком **делимого** (левого), а не делителя. В Python поведение другое.

---

### `**` — возведение в степень

**Что делает:** возводит левый операнд в степень правого.

**Магический метод:** `__pow__(self, other)`.

```python
2 ** 10     # → 1024
2 ** 0.5    # → 1.4142...  (квадратный корень)
2 ** -1     # → 0.5
(-2) ** 3   # → -8

# правоассоциативный: 2 ** 3 ** 2 = 2 ** (3**2) = 2**9 = 512
2 ** 3 ** 2 # → 512

# встроенная функция — то же самое
pow(2, 10)      # → 1024
pow(2, 10, 100) # → 24  (modular exponentiation: 2**10 % 100)
```

**Плюс:** работает с большими числами без переполнения — в отличие от C.

**Минус:** `**` правоассоциативен — порядок вычисления сюрпризный для новичков.

## Операторы присваивания

### ` = ` — присваивание

**Что делает:** связывает имя переменной с объектом. Не копирует объект — создаёт **ссылку**.

**Магического метода нет** — это языковая конструкция, не вызов метода.

```python
x = 42          # x ссылается на объект 42
y = x           # y ссылается на тот же объект 42
y = 99          # y теперь ссылается на 99, x остался 42

# для изменяемых объектов важно:
a = [1, 2, 3]
b = a           # b и a — ссылки на ОДИН список
b.append(4)
print(a)        # → [1, 2, 3, 4]  — a тоже изменился!

# чтобы скопировать:
b = a.copy()    # поверхностная копия
b = a[:]        # то же самое
```

---

### `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=` — составное присваивание

**Что делает:** выполняет операцию и сразу присваивает результат той же переменной.

**Магические методы:** `__iadd__`, `__isub__`, `__imul__` и т.д. Если `__iadd__` не определён — Python использует `__add__` и переприсваивает.

```python
x = 10
x += 5      # x = x + 5 → 15
x -= 3      # x = x - 3 → 12
x *= 2      # x = x * 2 → 24
x //= 5     # x = x // 5 → 4
x **= 3     # x = x ** 3 → 64

# для изменяемых объектов += меняет объект на месте (in-place)
lst = [1, 2]
lst += [3, 4]   # вызывает list.__iadd__ — меняет lst на месте
                # → [1, 2, 3, 4]

# строки — неизменяемые, += создаёт новый объект
s = "ab"
s += "cd"   # создаёт новую строку "abcd", s теперь ссылается на неё
```

**Нюанс:** для неизменяемых типов (`int`, `str`, `tuple`) `+=` всегда создаёт новый объект. Для изменяемых (`list`, `dict`) — меняет на месте.

---

### `:=` — walrus-оператор (морж)

**Что делает:** присваивает значение переменной **внутри выражения**. Добавлен в Python 3.8.

**Магического метода нет** — языковая конструкция.

```python
# без моржа — читаем файл дважды или нужна лишняя переменная
line = file.readline()
while line:
    обработать(line)
    line = file.readline()

# с моржом — компактнее
while line := file.readline():
    обработать(line)

# в условии — скобки обязательны: := по приоритету НИЖЕ, чем >
if (n := len(data)) > 10:
    print(f"Данных много: {n}")   # n = длина; без скобок n стал бы True/False

# в list comprehension
результаты = [y for x in данные if (y := обработать(x)) is not None]
```

**Плюс:** убирает дублирование вычислений.

**Минус:** злоупотребление ухудшает читаемость. Использовать там, где действительно упрощает.

## Операторы сравнения

Все возвращают `bool`. Цепочки сравнений работают как математические: `1 < x < 10` проверяет оба условия.

### ` == ` и `!=` — равенство и неравенство

**Что делает:** сравнивает **значения** объектов.

**Магические методы:** `__eq__(self, other)` / `__ne__(self, other)`.

```python
1 == 1          # → True
"abc" == "abc"  # → True
[1, 2] == [1, 2] # → True  (сравнивает содержимое)

1 != 2          # → True

# свой класс
class Точка:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

Точка(1, 2) == Точка(1, 2)  # → True
```

**Важно:** ` == ` сравнивает значения. `is` сравнивает идентичность (один ли это объект в памяти). Подробнее — в разделе про `is`.

---

### `<`, `>`, `<=`, `>=` — порядковые сравнения

**Магические методы:** `__lt__`, `__gt__`, `__le__`, `__ge__`.

```python
3 < 5       # → True
"abc" < "abd"  # → True (лексикографически)
[1, 2] < [1, 3]  # → True (сравнивает поэлементно)

# цепочки — работают естественно
1 < 2 < 3   # → True  (эквивалентно: 1<2 and 2<3)
1 < 2 > 0   # → True
```

Строки и последовательности сравниваются **посимвольно/поэлементно до первого различия** — это [лексикографический порядок](../Ядро%20языка/Лексикографический%20порядок.md); на нём же строится сортировка по нескольким ключам через кортежи.

**Практика — сортировка своих объектов:**

```python
from functools import total_ordering

@total_ordering  # декоратор: реализуй __eq__ и __lt__, остальные выведет сам
class Студент:
    def __init__(self, имя, оценка):
        self.имя = имя
        self.оценка = оценка
    def __eq__(self, other):
        return self.оценка == other.оценка
    def __lt__(self, other):
        return self.оценка < other.оценка

студенты = [Студент("Иван", 4), Студент("Аня", 5), Студент("Коля", 3)]
sorted(студенты)  # сортировка работает через __lt__
```

## Логические операторы

### `and` — логическое И

**Что делает:** возвращает первый **ложный** операнд, или последний если все истинны. Не просто `True`/`False`.

**Ленивое вычисление** — если левый операнд ложный, правый не вычисляется вообще.

**Магического метода нет** — встроенная языковая конструкция.

```python
True and True    # → True
True and False   # → False
False and True   # → False (правая часть не вычислялась)

# возвращает операнд, не bool:
0 and "привет"   # → 0     (первый ложный)
1 and "привет"   # → "привет" (все истинны → последний)
"" and 42        # → ""    (пустая строка — ложная)

# практика — значение по умолчанию через and/or:
имя = введённое_имя and введённое_имя.strip()
```

**Аналог:** `&&` в C/Java/JavaScript.

---

### `or` — логическое ИЛИ

**Что делает:** возвращает первый **истинный** операнд, или последний если все ложные.

**Ленивое вычисление** — если левый истинный, правый не вычисляется.

```python
False or True    # → True
False or False   # → False
0 or "привет"    # → "привет" (первый истинный)
"" or 0 or None  # → None    (все ложные → последний)
"а" or "б"       # → "а"     (первый истинный)

# классическая идиома — значение по умолчанию:
имя = введённое_имя or "Гость"
порт = os.getenv("PORT") or 8080
```

**Аналог:** `||` в C/Java/JavaScript.

---

### `not` — логическое НЕ

**Что делает:** инвертирует истинность. Всегда возвращает `True` или `False`.

**Магический метод:** инвертирует результат `__bool__()` объекта.

```python
not True     # → False
not False    # → True
not 0        # → True  (0 — ложное)
not "текст"  # → False (непустая строка — истинная)
not []       # → True  (пустой список — ложный)
not None     # → True

# двойное отрицание — привести к bool:
bool(значение)   # явный способ
not not значение # эквивалентно, но менее читаемо
```

**Приоритет:** `not` ниже сравнений. `not a == b` = `not (a == b)`, а не `(not a) == b`.

## Операторы идентичности

### `is` и `is not`

**Что делает:** проверяет что два имени ссылаются на **один и тот же объект** в памяти (одинаковый `id()`). Не сравнивает значения.

**Магического метода нет** — сравнивает адреса памяти напрямую.

`is not` — **единый оператор**, а не `not (x is y)`. Пиши `x is not None`, а не `not x is None`: читается как естественный язык, работает одинаково.

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

a is b      # → True  — один и тот же объект
a is c      # → False — разные объекты, хотя значения равны
a == c      # → True  — значения равны

# правильное использование is — сравнение с None:
x = None
if x is None:       # правильно
    ...
if x == None:       # работает, но не идиоматично
    ...

# is not
if x is not None:
    ...
```

**Нюанс — интернирование целых.** Тут работают ДВА механизма, и результат `is` вне диапазона кэша зависит от того, **как скомпилирован код** — полагаться нельзя.

1. **Small-int cache:** CPython заранее создаёт объекты для чисел **−5…256**. Для них `is` всегда `True`.
2. **Дедупликация констант:** компилятор хранит одинаковые литералы внутри одного code object в единственном экземпляре.

```python
a = 256
b = 256
a is b      # → True везде (small-int cache)

# 257 вне кэша — и результат разный:
a = 257
b = 257
a is b      # → True в скрипте/функции (дедупликация констант в одном code object)
            # → False в REPL (каждая строка компилируется отдельно)

# если объект создаётся в рантайме, а не берётся из констант — всегда False:
a = 257
b = int("257")
a is b      # → False
```

**Правило:** `is` — только для `None`, `True`, `False` и других синглтонов. Для сравнения значений — всегда ` == `.

## Операторы вхождения

### `in` и `not in`

**Что делает:** проверяет принадлежность элемента *коллекции*.

**Магический метод:** `__contains__(self, item)`. Если не определён — Python итерирует объект через `__iter__` и ищет перебором.

`not in` — тоже **единый оператор**: `x not in coll` предпочтительнее, чем `not (x in coll)` — короче и читаемее, семантика та же.

```python
3 in [1, 2, 3]          # → True
"ab" in "abcde"         # → True (подстрока)
"x" not in "abcde"      # → True
"ключ" in {"ключ": 1}   # → True (проверяет ключи dict)
5 in range(10)          # → True — range реализует __contains__

# скорость зависит от типа:
x in список     # O(n) — перебор
x in множество  # O(1) — хеш-таблица
x in словарь    # O(1) — хеш-таблица
```

**Практика:**

```python
ДОПУСТИМЫЕ = {"admin", "user", "moderator"}
if роль not in ДОПУСТИМЫЕ:
    raise ValueError(f"Неизвестная роль: {роль}")
```

## Побитовые операторы

Работают с числами на уровне двоичного представления. Каждый бит обрабатывается независимо.

### `&` — побитовое И

**Магический метод:** `__and__` / `__rand__`.

```python
0b1100 & 0b1010   # → 0b1000 = 8
12 & 10           # → 8

# практика — проверка флагов:
ФЛАГ_ЧТЕНИЕ  = 0b001  # 1
ФЛАГ_ЗАПИСЬ  = 0b010  # 2
ФЛАГ_ВЫПОЛН  = 0b100  # 4

права = 0b011  # чтение + запись
if права & ФЛАГ_ЧТЕНИЕ:
    print("Можно читать")
```

---

### `|` — побитовое ИЛИ

**Магический метод:** `__or__` / `__ror__`.

```python
0b1100 | 0b1010   # → 0b1110 = 14
12 | 10           # → 14

# в Python 3.9+ — объединение словарей:
d1 = {"a": 1}
d2 = {"b": 2}
d1 | d2           # → {"a": 1, "b": 2}

# установка флага:
права |= ФЛАГ_ВЫПОЛН    # добавить право на выполнение
```

---

### `^` — побитовое исключающее ИЛИ (XOR)

**Магический метод:** `__xor__`.

```python
0b1100 ^ 0b1010   # → 0b0110 = 6
12 ^ 10           # → 6

# XOR с самим собой = 0:
x ^ x             # → 0

# XOR дважды = исходное значение:
зашифрованное = сообщение ^ ключ
расшифрованное = зашифрованное ^ ключ  # → сообщение
```

---

### `~` — побитовое НЕ (инверсия)

**Магический метод:** `__invert__`.

```python
~5      # → -6   (инвертирует все биты: ~n = -(n+1))
~0      # → -1
~(-1)   # → 0

# практика: ~i как индекс с конца списка
lst = [10, 20, 30, 40, 50]
lst[~0]   # → 50  (последний)
lst[~1]   # → 40  (предпоследний)
```

---

### `<<` и `>>` — битовые сдвиги

**Магические методы:** `__lshift__` / `__rshift__`.

```python
1 << 3      # → 8   (умножение на 2³)
8 >> 1      # → 4   (деление на 2¹)
8 >> 2      # → 2   (деление на 2²)

# быстрое умножение/деление на степень 2:
x << n      # x * (2**n)
x >> n      # x // (2**n)
```

> ⚠️ Для отрицательных чисел Python ведёт себя так, будто слева бесконечно много единиц: `-1 >> 10` → `-1`, а `-5 >> 1` → `-3` (округление **вниз**, а не к нулю). Фиксированной разрядности у целых нет, поэтому «сдвиг за край» ничего не обнуляет.

> Что этими операторами **решают** — XOR-самоуничтожение, `n & (n-1)`, подсчёт битов, битовые маски — см. [Битовые приёмы](../Алгоритмы/Приёмы/Битовые%20приёмы.md) и Маска.

## Тернарный оператор

### `A if условие else B`

**Что делает:** возвращает `A` если условие истинно, иначе `B`. Инлайн-if.

**Магического метода нет** — языковая конструкция.

```python
x = 5
результат = "чётное" if x % 2 == 0 else "нечётное"
# → "нечётное"

# аналог:
if x % 2 == 0:
    результат = "чётное"
else:
    результат = "нечётное"

# вложенные (читаемость снижается):
категория = "A" if x > 90 else "B" if x > 70 else "C"
```

**Плюс:** компактно, удобно для простых условий.

**Минус:** сложные вложенные тернарные выражения — нечитаемы. Лучше обычный `if/else`.

**Аналог:** `условие ? A : B` в C/Java/JavaScript.

## Оператор `@` — матричное умножение

**Что делает:** матричное произведение. Добавлен в Python 3.5 (PEP 465).

**Магический метод:** `__matmul__(self, other)`.

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

A @ B   # матричное умножение
# → [[19, 22], [43, 50]]

# то же самое, но verbose:
np.dot(A, B)
```

Встроенные типы `@` не поддерживают — только сторонние библиотеки (NumPy и т.п.).
