# Match Case Python

> `match` — структурное сопоставление с образцом (pattern matching). Добавлено в Python 3.10. Не просто `switch/case` из других языков — умеет деструктурировать объекты, проверять типы, захватывать переменные.

---

### Базовый синтаксис

```python
match значение:
    case образец_1:
        тело
    case образец_2:
        тело
    case _:
        тело по умолчанию   # _ — wildcard, всегда совпадает
```

```python
команда = "старт"

match команда:
    case "старт":
        print("запускаем")
    case "стоп":
        print("останавливаем")
    case _:
        print("неизвестная команда")
```

---

### Виды образцов

#### Литеральный образец

Сравнение с конкретным значением. Работает с `int`, `float`, `str`, `bool`, `None`.

```python
match код:
    case 200:
        print("OK")
    case 404:
        print("не найдено")
    case 500:
        print("ошибка сервера")
```

#### OR-образец (`|`)

Несколько значений в одном `case`.

```python
match день:
    case "сб" | "вс":
        print("выходной")
    case "пн" | "вт" | "ср" | "чт" | "пт":
        print("рабочий")
```

#### Захват переменной

Имя без кавычек — **захват**: связывает совпавшее значение с переменной.

```python
match точка:
    case (0, y):
        print(f"на оси Y, y={y}")
    case (x, 0):
        print(f"на оси X, x={x}")
    case (x, y):
        print(f"точка ({x}, {y})")
```

> Отличие от константы: `case "стоп"` — литерал, `case x` — захват в переменную `x`.

#### Образец последовательности

Сопоставление с `list` или `tuple`. Поддерживает `*rest` для остатка.

```python
match команда.split():
    case ["выход"]:
        выйти()
    case ["перейти", направление]:
        перейти(направление)
    case ["взять", *предметы]:
        взять(предметы)       # предметы — список остатка
    case _:
        print("не понял")
```

#### Образец маппинга (словарь)

Проверяет наличие указанных ключей. Лишние ключи игнорируются. `**rest` — захват остального.

```python
match запрос:
    case {"метод": "GET", "путь": путь}:
        обработать_get(путь)
    case {"метод": "POST", "путь": путь, "тело": тело}:
        обработать_post(путь, тело)
    case {"метод": метод, **остальное}:
        print(f"неизвестный метод: {метод}")
```

#### Образец класса

Проверяет тип объекта и деструктурирует атрибуты через `ИмяКласса(атрибут=значение)`.

```python
from dataclasses import dataclass

@dataclass
class Точка:
    x: float
    y: float

@dataclass
class Круг:
    центр: Точка
    радиус: float

match фигура:
    case Круг(центр=Точка(x=0, y=0), радиус=r):
        print(f"круг в начале координат, r={r}")
    case Точка(x=x, y=y):
        print(f"точка ({x}, {y})")
```

Для встроенных типов — позиционные аргументы:

```python
match значение:
    case int(n):
        print(f"целое: {n}")
    case str(s):
        print(f"строка: {s}")
    case float(f):
        print(f"дробное: {f}")
```

#### Guard — условие `if`

Дополнительная проверка после сопоставления. Если `if` не выполняется — образец не совпал.

```python
match точка:
    case (x, y) if x == y:
        print(f"на диагонали: ({x}, {y})")
    case (x, y) if x > 0 and y > 0:
        print(f"первый квадрант: ({x}, {y})")
    case (x, y):
        print(f"где-то ещё: ({x}, {y})")
```

#### AS-образец

Захватить совпавшее значение целиком под именем.

```python
match данные:
    case [первый, *_] as весь_список:
        print(f"первый: {первый}, список: {весь_список}")
```

---

### Сравнение с if/elif

```python
# if/elif:
if команда == "старт":
    запустить()
elif команда == "стоп":
    остановить()
else:
    ошибка()

# match:
match команда:
    case "старт":
        запустить()
    case "стоп":
        остановить()
    case _:
        ошибка()
```

`match` выигрывает при деструктуризации — там где `if` потребовал бы цепочки `isinstance` и индексирования:

```python
# if — громоздко:
if isinstance(фигура, Круг) and isinstance(фигура.центр, Точка) and фигура.центр.x == 0:
    ...

# match — читаемо:
match фигура:
    case Круг(центр=Точка(x=0)):
        ...
```

### Сводная таблица образцов

|Образец|Синтаксис|Что делает|
|---|---|---|
|Литерал|`case 42` / `case "ok"`|Сравнение с константой|
|Wildcard|`case _`|Всегда совпадает, не захватывает|
|Захват|`case x`|Захватывает значение в переменную|
|OR|`case "a" \| "b"`|Один из вариантов|
|Последовательность|`case [x, y]`|Деструктуризация списка/кортежа|
|Маппинг|`case {"key": val}`|Проверка ключей словаря|
|Класс|`case Foo(x=x)`|Проверка типа + атрибутов|
|AS|`case x as y`|Сопоставить и захватить целиком|
|Guard|`case x if условие`|Образец + дополнительная проверка|

### Важные нюансы

**Захват vs константа.** Голое имя в `case` — **всегда захват** переменной, а не сравнение с ней. Даже заглавное имя-«константа» перезапишется и совпадёт с чем угодно:

```python
ОЖИДАЕМОЕ = 42

# НЕПРАВИЛЬНО — bare-имя захватывает, а не сравнивает с ОЖИДАЕМОЕ:
match значение:
    case ОЖИДАЕМОЕ:      # захват: переписывает ОЖИДАЕМОЕ и совпадает с ЛЮБЫМ значением
        ...
```

Голый захват (`case x`) — **безотказный** образец: совпадает всегда. Поэтому он не может стоять раньше других `case` — это ошибка ещё на этапе компиляции:

```python
# SyntaxError: name capture 'x' makes remaining patterns unreachable
match значение:
    case x:              # безотказный образец делает следующие недостижимыми
        ...
    case 42:
        ...
```

Правильно сравнивать с константой — литералом, **точечным** именем (enum/атрибут) или через guard:

```python
from enum import Enum

class Цвет(Enum):
    КРАСНЫЙ = 1
    СИНИЙ = 2

match цвет:
    case Цвет.КРАСНЫЙ:          # точечное имя — сравнение (value pattern), работает
        ...

match значение:
    case v if v == ОЖИДАЕМОЕ:   # guard — когда нужно сравнить с переменной
        ...
    case _:
        ...
```

**`match` и `case` — мягкие ключевые слова.** Их можно использовать как имена переменных вне конструкции — обратная совместимость.

```python
match = 10       # допустимо
case = "abc"     # допустимо
```

**Совпадает первый подходящий `case`**, остальные не проверяются — как в `if/elif`. Важно помнить при перекрывающихся образцах: более общий образец выше «перехватит» совпадение раньше частного.
