# Локально-чувствительное хеширование (SimHash)

**Локально-чувствительное хеширование** (LSH, Locality-Sensitive Hashing) — семейство методов хеширования, где **похожие объекты получают похожие хеши**. Противоположность криптографическому хешу, где малейшее изменение полностью меняет результат.

**SimHash** — конкретная реализация LSH для текстов. Документы с высоким сходством дают хеши, отличающиеся в небольшом числе битов. Расстояние Хэмминга между хешами ≈ мера несхожести документов.

> **Аналогия:** обычный хеш — отпечатки пальцев. «Кот» и «кит» дают совершенно разные отпечатки. SimHash — ДНК. «Кот» и «кит» дают похожие ДНК-профили, потому что биологически близки.

---

### Обычный хеш vs SimHash

```
MD5("кот") = "a3f9c1d7..."
MD5("кот.") = "7b2e8452..."  ← полностью другой

SimHash("кот") = 101101001...
SimHash("кот.") = 101101000...  ← отличается на 1 бит

SimHash("совсем другой текст") = 010010110...  ← много отличий
```

Расстояние Хэмминга между двумя SimHash = количество позиций где биты различаются = мера несходства.

---

### Как работает SimHash

1. Разбить документ на **шинглы** (n-граммы слов или символов)
2. Для каждого шингла вычислить обычный хеш
3. Инициализировать вектор из $b$ нулей
4. Для каждого шингла: если бит $i$ хеша = 1 → `вектор[i] += 1`, иначе → `вектор[i] -= 1`
5. Финальный SimHash: `вектор[i] > 0 → 1`, иначе → `0`

```
текст: "кот и пёс"
шинглы (биграммы): ["кот и", "и пёс"]

хеш("кот и") = 1011...
хеш("и пёс") = 0110...

вектор: [+1-1, -1+1, +1+1, +1-1, ...]
         ↑      ↑    ↑      ↑
        итог:  [0,   0,    +2,   0, ...]

SimHash: [0, 0, 1, 0, ...]  (бит=1 если > 0)
```

Популярные слова встречаются в обоих хешах → их биты «усредняются» → структура документа отражается в хеше.

### Реализации

#### SimHash для текстов

```python
import hashlib
import re
from collections import Counter

class SimHash:
    def __init__(self, размер_бит=64):
        self.размер_бит = размер_бит

    def _хеш(self, строка):
        """Обычный хеш строки → целое число."""
        данные = строка.encode("utf-8")
        return int(hashlib.md5(данные).hexdigest(), 16)

    def _шинглы(self, текст, n=2):
        """n-граммы слов."""
        слова = re.findall(r'\w+', текст.lower())
        if len(слова) < n:
            return слова
        return [" ".join(слова[i:i+n]) for i in range(len(слова) - n + 1)]

    def вычислить(self, текст, веса=None):
        """
        текст  — строка или список токенов
        веса   — словарь {шингл: вес} (по умолчанию TF)
        """
        if isinstance(текст, str):
            шинглы = self._шинглы(текст)
        else:
            шинглы = текст

        if не веса:
            частоты = Counter(шинглы)
            веса = {ш: ч for ш, ч in частоты.items()}

        # инициализируем вектор
        вектор = [0] * self.размер_бит

        for шингл, вес in веса.items():
            хеш = self._хеш(шингл)
            for i in range(self.размер_бит):
                if хеш & (1 << i):
                    вектор[i] += вес
                else:
                    вектор[i] -= вес

        # финальный хеш
        результат = 0
        for i in range(self.размер_бит):
            if вектор[i] > 0:
                результат |= (1 << i)

        return результат

    def расстояние_хэмминга(self, h1, h2):
        """Количество позиций где биты различаются."""
        xor = h1 ^ h2
        return bin(xor).count("1")

    def схожесть(self, h1, h2):
        """Нормализованная схожесть [0, 1]."""
        расст = self.расстояние_хэмминга(h1, h2)
        return 1 - расст / self.размер_бит


# пример:
sh = SimHash(размер_бит=64)

h1 = sh.вычислить("Python — язык программирования общего назначения")
h2 = sh.вычислить("Python — язык программирования высокого уровня")
h3 = sh.вычислить("Кот сидит на диване и смотрит в окно")

print(f"h1 vs h2 (похожие):  расст={sh.расстояние_хэмминга(h1, h2)}, "
      f"схожесть={sh.схожесть(h1, h2):.2%}")
print(f"h1 vs h3 (разные):   расст={sh.расстояние_хэмминга(h1, h3)}, "
      f"схожесть={sh.схожесть(h1, h3):.2%}")
# → h1 vs h2 (похожие):  расст=3-8, схожесть=~90%
# → h1 vs h3 (разные):   расст=25-35, схожесть=~50%
```

#### Детектор дубликатов

```python
class ДетекторДубликатов:
    def __init__(self, порог_бит=3):
        """
        порог_бит — максимальное расстояние Хэмминга для «дублей»
        типично 3-5 для 64-битного SimHash
        """
        self._sh = SimHash(64)
        self._порог = порог_бит
        self._документы = {}   # doc_id → (хеш, текст)

    def добавить(self, doc_id, текст):
        хеш = self._sh.вычислить(текст)
        self._документы[doc_id] = (хеш, текст)

    def найти_дубли(self, doc_id):
        """Найти все документы похожие на данный."""
        if doc_id not in self._документы:
            return []
        хеш_цели, _ = self._документы[doc_id]
        дубли = []
        for id2, (хеш2, _) in self._документы.items():
            if id2 != doc_id:
                расст = self._sh.расстояние(хеш_цели, хеш2)
                if расст <= self._порог:
                    дубли.append((id2, расст))
        return sorted(дубли, key=lambda x: x[1])

    def все_пары_дублей(self):
        """Найти все пары похожих документов."""
        ids = list(self._документы.keys())
        пары = []
        for i in range(len(ids)):
            for j in range(i + 1, len(ids)):
                h1 = self._документы[ids[i]][0]
                h2 = self._документы[ids[j]][0]
                расст = self._sh.расстояние(h1, h2)
                if расст <= self._порог:
                    пары.append((ids[i], ids[j], расст))
        return пары


детектор = ДетекторДубликатов(порог_бит=5)
детектор.добавить("doc1", "Python — язык программирования общего назначения")
детектор.добавить("doc2", "Python — язык программирования высокого уровня назначения")
детектор.добавить("doc3", "Java — объектно-ориентированный язык программирования")
детектор.добавить("doc4", "Совершенно другой текст про котов и собак")

print("дубли doc1:", детектор.найти_дубли("doc1"))
# → [("doc2", N)]  — doc2 похож на doc1

print("все пары:", детектор.все_пары_дублей())
```

#### LSH-индекс для быстрого поиска похожих (band-and-row)

Для большой коллекции ($10^6+$ документов) перебор всех пар — $O(n^2)$. LSH-индекс разбивает хеш на **полосы** (bands) и группирует документы по совпадению полос.

```python
class LSHИндекс:
    def __init__(self, бит=64, полос=8):
        """
        полос=8, бит_на_полосу=64//8=8:
        два документа попадают в одну корзину если совпадает хотя бы одна полоса
        """
        self._sh = SimHash(бит)
        self._полос = полос
        self._бит_на_полосу = бит // полос
        self._корзины = {}    # (полоса, значение) → [doc_id, ...]
        self._хеши = {}       # doc_id → хеш

    def добавить(self, doc_id, текст):
        хеш = self._sh.вычислить(текст)
        self._хеши[doc_id] = хеш

        # разбить хеш на полосы
        маска = (1 << self._бит_на_полосу) - 1
        for п in range(self._полос):
            сдвиг = п * self._бит_на_полосу
            значение = (хеш >> сдвиг) & маска
            ключ = (п, значение)
            if ключ not in self._корзины:
                self._корзины[ключ] = []
            self._корзины[ключ].append(doc_id)

    def найти_кандидатов(self, doc_id):
        """Быстрый поиск кандидатов через корзины (без O(n²))."""
        хеш = self._хеши.get(doc_id)
        if хеш is None:
            return set()

        кандидаты = set()
        маска = (1 << self._бит_на_полосу) - 1
        for п in range(self._полос):
            сдвиг = п * self._бит_на_полосу
            значение = (хеш >> сдвиг) & маска
            ключ = (п, значение)
            для_полосы = self._корзины.get(ключ, [])
            кандидаты.update(для_полосы)

        кандидаты.discard(doc_id)
        return кандидаты


индекс = LSHИндекс(бит=64, полос=8)
индекс.добавить("d1", "Python язык программирования")
индекс.добавить("d2", "Python язык программирования общего назначения")
индекс.добавить("d3", "совсем другой текст")

кандидаты = индекс.найти_кандидатов("d1")
print("кандидаты для d1:", кандидаты)
# → {"d2"}  — похож, но не d3
```

### Big O

|Операция|Сложность|
|---|---|
|Вычисление SimHash|$O(t \cdot b)$ — $t$ токенов, $b$ бит|
|Расстояние Хэмминга|$O(b)$|
|Поиск дублей наивно|$O(n^2 \cdot b)$|
|LSH-индекс: добавить|$O(b)$|
|LSH-индекс: найти кандидатов|$O(b + k)$ — $k$ кандидатов|

---

### Плюсы и минусы

**Плюсы:**

- Быстрое сравнение документов — достаточно сравнить два числа
- Компактный «отпечаток» — 64 бит на документ любой длины
- LSH-индекс находит похожих за $O(1)$, не $O(n^2)$
- Работает для текстов, изображений, аудио (разные реализации LSH)

**Минусы:**

- Приближённый результат — могут быть ложноположительные и ложноотрицательные
- Качество зависит от правильного выбора шинглов и размера хеша
- Труднее интерпретировать чем точное сравнение
