# Двоичная куча и очередь с приоритетом

**Двоичная куча** (Binary Heap) — дерево, хранящееся в **массиве**, где каждый узел удовлетворяет свойству кучи: родитель ≤ детей (min-куча) или родитель ≥ детей (max-куча).

**Очередь с приоритетом** (Priority Queue) — АТД: при извлечении всегда получаем элемент с наименьшим (или наибольшим) приоритетом. Двоичная куча — стандартная реализация.

> **Аналогия:** приёмный покой больницы. Пациенты приходят в произвольном порядке, но врач всегда принимает самого тяжёлого — независимо от времени ожидания.

---

### Как куча хранится в массиве

Дерево записывается в массив уровень за уровнем. Для узла на индексе $i$:

- Левый ребёнок: $2i + 1$
- Правый ребёнок: $2i + 2$
- Родитель: $(i - 1) // 2$

```
min-куча:         массив:
       1           [1, 3, 5, 7, 4, 8, 9]
      / \
     3   5          i=0: 1  (корень)
    / \ / \         i=1: 3  (левый ребёнок 0)
   7  4 8  9        i=2: 5  (правый ребёнок 0)
                    i=3: 7  (левый ребёнок 1)
                    ...

узел i=1 (значение 3):
  левый ребёнок: 2*1+1 = 3 → arr[3] = 7
  правый ребёнок: 2*1+2 = 4 → arr[4] = 4
  родитель: (1-1)//2 = 0 → arr[0] = 1
```

Никаких указателей — массив компактен и cache-friendly.

---

### Операции

|Операция|Сложность|
|---|---|
|`peek` — посмотреть минимум|$O(1)$|
|`push` — добавить элемент|$O(\log n)$|
|`pop` — извлечь минимум|$O(\log n)$|
|`heapify` — построить кучу из массива|$O(n)$|

---

### Как работают операции

**push** — добавить в конец, затем «всплыть» (sift up): менять с родителем пока нарушается свойство кучи.

```
добавить 2 в [1, 3, 5, 7, 4]:
  → [1, 3, 5, 7, 4, 2]   добавили в конец (i=5)
  2 < parent[i=2]=5 → меняем: [1, 3, 2, 7, 4, 5]
  2 > parent[i=0]=1 → стоп
  → [1, 3, 2, 7, 4, 5]
```

**pop** — корень в результат, последний элемент на место корня, затем «утонуть» (sift down).

```
извлечь из [1, 3, 2, 7, 4, 5]:
  результат = 1
  [5, 3, 2, 7, 4]   последний на место корня
  5 > min(left=3, right=2)=2 → меняем с 2: [2, 3, 5, 7, 4]
  5 > min(left=7, right=4)=4 → меняем с 4: [2, 3, 4, 7, 5]
  5 — лист → стоп
  → [2, 3, 4, 7, 5]
```

### Реализации

#### Базовая min-куча

```python
class MinHeap:
    def __init__(self):
        self._данные = []

    def _родитель(self, i):    return (i - 1) // 2
    def _левый(self, i):       return 2 * i + 1
    def _правый(self, i):      return 2 * i + 2
    def _есть(self, i):        return i < len(self._данные)

    def peek(self):
        if not self._данные:
            raise IndexError("куча пуста")
        return self._данные[0]

    def push(self, значение):
        self._данные.append(значение)
        self._всплыть(len(self._данные) - 1)

    def pop(self):
        if not self._данные:
            raise IndexError("куча пуста")
        if len(self._данные) == 1:
            return self._данные.pop()
        минимум = self._данные[0]
        self._данные[0] = self._данные.pop()   # последний на место корня
        self._утонуть(0)
        return минимум

    def _всплыть(self, i):
        while i > 0:
            п = self._родитель(i)
            if self._данные[i] < self._данные[п]:
                self._данные[i], self._данные[п] = self._данные[п], self._данные[i]
                i = п
            else:
                break

    def _утонуть(self, i):
        n = len(self._данные)
        while True:
            наименьший = i
            л, п = self._левый(i), self._правый(i)
            if л < n and self._данные[л] < self._данные[наименьший]:
                наименьший = л
            if п < n and self._данные[п] < self._данные[наименьший]:
                наименьший = п
            if наименьший == i:
                break
            self._данные[i], self._данные[наименьший] = (
                self._данные[наименьший], self._данные[i]
            )
            i = наименьший

    def __len__(self):     return len(self._данные)
    def __bool__(self):    return bool(self._данные)
    def __repr__(self):    return f"MinHeap({self._данные})"


heap = MinHeap()
for x in [5, 3, 8, 1, 4, 2]:
    heap.push(x)
print(heap)             # → MinHeap([1, 3, 2, 5, 4, 8])
print(heap.pop())       # → 1
print(heap.pop())       # → 2
print(heap)             # → MinHeap([3, 5, 8, 4])
```

#### heapify — построить кучу за $O(n)$

Эффективнее чем $n$ раз вызывать `push` ($O(n \log n)$). Утапливаем все нелистовые узлы снизу вверх.

```python
def heapify(arr):
    """Преобразовать список в min-кучу на месте за O(n)."""
    n = len(arr)
    # начинаем с последнего нелистового узла
    for i in range(n // 2 - 1, -1, -1):
        _утонуть(arr, i, n)
    return arr

def _утонуть(arr, i, n):
    while True:
        наим = i
        л, п = 2*i+1, 2*i+2
        if л < n and arr[л] < arr[наим]: наим = л
        if п < n and arr[п] < arr[наим]: наим = п
        if наим == i: break
        arr[i], arr[наим] = arr[наим], arr[i]
        i = наим

данные = [5, 3, 8, 1, 4, 2]
heapify(данные)
print(данные)   # → [1, 3, 2, 5, 4, 8]
```

#### Heap Sort — сортировка кучей $O(n \log n)$, $O(1)$ памяти

```python
def heap_sort(arr):
    n = len(arr)

    # построить max-кучу (для сортировки по возрастанию)
    def _утонуть_макс(arr, i, n):
        while True:
            наиб = i
            л, п = 2*i+1, 2*i+2
            if л < n and arr[л] > arr[наиб]: наиб = л
            if п < n and arr[п] > arr[наиб]: наиб = п
            if наиб == i: break
            arr[i], arr[наиб] = arr[наиб], arr[i]
            i = наиб

    for i in range(n // 2 - 1, -1, -1):
        _утонуть_макс(arr, i, n)

    # извлекать максимум в конец массива
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        _утонуть_макс(arr, 0, i)

    return arr


heap_sort([5, 3, 8, 1, 4, 2])   # → [1, 2, 3, 4, 5, 8]
```

#### Очередь с приоритетом через heapq

```python
import heapq

class ОчередьСПриоритетом:
    def __init__(self):
        self._heap = []
        self._счётчик = 0   # для стабильного порядка при равных приоритетах

    def добавить(self, элемент, приоритет):
        # (приоритет, счётчик, элемент) — счётчик разрывает ничью
        heapq.heappush(self._heap, (приоритет, self._счётчик, элемент))
        self._счётчик += 1

    def извлечь(self):
        if not self._heap:
            raise IndexError("очередь пуста")
        приоритет, _, элемент = heapq.heappop(self._heap)
        return элемент, приоритет

    def посмотреть(self):
        if not self._heap:
            raise IndexError("очередь пуста")
        приоритет, _, элемент = self._heap[0]
        return элемент, приоритет

    def __len__(self):  return len(self._heap)
    def __bool__(self): return bool(self._heap)


очередь = ОчередьСПриоритетом()
очередь.добавить("задача C", приоритет=3)
очередь.добавить("задача A", приоритет=1)
очередь.добавить("задача B", приоритет=2)
очередь.добавить("задача D", приоритет=1)   # тот же приоритет что A

while очередь:
    задача, приоритет = очередь.извлечь()
    print(f"[{приоритет}] {задача}")
# → [1] задача A
# → [1] задача D
# → [2] задача B
# → [3] задача C
```

#### heapq — встроенный модуль Python

```python
import heapq

куча = []
heapq.heappush(куча, 5)
heapq.heappush(куча, 1)
heapq.heappush(куча, 3)

heapq.heappop(куча)   # → 1 (всегда минимум)
heapq.heappop(куча)   # → 3

# из готового списка за O(n):
данные = [5, 1, 3, 7, 4]
heapq.heapify(данные)

# n наибольших/наименьших:
heapq.nlargest(3, [5, 1, 3, 7, 4])    # → [7, 5, 4]
heapq.nsmallest(3, [5, 1, 3, 7, 4])   # → [1, 3, 4]

# слить несколько отсортированных последовательностей:
list(heapq.merge([1, 3, 5], [2, 4, 6]))   # → [1, 2, 3, 4, 5, 6]
```

### Min-куча vs Max-куча

Python `heapq` — только min-куча. Max-куча — отрицать значения.

```python
import heapq

# max-куча через отрицание:
max_куча = []
for x in [5, 1, 3, 7, 4]:
    heapq.heappush(max_куча, -x)

heapq.heappop(max_куча)   # → -7, то есть реальное значение 7
```

### Применение в алгоритмах

```python
# Дейкстра — очередь с приоритетом по расстоянию:
import heapq

def дейкстра(граф, старт):
    dist = {v: float("inf") for v in граф}
    dist[старт] = 0
    heap = [(0, старт)]

    while heap:
        d, v = heapq.heappop(heap)
        if d > dist[v]:
            continue
        for сосед, вес in граф[v]:
            новое = dist[v] + вес
            if новое < dist[сосед]:
                dist[сосед] = новое
                heapq.heappush(heap, (новое, сосед))
    return dist


# K наибольших элементов за O(n log k):
def k_наибольших(поток, k):
    min_куча = []
    for x in поток:
        if len(min_куча) < k:
            heapq.heappush(min_куча, x)
        elif x > min_куча[0]:
            heapq.heapreplace(min_куча, x)
    return sorted(min_куча, reverse=True)

k_наибольших([3, 1, 5, 2, 8, 4, 7], k=3)   # → [8, 7, 5]


# Медиана потока — две кучи:
class МедианаПотока:
    def __init__(self):
        self._макс_куча = []   # левая половина (отрицательные)
        self._мин_куча = []    # правая половина

    def добавить(self, x):
        heapq.heappush(self._макс_куча, -x)
        # перебалансировать
        if self._мин_куча and -self._макс_куча[0] > self._мин_куча[0]:
            heapq.heappush(self._мин_куча, -heapq.heappop(self._макс_куча))
        if len(self._макс_куча) > len(self._мин_куча) + 1:
            heapq.heappush(self._мин_куча, -heapq.heappop(self._макс_куча))
        if len(self._мин_куча) > len(self._макс_куча):
            heapq.heappush(self._макс_куча, -heapq.heappop(self._мин_куча))

    def медиана(self):
        if len(self._макс_куча) > len(self._мин_куча):
            return -self._макс_куча[0]
        return (-self._макс_куча[0] + self._мин_куча[0]) / 2


м = МедианаПотока()
for x in [5, 2, 8, 1, 9]:
    м.добавить(x)
    print(м.медиана())   # → 5, 3.5, 5, 3.5, 5
```

### Плюсы и минусы

**Плюсы:**

- $O(\log n)$ на push/pop — быстрее линейного поиска минимума $O(n)$
- $O(1)$ peek — всегда минимум в корне
- $O(n)$ heapify — эффективное построение
- Компактное хранение в массиве, cache-friendly

**Минусы:**

- Нет произвольного доступа по ключу — только min/max
- Поиск произвольного элемента — $O(n)$
- Не устойчивая — порядок равных элементов не гарантирован
- Нельзя эффективно обновить приоритет элемента в середине

### Применение

- **[Алгоритм Дейкстры](../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md)** — всегда обрабатывать ближайшую вершину

- **Планировщик задач** — OS выбирает процесс с наивысшим приоритетом
- **k наибольших элементов** в потоке за $O(n \log k)$
- **Медиана потока** — две кучи
- **[Подсчёт ресурсов по интервалам](../../Алгоритмы/Приёмы/Интервалы.md#минимум-переговорок)** — куча концов как множество занятых комнат: сколько нужно переговорок, номеров в отеле, операционных
- **Heap Sort** — $O(n \log n)$, $O(1)$ памяти
- **Поиск кратчайшего пути** в A*
