# Алгоритм Беллмана — Форда

**Алгоритм Беллмана — Форда** — нахождение кратчайшего пути от одной вершины до всех остальных во взвешенном графе, в том числе с **отрицательными** весами рёбер. Дополнительно обнаруживает **отрицательные циклы**.

> **Аналогия:** обмен валюты через цепочку банков. Некоторые курсы «выгодные» — отрицательная стоимость. Алгоритм проходит все возможные маршруты несколько раз, каждый раз улучшая оценки, пока улучшения не прекратятся.

Медленнее [Дейкстры](../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md), зато работает там, где Дейкстра даёт неверный ответ — при отрицательных весах.

---

### Почему Дейкстра не работает с отрицательными весами

```
A —(2)— B —(-4)— C
A —(3)— C

Дейкстра от A:
  обрабатывает C с расстоянием 3 и закрывает
  позже находит путь A→B→C = 2 + (−4) = −2
  но C уже «закрыта» → не обновляется → неверный ответ: 3 вместо -2
```

Дейкстра закрывает вершины, предполагая что дешевле уже не будет. Отрицательное ребро опровергает это. Беллман-Форд не закрывает вершины — он проходит все рёбра $V-1$ раз.

---

### Как работает

Ключевое наблюдение: кратчайший путь в графе из $V$ вершин содержит не более $V-1$ рёбер (иначе — цикл). Значит, $V-1$ итераций релаксации всех рёбер гарантированно находят оптимальный путь.

**Релаксация ребра** $(u, v, w)$: если `dist[u] + w < dist[v]` — обновить `dist[v]`.

```
граф:
A —(1)— B —(−3)— C
A —(4)— C

старт: A
dist = {A:0, B:∞, C:∞}

итерация 1 (проходим все рёбра):
  ребро A→B: 0+1=1 < ∞ → dist[B] = 1
  ребро B→C: 1+(−3)=−2 < ∞ → dist[C] = −2
  ребро A→C: 0+4=4 > −2 → не обновляем

итерация 2:
  ребро A→B: 0+1=1 = 1 → нет изменений
  ребро B→C: 1+(−3)=−2 = −2 → нет изменений
  ребро A→C: 0+4=4 > −2 → нет изменений

итерации 1..V-1 не дали новых изменений → готово

dist = {A:0, B:1, C:−2}   → A→B→C = −2 ✓
```

### Реализации

#### Базовая

```python
def беллман_форд(вершины, рёбра, старт):
    """
    вершины — список всех вершин
    рёбра   — список (u, v, вес)
    """
    dist = {v: float("inf") for v in вершины}
    dist[старт] = 0
    предшественник = {старт: None}

    # V-1 итераций релаксации
    for _ in range(len(вершины) - 1):
        обновлено = False
        for u, v, w in рёбра:
            if dist[u] != float("inf") and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                предшественник[v] = u
                обновлено = True
        if not обновлено:
            break   # ранняя остановка если уже сошлось

    # проверка на отрицательный цикл
    for u, v, w in рёбра:
        if dist[u] != float("inf") and dist[u] + w < dist[v]:
            raise ValueError("граф содержит отрицательный цикл")

    return dist, предшественник


def восстановить_путь(предшественник, цель):
    путь = []
    текущая = цель
    while текущая is not None:
        путь.append(текущая)
        текущая = предшественник.get(текущая)
    return путь[::-1]


вершины = ["A", "B", "C", "D"]
рёбра = [
    ("A", "B", 1),
    ("B", "C", -3),
    ("A", "C", 4),
    ("C", "D", 2),
]
dist, пред = беллман_форд(вершины, рёбра, "A")
print(dist)                               # → {"A":0, "B":1, "C":-2, "D":0}
print(восстановить_путь(пред, "D"))       # → ["A", "B", "C", "D"]
```

#### С форматом графа как словарь

```python
def беллман_форд_граф(граф, старт):
    """
    граф: {u: [(v, вес), ...]}
    """
    # собрать список рёбер из словаря
    рёбра = []
    for u in граф:
        for v, w in граф[u]:
            рёбра.append((u, v, w))

    dist = {v: float("inf") for v in граф}
    dist[старт] = 0
    предшественник = {старт: None}

    for _ in range(len(граф) - 1):
        for u, v, w in рёбра:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                предшественник[v] = u

    # проверка отрицательного цикла
    for u, v, w in рёбра:
        if dist[u] + w < dist[v]:
            raise ValueError(f"отрицательный цикл: через {u} → {v}")

    return dist, предшественник


граф = {
    "A": [("B", 4), ("C", 2)],
    "B": [("D", -1)],
    "C": [("B", -3), ("D", 5)],
    "D": [],
}
dist, _ = беллман_форд_граф(граф, "A")
print(dist)   # → {"A":0, "B":-1, "C":2, "D":-2}
```

#### Обнаружение отрицательного цикла и его восстановление

```python
def найти_отрицательный_цикл(вершины, рёбра):
    """Возвращает список вершин отрицательного цикла или None."""
    dist = {v: 0 for v in вершины}   # 0 для всех — ищем любой цикл
    предшественник = {v: None for v in вершины}

    последняя_обновлённая = None

    for i in range(len(вершины)):
        последняя_обновлённая = None
        for u, v, w in рёбра:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                предшественник[v] = u
                последняя_обновлённая = v

    if последняя_обновлённая is None:
        return None   # отрицательного цикла нет

    # пройти V раз чтобы точно оказаться внутри цикла
    v = последняя_обновлённая
    for _ in range(len(вершины)):
        v = предшественник[v]

    # теперь v внутри цикла — восстанавливаем его
    цикл = []
    текущая = v
    while True:
        цикл.append(текущая)
        текущая = предшественник[текущая]
        if текущая == v:
            break
    цикл.append(v)

    return цикл[::-1]


вершины = ["A", "B", "C"]
рёбра_с_циклом = [
    ("A", "B", 1),
    ("B", "C", -3),
    ("C", "A", 1),   # цикл A→B→C→A с суммой 1-3+1 = -1
]
найти_отрицательный_цикл(вершины, рёбра_с_циклом)
# → ["A", "B", "C", "A"]  или аналогичный цикл
```

#### Оптимизированная версия — ранняя остановка + очередь SPFA

SPFA (Shortest Path Faster Algorithm) — очередеобразная оптимизация Беллмана-Форда. Обрабатывает только вершины, расстояние которых изменилось.

```python
from collections import deque

def spfa(граф, старт):
    """SPFA — оптимизированный Беллман-Форд через очередь."""
    dist = {v: float("inf") for v in граф}
    dist[старт] = 0
    предшественник = {старт: None}
    в_очереди = {v: False for v in граф}
    счётчик = {v: 0 for v in граф}   # сколько раз вершина добавлялась

    очередь = deque([старт])
    в_очереди[старт] = True
    счётчик[старт] = 1

    while очередь:
        u = очередь.popleft()
        в_очереди[u] = False

        for v, w in граф[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                предшественник[v] = u
                if not в_очереди[v]:
                    очередь.append(v)
                    в_очереди[v] = True
                    счётчик[v] += 1
                    if счётчик[v] >= len(граф):
                        raise ValueError("отрицательный цикл")

    return dist, предшественник


граф = {
    "A": [("B", 1), ("C", 4)],
    "B": [("C", -3)],
    "C": [("D", 2)],
    "D": [],
}
dist, _ = spfa(граф, "A")
print(dist)   # → {"A":0, "B":1, "C":-2, "D":0}
```

---

### Big O

|Реализация|Время|Память|
|---|---|---|
|Базовая|$O(V \cdot E)$|$O(V)$|
|С ранней остановкой|$O(V \cdot E)$ худший, быстрее на практике|$O(V)$|
|SPFA|$O(V \cdot E)$ худший, $O(E)$ средний|$O(V + E)$|

Беллман-Форд всегда медленнее Дейкстры на графах без отрицательных весов. Использовать только когда они есть.

---

### Беллман-Форд vs Дейкстра

| |[Дейкстра](../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md)|Беллман-Форд|
|---|---|---|
|Отрицательные веса|✗|✓|
|Отрицательные циклы (обнаружение)|✗|✓|
|Время|$O((V+E)\log V)$|$O(V \cdot E)$|
|Скорость|Быстрее|Медленнее|
|Когда использовать|Веса ≥ 0|Есть отрицательные веса|

---

### Плюсы и минусы

**Плюсы:**

- Работает с отрицательными весами рёбер
- Обнаруживает отрицательные циклы
- Простая реализация — тройной цикл
- Работает с любым форматом задания рёбер

**Минусы:**

- $O(V \cdot E)$ — медленнее Дейкстры
- Не подходит для больших плотных графов
- Отрицательный цикл делает задачу нерешаемой (бесконечно уменьшающийся путь)

---

### Применение

- Финансовые графы с арбитражем — отрицательный цикл = прибыльная цепочка обменов
- Маршрутизация в компьютерных сетях — протокол RIP использует вариант Беллмана-Форда
- Обнаружение аномалий — поиск циклов с суммарно отрицательным весом
- Игровые карты где некоторые пути «дают» ресурсы (отрицательная стоимость)

```python
# пример: арбитраж валют
# логарифмируем курсы: вес = -log(курс)
# отрицательный цикл = прибыльная цепочка обменов
import math

курсы = {
    "USD": [("EUR", 0.9), ("RUB", 90.0)],
    "EUR": [("USD", 1.1), ("RUB", 100.0)],
    "RUB": [("USD", 0.011), ("EUR", 0.01)],
}

рёбра = []
for u in курсы:
    for v, курс in курсы[u]:
        рёбра.append((u, v, -math.log(курс)))   # отрицательный лог

try:
    dist, _ = беллман_форд(list(курсы.keys()), рёбра, "USD")
    print("арбитража нет")
except ValueError:
    print("найден арбитраж — прибыльная цепочка обменов!")
```

> Без отрицательных весов → [Алгоритм Дейкстры](../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md). Невзвешенный граф → [BFS — поиск в ширину](../../Алгоритмы/Поиск/BFS.md). Нотация — Вычислительная сложность.
