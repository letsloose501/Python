# BFS — поиск в ширину

**BFS** (Breadth-First Search, поиск в ширину) — обход графа уровень за уровнем. Сначала все соседи стартовой вершины, потом их соседи, и так далее.

> **Аналогия:** камень брошен в воду — круги расходятся равномерно во все стороны. BFS так же расходится от стартовой точки, обрабатывая все вершины на расстоянии 1, потом 2, потом 3...

Отвечает на два вопроса: **существует ли путь** из A в B, и **какой путь кратчайший** (по числу рёбер).

---

### Как работает

Использует очередь (FIFO): кто добавлен первым — обрабатывается первым. Это гарантирует, что вершины обрабатываются в порядке удалённости от старта.

```
граф:
A — B — D
|       |
C ——————┘

старт: A

шаг 1: очередь = [A],  посещённые = {A}
шаг 2: берём A → добавляем соседей B, C
       очередь = [B, C], посещённые = {A, B, C}
шаг 3: берём B → добавляем D
       очередь = [C, D], посещённые = {A, B, C, D}
шаг 4: берём C → D уже посещена, ничего не добавляем
       очередь = [D]
шаг 5: берём D → нет новых соседей
       очередь = []

порядок обхода: A → B → C → D
```

Без `посещённых` алгоритм зациклится на графе с циклами.

---

### Реализации

#### Базовая — обход графа

```python
from collections import deque

def bfs(граф, старт):
    посещённые = {старт}
    очередь = deque([старт])
    порядок = []

    while очередь:
        вершина = очередь.popleft()
        порядок.append(вершина)

        for сосед in граф[вершина]:
            if сосед not in посещённые:
                посещённые.add(сосед)
                очередь.append(сосед)

    return порядок


граф = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C"],
}
bfs(граф, "A")   # → ["A", "B", "C", "D"]
```

#### Поиск пути от A до B

```python
from collections import deque

def bfs_path(граф, старт, цель):
    if старт == цель:
        return [старт]

    посещённые = {старт}
    очередь = deque([(старт, [старт])])   # (вершина, путь до неё)

    while очередь:
        вершина, путь = очередь.popleft()

        for сосед in граф[вершина]:
            if сосед not in посещённые:
                новый_путь = путь + [сосед]
                if сосед == цель:
                    return новый_путь
                посещённые.add(сосед)
                очередь.append((сосед, новый_путь))

    return None   # путь не найден


граф = {
    "A": ["B", "C"],
    "B": ["D", "E"],
    "C": ["F"],
    "D": [], "E": [], "F": [],
}
bfs_path(граф, "A", "E")   # → ["A", "B", "E"]
bfs_path(граф, "A", "X")   # → None
```

#### Кратчайшее расстояние (количество шагов)

```python
from collections import deque

def bfs_distance(граф, старт):
    расстояния = {старт: 0}
    очередь = deque([старт])

    while очередь:
        вершина = очередь.popleft()

        for сосед in граф[вершина]:
            if сосед not in расстояния:
                расстояния[сосед] = расстояния[вершина] + 1
                очередь.append(сосед)

    return расстояния


граф = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}
bfs_distance(граф, "A")
# → {"A": 0, "B": 1, "C": 1, "D": 2}
```
 
#### Обход по уровням

```python
from collections import deque

def bfs_levels(граф, старт):
    посещённые = {старт}
    очередь = deque([[старт]])   # очередь уровней
    уровни = []

    while очередь:
        уровень = очередь.popleft()
        уровни.append(уровень)
        следующий = []

        for вершина in уровень:
            for сосед in граф[вершина]:
                if сосед not in посещённые:
                    посещённые.add(сосед)
                    следующий.append(сосед)

        if следующий:
            очередь.append(следующий)

    return уровни


граф = {"A": ["B", "C"], "B": ["D", "E"], "C": ["F"], "D": [], "E": [], "F": []}
bfs_levels(граф, "A")
# → [["A"], ["B", "C"], ["D", "E", "F"]]
```

#### BFS на матрице (лабиринт)

```python
from collections import deque

def bfs_maze(сетка, старт, цель):
    """
    сетка — двумерный список: 0 = свободно, 1 = стена
    старт, цель — кортежи (строка, столбец)
    """
    строк = len(сетка)
    столбцов = len(сетка[0])
    направления = [(0,1),(0,-1),(1,0),(-1,0)]

    посещённые = {старт}
    очередь = deque([(старт, [старт])])

    while очередь:
        (r, c), путь = очередь.popleft()

        if (r, c) == цель:
            return путь

        for dr, dc in направления:
            nr, nc = r + dr, c + dc
            if (0 <= nr < строк and 0 <= nc < столбцов
                    and сетка[nr][nc] == 0
                    and (nr, nc) not in посещённые):
                посещённые.add((nr, nc))
                очередь.append(((nr, nc), путь + [(nr, nc)]))

    return None   # выхода нет


лабиринт = [
    [0, 1, 0, 0],
    [0, 0, 0, 1],
    [1, 0, 1, 0],
    [0, 0, 0, 0],
]
bfs_maze(лабиринт, (0,0), (3,3))
# → [(0,0),(1,0),(1,1),(1,2),(2,1),(3,1),(3,2),(3,3)]
```

#### Топологическая сортировка (алгоритм Кана)

BFS на направленном графе — упорядочить вершины так, чтобы все зависимости стояли раньше.

```python
from collections import deque, defaultdict

def топологическая_сортировка(граф):
    входящие = defaultdict(int)
    for v in граф:
        for сосед in граф[v]:
            входящие[сосед] += 1

    # начинаем с вершин без зависимостей
    очередь = deque(v for v in граф if входящие[v] == 0)
    порядок = []

    while очередь:
        v = очередь.popleft()
        порядок.append(v)
        for сосед in граф[v]:
            входящие[сосед] -= 1
            if входящие[сосед] == 0:
                очередь.append(сосед)

    if len(порядок) != len(граф):
        raise ValueError("граф содержит цикл")
    return порядок


# задачи: A и B не зависят ни от чего, C зависит от A, D зависит от B и C
граф = {"A": ["C"], "B": ["D"], "C": ["D"], "D": []}
топологическая_сортировка(граф)
# → ["A", "B", "C", "D"]  или  ["B", "A", "C", "D"]
```

### Big O

| |Сложность|
|---|---|
|Время|$O(V + E)$|
|Память|$O(V)$|

$V$ — вершины, $E$ — рёбра. Каждая вершина добавляется в очередь один раз, каждое ребро просматривается один раз.

Память: в худшем случае вся очередь содержит все вершины одного уровня — может быть $O(V)$.

> **Сколько на самом деле лежит в очереди.** Для сетки $n \times m$ ходит поверье «не больше $n + m$, ведь это фронт волны». Замером оно опровергается: на H-фрактальном лабиринте пик очереди достигает $1{,}45 \cdot (n+m)$ и растёт с размером поля. Но и обратное утверждение — «очередь доходит до $n \cdot m$» — не подтверждается: её доля от площади поля падает вдвое при каждом удвоении стороны. Спор при этом бесполезен: массив посещённых уже занимает $O(n \cdot m)$, поэтому итоговая оценка памяти от размера очереди не зависит. Замеры — в [Обход клетчатого поля](../../Алгоритмы/Приёмы/Обход%20клетчатого%20поля.md#оценки).

### BFS vs DFS

| |BFS|[DFS](../../Алгоритмы/Поиск/DFS.md)|
|---|---|---|
|Структура|Очередь (FIFO)|Стек / рекурсия|
|Порядок|Уровень за уровнем|Сначала вглубь|
|Кратчайший путь (невзвешенный)|✓|✗|
|Топологическая сортировка|✓ (алгоритм Кана)|✓|
|Память|$O(V)$ — может быть большой|$O(h)$ — глубина дерева|
|Подходит для|Кратчайший путь, уровни|Циклы, компоненты, топосортировка|

---

### Плюсы и минусы

**Плюсы:**

- Гарантирует кратчайший путь по числу рёбер
- Находит все вершины на заданном расстоянии
- Обнаруживает компоненты связности
- Хорошо работает на широких, неглубоких графах

**Минусы:**

- $O(V)$ памяти — очередь может вырасти до всех вершин одного уровня
- Не подходит для взвешенных графов — там нужен [Алгоритм Дейкстры](../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md)
- Медленнее DFS на задачах где важна только достижимость

---

### Применение

- Кратчайший путь в невзвешенном графе — навигация, сети
- Топологическая сортировка — порядок сборки, зависимости пакетов
- Обход уровней дерева — вывод иерархии, поиск по уровням
- Обнаружение компонент связности
- BFS на матрице — лабиринты, карты, задачи на сетке ([Обход клетчатого поля](../../Алгоритмы/Приёмы/Обход%20клетчатого%20поля.md) — шаблон, ловушки, оценки)
- **Мультистарт** — волна сразу из нескольких источников: в очередь кладут все стартовые вершины, и каждая клетка достаётся тому, кто добрался первым. Заменяет $k$ отдельных обходов одним, сложность остаётся $O(V+E)$ ([разбор](../../Алгоритмы/Приёмы/Обход%20клетчатого%20поля.md#мультистарт-волна-из-нескольких-источников))
- Краулеры сайтов — обход ссылок по уровням вложенности
- Социальные сети — найти всех друзей в радиусе N рукопожатий

> Взвешенный граф → [Алгоритм Дейкстры](../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md). Стратегия обхода — [DFS — поиск в глубину](../../Алгоритмы/Поиск/DFS.md). Нотация — Вычислительная сложность.
