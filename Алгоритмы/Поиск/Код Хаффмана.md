# Код Хаффмана

**Код Хаффмана** (Huffman Coding) — алгоритм **сжатия данных без потерь**. Частым символам назначается короткий двоичный код, редким — длинный. Итоговое представление занимает меньше места чем стандартное 8-битное ASCII.

> **Аналогия:** азбука Морзе. «Е» (самая частая буква) — одна точка. «Й» — редкая буква — длинная последовательность. Хаффман делает то же самое автоматически, исходя из реальных частот в тексте.

Жадный алгоритм (жадная стратегия): на каждом шаге объединяет два наименее частых символа. Гарантированно оптимален для посимвольного кодирования.

---

### Как работает

#### Шаг 1 — Подсчитать частоты

```
текст: "aabbbcccc"

частоты: a=2, b=3, c=4
```

#### Шаг 2 — Построить дерево снизу вверх

Каждый символ — лист дерева с весом = частота. На каждом шаге берём два узла с наименьшим весом, создаём родителя с весом = сумма детей.

```
начало: [a:2] [b:3] [c:4]

шаг 1: объединяем a:2 и b:3 → [ab:5]
       оставшиеся: [c:4] [ab:5]

шаг 2: объединяем c:4 и ab:5 → [корень:9]

дерево:
         9
        / \
       4   5
       c  / \
         2   3
         a   b
```

#### Шаг 3 — Назначить коды

Левое ребро = 0, правое ребро = 1. Код символа = путь от корня до листа.

```
         9
        / \
     0/   \1
      c    5
          / \
        0/   \1
         a    b

c → 0
a → 10
b → 11
```

#### Шаг 4 — Закодировать

```
"aabbbcccc"
= 10 10 11 11 11 0 0 0 0
= 1010111100 00  (14 бит)

без Хаффмана: 9 символов × 8 бит = 72 бита
с Хаффманом: 14 бит → сжатие ~80%
```

---

### Почему коды не перекрываются

Символы только в **листьях** дерева. Никакой код не является префиксом другого. Это называется **префиксным кодом** — декодирование однозначно: идёшь по дереву бит за битом, дошёл до листа — нашёл символ, начинаешь сначала.

```
биты: 1010111100
     1 → идём вправо
     0 → идём влево → лист: a → reset
     1 → идём вправо
     0 → идём влево → лист: a → reset
     ...
```

### Реализации

#### Базовая — построение дерева и кодирование

```python
import heapq
from collections import Counter, defaultdict

class УзелХаффмана:
    def __init__(self, символ, частота):
        self.символ = символ
        self.частота = частота
        self.левый = None
        self.правый = None

    # для heapq — сравниваем по частоте
    def __lt__(self, другой):
        return self.частота < другой.частота


def построить_дерево(текст):
    частоты = Counter(текст)
    куча = [УзелХаффмана(с, ч) for с, ч in частоты.items()]
    heapq.heapify(куча)

    while len(куча) > 1:
        левый = heapq.heappop(куча)
        правый = heapq.heappop(куча)
        родитель = УзелХаффмана(None, левый.частота + правый.частота)
        родитель.левый = левый
        родитель.правый = правый
        heapq.heappush(куча, родитель)

    return куча[0]   # корень


def построить_коды(корень):
    коды = {}

    def _обход(узел, текущий_код):
        if узел is None:
            return
        if узел.символ is not None:   # лист
            коды[узел.символ] = текущий_код or "0"   # "0" для текста из 1 символа
            return
        _обход(узел.левый, текущий_код + "0")
        _обход(узел.правый, текущий_код + "1")

    _обход(корень, "")
    return коды


def кодировать(текст):
    корень = построить_дерево(текст)
    коды = построить_коды(корень)
    закодированный = "".join(коды[с] for с in текст)
    return закодированный, корень, коды


def декодировать(биты, корень):
    результат = []
    текущий = корень
    for бит in биты:
        текущий = текущий.левый if бит == "0" else текущий.правый
        if текущий.символ is not None:
            результат.append(текущий.символ)
            текущий = корень
    return "".join(результат)


# пример:
текст = "aabbbcccc"
биты, корень, коды = кодировать(текст)
print("коды:", коды)
# → {"c": "0", "a": "10", "b": "11"}

print("закодировано:", биты)
# → "1010111100000"

print("декодировано:", декодировать(биты, корень))
# → "aabbbcccc"

оригинал_бит = len(текст) * 8
сжатых_бит = len(биты)
print(f"сжатие: {оригинал_бит} → {сжатых_бит} бит ({100 - сжатых_бит*100//оригинал_бит}%)")
```

#### С сохранением таблицы кодов (для передачи)

Для декодирования нужно либо дерево, либо таблица кодов. При передаче файла их нужно сохранять вместе с данными.

```python
import json

def сохранить_кодировку(текст):
    биты, _, коды = кодировать(текст)
    # добавляем длину чтобы знать где padding при записи в байты
    заголовок = json.dumps(коды, ensure_ascii=False)
    return заголовок, биты

def загрузить_и_декодировать(заголовок, биты):
    коды = json.loads(заголовок)
    # инвертируем: код → символ
    обратные_коды = {v: k for k, v in коды.items()}

    результат = []
    буфер = ""
    for бит in биты:
        буфер += бит
        if буфер in обратные_коды:
            результат.append(обратные_коды[буфер])
            буфер = ""
    return "".join(результат)


заголовок, биты = сохранить_кодировку("hello world")
print(загрузить_и_декодировать(заголовок, биты))   # → "hello world"
```

#### Перевод битов в байты — реальное сжатие

```python
def биты_в_байты(биты):
    """Упаковать строку битов в bytes. Добавляем padding до кратности 8."""
    padding = (8 - len(биты) % 8) % 8
    биты += "0" * padding
    байты = bytearray()
    for i in range(0, len(биты), 8):
        байты.append(int(биты[i:i+8], 2))
    return bytes(байты), padding

def байты_в_биты(байты, padding):
    биты = "".join(f"{b:08b}" for b in байты)
    return биты[:-padding] if padding else биты


текст = "aabbbcccc" * 100
биты_строка, корень, _ = кодировать(текст)
байты, padding = биты_в_байты(биты_строка)

print(f"оригинал: {len(текст)} байт")
print(f"сжато:    {len(байты)} байт")
print(f"коэффициент: {len(текст) / len(байты):.2f}x")

# декодирование обратно
биты_обратно = байты_в_биты(байты, padding)
print(декодировать(биты_обратно, корень) == текст)   # → True
```

#### Полный класс

```python
import heapq
from collections import Counter

class КодировщикХаффмана:
    def __init__(self):
        self.корень = None
        self.коды = {}

    class _Узел:
        def __init__(self, символ, частота):
            self.символ = символ
            self.частота = частота
            self.левый = self.правый = None
        def __lt__(self, д):
            return self.частота < д.частота

    def обучить(self, текст):
        частоты = Counter(текст)
        куча = [self._Узел(с, ч) for с, ч in частоты.items()]
        heapq.heapify(куча)

        if len(куча) == 1:
            единственный = heapq.heappop(куча)
            self.корень = self._Узел(None, единственный.частота)
            self.корень.левый = единственный
        else:
            while len(куча) > 1:
                l, r = heapq.heappop(куча), heapq.heappop(куча)
                р = self._Узел(None, l.частота + r.частота)
                р.левый, р.правый = l, r
                heapq.heappush(куча, р)
            self.корень = куча[0]

        self.коды = {}
        self._обойти(self.корень, "")
        return self

    def _обойти(self, узел, код):
        if узел is None:
            return
        if узел.символ is not None:
            self.коды[узел.символ] = код or "0"
        else:
            self._обойти(узел.левый, код + "0")
            self._обойти(узел.правый, код + "1")

    def кодировать(self, текст):
        return "".join(self.коды[с] for с in текст)

    def декодировать(self, биты):
        результат, текущий = [], self.корень
        for бит in биты:
            текущий = текущий.левый if бит == "0" else текущий.правый
            if текущий.символ is not None:
                результат.append(текущий.символ)
                текущий = self.корень
        return "".join(результат)

    def коэффициент_сжатия(self, текст):
        биты = self.кодировать(текст)
        оригинал = len(текст) * 8
        сжато = len(биты)
        return оригинал, сжато, оригинал / сжато


кодировщик = КодировщикХаффмана()
кодировщик.обучить("this is an example of a huffman tree")
биты = кодировщик.кодировать("this is an example of a huffman tree")
print(кодировщик.декодировать(биты))   # → "this is an example of a huffman tree"

orig, comp, ratio = кодировщик.коэффициент_сжатия("this is an example of a huffman tree")
print(f"{orig} → {comp} бит, сжатие {ratio:.2f}x")
```

### Big O

|Операция|Сложность|
|---|---|
|Подсчёт частот|$O(n)$|
|Построение дерева|$O(k \log k)$|
|Кодирование текста|$O(n)$|
|Декодирование|$O(n)$|
|**Итого**|$O(n + k \log k)$|

$n$ — длина текста, $k$ — количество уникальных символов. Обычно $k \ll n$, поэтому доминирует $O(n)$.

Память: $O(k)$ для дерева и таблицы кодов.

### Степень сжатия

Зависит от распределения частот. Чем неравномернее распределение — тем лучше сжатие.

|Распределение|Ожидаемое сжатие|
|---|---|
|Один символ встречается в 90%|Очень хорошее (~90%)|
|Равномерное (все одинаково часто)|Нет сжатия — коды одинаковой длины|
|Типичный английский текст|~40–50%|
|Типичный русский текст|~35–45%|

```python
def показать_эффективность(текст):
    _, корень, коды = кодировать(текст)
    частоты = Counter(текст)
    total = len(текст)
    средняя_длина = sum(частоты[с] / total * len(код) for с, код in коды.items())
    print(f"средняя длина кода: {средняя_длина:.2f} бит/символ (vs 8 бит ASCII)")
    for с, код in sorted(коды.items(), key=lambda x: len(x[1])):
        print(f"  {repr(с)}: {код!r:10} частота={частоты[с]}")

показать_эффективность("aabbbcccc")
#   'c': '0'       частота=4
#   'a': '10'      частота=2
#   'b': '11'      частота=3
# средняя длина кода: 1.56 бит/символ (vs 8 бит ASCII)
```

### Плюсы и минусы

**Плюсы:**

- Оптимален для посимвольного кодирования — доказуемо лучший префиксный код
- Без потерь — исходные данные восстанавливаются полностью
- Простая идея, эффективная реализация
- Работает с любыми данными: текст, изображения, звук

**Минусы:**

- Нужно хранить/передавать таблицу кодов вместе с данными
- Не адаптивный — строится по заранее известным частотам
- Хуже современных алгоритмов (LZ77, LZ78, Deflate) на реальных данных
- Не использует контекст — каждый символ кодируется независимо

---

### Применение

- **ZIP, GZIP, ZLIB** — используют Хаффман как один из этапов (после LZ77)
- **JPEG** — финальный этап сжатия коэффициентов DCT
- **MP3** — часть схемы кодирования аудио
- **Deflate** (PNG, HTTP gzip) — LZ77 + Хаффман
- Учебный пример жадного алгоритма и оптимального префиксного кода

```python
# сравнение с zlib (который тоже использует Хаффман внутри):
import zlib
текст = "aabbbcccc" * 1000
оригинал = текст.encode()
сжатый = zlib.compress(оригинал)
print(f"наш Хаффман: ~{len(текст) * 156 // 800} байт")   # ~195 байт
print(f"zlib:        {len(сжатый)} байт")                  # ещё меньше
```
