# Шпаргалка — шаблоны алгоритмов

> Готовые каркасы: **распознал приём → скопировал шаблон → адаптировал**. Каждый блок: *когда применять → шаблон → сложность → где встречается*.
>
> **Как выбрать приём по условию:**
> - «отсортированный массив / пара / палиндром» → **два указателя**
> - «подстрока/подмассив без повторов, максимум окна» → **скользящее окно**
> - «сумма подмассива = k» → **префиксные суммы + хеш**
> - «найти в отсортированном / минимальное X, при котором ...» → **бинпоиск (в т.ч. по ответу)**
> - «есть ли / сколько раз / частоты» → **хеш-таблица**
> - «следующий больший / скобки / вложенность» → **стек**
> - «кратчайший путь по клеткам/невзвешенному графу» → **BFS**
> - «связность / обойти всё / компоненты» → **DFS**
> - «зависимости, порядок» → **топологическая сортировка**
> - «кратчайший путь во взвешенном графе» → **Дейкстра**
> - «все комбинации / перестановки / расстановки» → **backtracking**
> - «оптимум с перекрывающимися подзадачами» → **динамическое программирование**
> - «числа из диапазона 1..n, длина массива n, память O(1)» → **циклическая сортировка**
> - «все элементы парами, кроме одного» / «двоичное представление» → **биты (XOR)**
> - «максимальная сумма подряд идущих» → **Кадане**

## 0. Быстрый ввод-вывод (контест)

Медленный `input()`/`print()` в цикле съедает время. Шаблон на старте каждого решения:

```python
import sys

input = sys.stdin.readline            # одна строка быстро
data = sys.stdin.buffer.read().split()  # разом всё, если ввода много

# вывод — собрать в список и вывести одним write:
out = []
# ... out.append(str(результат))
sys.stdout.write("\n".join(out) + "\n")
```
Опора: [sys](../Библиотеки/Модули/Система%20и%20окружение/sys.md). Всегда `int(input())`, `map(int, input().split())` для чисел.

## 1. Два указателя ([Два указателя](../Алгоритмы/Приёмы/Два%20указателя.md))

**Когда:** отсортированный массив; пара/тройка с суммой; палиндром; слияние. Два индекса вместо вложенного цикла → `O(n²)` → `O(n)`.

**Сходящиеся (навстречу):**
```python
def two_sum_sorted(a, target):
    l, r = 0, len(a) - 1
    while l < r:
        s = a[l] + a[r]
        if s == target:
            return l, r
        if s < target:
            l += 1          # нужно больше
        else:
            r -= 1          # нужно меньше
    return -1
```
**Сложность:** time `O(n)`, space `O(1)`.
**Где:** #167 Two Sum II, #125 Valid Palindrome, #15 3Sum, #11 Container With Most Water.

## 2. Скользящее окно ([Скользящее окно](../Алгоритмы/Приёмы/Скользящее%20окно.md))

**Когда:** самая длинная/короткая подстрока или подмассив по условию. Окно `[left, right]` расширяется вправо, сжимается слева при нарушении.

```python
def longest_unique(s):
    last = {}          # символ -> последний индекс
    left = 0
    best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1     # сдвигаем левую границу
        last[ch] = right
        best = max(best, right - left + 1)
    return best
```
**Сложность:** time `O(n)`, space `O(k)` (алфавит).
**Где:** #3 Longest Substring Without Repeating, #209 Minimum Size Subarray Sum, #76 Minimum Window Substring, #438 Find All Anagrams.

## 3. Префиксные суммы ([Префиксные суммы](../Алгоритмы/Приёмы/Префиксные%20суммы.md))

**Когда:** много запросов «сумма на отрезке»; «число подмассивов с суммой = k».

```python
from collections import defaultdict

def subarray_sum_k(nums, k):
    count = prefix = 0
    seen = defaultdict(int)
    seen[0] = 1                     # пустой префикс
    for x in nums:
        prefix += x
        count += seen[prefix - k]   # сколько префиксов дают нужную разницу
        seen[prefix] += 1
    return count
```
**Сложность:** time `O(n)`, space `O(n)`.
**Где:** #560 Subarray Sum Equals K, #303 Range Sum Query.

## 4. Бинарный поиск (Алгоритмы поиска)

**Когда:** отсортированный массив; или «минимальное/максимальное X, при котором условие выполняется» (бинпоиск по ответу). Инвариант: ответ всегда в `[lo, hi]`.

**Классический (найти значение):**
```python
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

**Бинпоиск по ответу (первый True в монотонном False…False True…True):**
```python
def first_true(lo, hi, ok):
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid            # ответ здесь или левее
        else:
            lo = mid + 1        # ответ строго правее
    return lo
```
Готовое — модуль [bisect](../Библиотеки/Модули/Коллекции%20и%20структуры%20данных/bisect.md) (`bisect_left`/`bisect_right`).
**Сложность:** time `O(log n)`.
**Где:** #704 Binary Search, #35 Search Insert, #33 Rotated Sorted, #278 First Bad Version, #875 Koko Eating Bananas (по ответу).

## 5. Хеш-таблица ([Хеш-таблица](../Данные/Структуры%20данных/Хеш-таблица.md), [Словарь](../Данные/АТД/Словарь.md))

**Когда:** быстрый поиск «видели ли», подсчёт частот, группировка. `in` за `O(1)` вместо `O(n)`.

```python
from collections import Counter, defaultdict

# 1) видели ли дополнение (Two Sum):
def two_sum(nums, target):
    seen = {}                       # значение -> индекс
    for i, x in enumerate(nums):
        if target - x in seen:
            return seen[target - x], i
        seen[x] = i

# 2) частоты:
freq = Counter(nums)
top_k = [x for x, _ in freq.most_common(k)]

# 3) группировка по ключу (анаграммы):
groups = defaultdict(list)
for w in words:
    groups[tuple(sorted(w))].append(w)
```
**Где:** #1 Two Sum, #242 Valid Anagram, #49 Group Anagrams, #347 Top K Frequent.
Опора: модуль [collections](../Библиотеки/Модули/Коллекции%20и%20структуры%20данных/collections.md).

## 6. Стек и монотонный стек ([Стек](../Данные/АТД/Стек.md), [Монотонный стек](../Алгоритмы/Приёмы/Монотонный%20стек.md))

**Когда:** скобки/вложенность; «следующий больший элемент» (монотонный стек).

**Скобки:**
```python
def valid_parens(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
        else:
            stack.append(ch)
    return not stack
```

**Монотонный стек (next greater / Daily Temperatures):**
```python
def daily_temperatures(t):
    res = [0] * len(t)
    stack = []                      # индексы, температуры убывают
    for i, cur in enumerate(t):
        while stack and t[stack[-1]] < cur:
            j = stack.pop()
            res[j] = i - j
        stack.append(i)
    return res
```
**Где:** #20 Valid Parentheses, #739 Daily Temperatures, #155 Min Stack, #496 Next Greater Element.

## 7. BFS ([Граф](../Данные/Структуры%20данных/Граф.md), [Очередь](../Данные/АТД/Очередь.md))

**Когда:** кратчайший путь в **невзвешенном** графе или по клеткам сетки; обход по слоям. Всегда `deque`, не список.

**По сетке (кратчайший путь):**
```python
from collections import deque

def bfs_grid(grid, start):
    rows, cols = len(grid), len(grid[0])
    dist = {start: 0}
    q = deque([start])
    while q:
        r, c = q.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if (0 <= nr < rows and 0 <= nc < cols
                    and (nr, nc) not in dist and grid[nr][nc] != '#'):
                dist[(nr, nc)] = dist[(r, c)] + 1
                q.append((nr, nc))
    return dist
```

**По графу (список смежности):**
```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    q = deque([start])
    while q:
        node = q.popleft()
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)      # помечаем при добавлении, не при снятии!
                q.append(nxt)
```
**Мультистарт (несколько источников сразу):**
```python
q = deque()
for r, c in sources:              # ВСЕ источники кладём до старта цикла
    q.append((r, c))
    dist[(r, c)] = 0              # у всех расстояние 0
# дальше цикл ровно тот же
```
Заменяет `k` отдельных обходов одним, сложность остаётся `O(V + E)`. ⚠️ Если источников много, а цель одна — дешевле запустить обычный BFS **от цели** и остановиться на первом встреченном источнике.

**Сложность:** time `O(V + E)`.
**Где:** #200 Number of Islands, #542 01 Matrix, #994 Rotting Oranges (мультистарт), #1091 Shortest Path in Binary Matrix, #127 Word Ladder. Свои: [Кратчайший путь (BFS)](../Алгоритмы/Задачки/Кратчайший%20путь%20%28BFS%29.md), [Ход конём](../Алгоритмы/Задачки/Ход%20конём.md), [Обход клетчатого поля](../Алгоритмы/Приёмы/Обход%20клетчатого%20поля.md).
**Почему BFS даёт кратчайший путь:** обходит вершины по возрастанию расстояния — первая встреча = минимальная.

## 8. DFS ([DFS](../Алгоритмы/Поиск/DFS.md))

**Когда:** обойти всё; связные компоненты; проверка пути; заливка. Рекурсия или стек.

**Рекурсивный:**
```python
def dfs(graph, node, visited):
    visited.add(node)
    for nxt in graph[node]:
        if nxt not in visited:
            dfs(graph, nxt, visited)
```

**Итеративный (если боишься лимита рекурсии — [sys](../Библиотеки/Модули/Система%20и%20окружение/sys.md) `setrecursionlimit`):**
```python
def dfs_iter(graph, start):
    visited = set()
    stack = [start]
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        stack.extend(nxt for nxt in graph[node] if nxt not in visited)
    return visited

# подсчёт «островов» заливкой:
def num_islands(grid):
    rows, cols = len(grid), len(grid[0])
    count = 0
    def sink(r, c):
        if 0 <= r < rows and 0 <= c < cols and grid[r][c] == '1':
            grid[r][c] = '0'
            for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                sink(r + dr, c + dc)
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                sink(r, c)
    return count
```
**Где:** #200 Number of Islands, #133 Clone Graph, #695 Max Area of Island, #547 Number of Provinces.

## 9. Топологическая сортировка (Kahn / BFS)

**Когда:** порядок при зависимостях; обнаружить цикл в ориентированном графе.

```python
from collections import deque

def topo_sort(n, edges):            # edges: (u, v) значит u должно идти до v
    graph = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        graph[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []   # [] = есть цикл
```
**Где:** #207 Course Schedule, #210 Course Schedule II.

## 10. Дейкстра ([Алгоритм Дейкстры](../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md), heapq)

**Когда:** кратчайший путь во **взвешенном** графе с неотрицательными рёбрами.

```python
import heapq

def dijkstra(graph, start, n):      # graph[u] = [(v, w), ...]
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]               # (расстояние, вершина)
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:             # устаревшая запись — пропустить
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```
**Сложность:** time `O(E log V)`.
**Где:** #743 Network Delay Time, #1631 Path With Minimum Effort, #787 Cheapest Flights.
**Про кортеж `(dist, node)`:** куча сортирует по первому элементу; устаревшие записи не удаляем, а отсеиваем проверкой `d > dist[u]`.

## 11. Рекурсия и backtracking ([Рекурсия](../Алгоритмы/Стратегии/Рекурсия.md), [Поиск с возвратом](../Алгоритмы/Стратегии/Поиск%20с%20возвратом.md))

**Когда:** перебрать все подмножества / перестановки / расстановки. Каркас: **выбор → вглубь → откат**.

**Подмножества:**
```python
def subsets(nums):
    res, path = [], []
    def backtrack(start):
        res.append(path[:])                 # фиксируем текущее
        for i in range(start, len(nums)):
            path.append(nums[i])            # выбор
            backtrack(i + 1)                # вглубь
            path.pop()                      # откат
    backtrack(0)
    return res
```

**Перестановки:**
```python
def permutations(nums):
    res, path = [], []
    used = [False] * len(nums)
    def backtrack():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True; path.append(nums[i])
            backtrack()
            path.pop(); used[i] = False
    backtrack()
    return res
```
**Сложность:** экспоненциальная (`O(2ⁿ)` подмножества, `O(n!)` перестановки) — это норма для перебора.
**Где:** #78 Subsets, #46 Permutations, #39 Combination Sum, #51 N-Queens.

## 12. Динамическое программирование ([Динамическое программирование](../Алгоритмы/Стратегии/Динамическое%20программирование.md))

**Когда:** оптимум/счёт с перекрывающимися подзадачами и оптимальной подструктурой. Два стиля — оба ниже.

**Сверху вниз (мемоизация, [functools](../Библиотеки/Модули/Функциональные%20инструменты/functools.md) `lru_cache`)** — пиши рекурсию, кэш добавь декоратором:
```python
from functools import lru_cache

def coin_change(coins, amount):
    @lru_cache(maxsize=None)
    def dp(rem):
        if rem == 0:
            return 0
        if rem < 0:
            return float('inf')
        return min((dp(rem - c) + 1 for c in coins), default=float('inf'))
    ans = dp(amount)
    return ans if ans != float('inf') else -1
```

**Снизу вверх (табуляция)** — заводим массив состояний, заполняем по порядку:
```python
def house_robber(nums):             # нельзя брать два соседних
    prev, cur = 0, 0
    for x in nums:
        prev, cur = cur, max(cur, prev + x)
    return cur

def climbing_stairs(n):
    a, b = 1, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
**Где:** #509 Fibonacci, #70 Climbing Stairs, #198 House Robber, #322 Coin Change, #300 LIS, #1143 LCS, #72 Edit Distance, #62 Unique Paths.
**Мемо vs табуляция:** мемоизация — «ленивая», считает только нужные состояния, короче писать; табуляция — без рекурсии, экономит стек.
⚠️ **Потолок мемоизации — ~1000 по глубине**, и `setrecursionlimit` его не поднимает, если кэш навешен `@lru_cache` (C-обёртка, Python 3.12+). Глубокое ДП пиши снизу вверх или кэшируй ручным `dict` ([Мемоизация](../Алгоритмы/Приёмы/Мемоизация.md)).

## 13. Обход дерева ([Дерево](../Данные/Структуры%20данных/Дерево.md))

**DFS-обходы (in/pre/post-order):**
```python
def inorder(node, res):             # левый → корень → правый (для BST = отсортированно)
    if not node:
        return
    inorder(node.left, res)
    res.append(node.val)
    inorder(node.right, res)
```
- **pre-order** (корень→левый→правый) — копирование/сериализация дерева.
- **post-order** (левый→правый→корень) — удаление, подсчёт высоты снизу вверх.

**Level order (BFS по слоям):**
```python
from collections import deque

def level_order(root):
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):     # ровно один слой
            node = q.popleft()
            level.append(node.val)
            if node.left:  q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res
```
**Где:** #104 Max Depth, #226 Invert Tree, #102 Level Order, #98 Validate BST.

## 14. Union-Find / DSU (система непересекающихся множеств)

**Когда:** динамическая связность, компоненты, обнаружение цикла в неориентированном графе. Со сжатием пути и рангом — почти `O(1)` на операцию.

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]   # сжатие пути
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False            # уже связаны (ребро замыкает цикл)
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True
```
**Где:** #547 Number of Provinces, #684 Redundant Connection, #200 (альтернатива DFS).

## 15. Циклическая сортировка ([Циклическая сортировка](../Алгоритмы/Приёмы/Циклическая%20сортировка.md))

**Когда:** числа взяты из диапазона `1..n` (или `0..n`), длина массива равна размеру диапазона, и просят $O(1)$ памяти. Значение само задаёт свой индекс.

```python
def cyclic_sort(nums):
    i = 0
    while i < len(nums):
        j = nums[i] - 1                          # место для nums[i]
        if nums[i] != nums[j]:                   # сравниваем ЗНАЧЕНИЯ, не позицию!
            nums[i], nums[j] = nums[j], nums[i]  # i не двигаем
        else:
            i += 1
    # после прохода: x != i + 1 → i+1 пропало, x — дубликат
    return [i + 1 for i, x in enumerate(nums) if x != i + 1]
```
**Сложность:** time `O(n)` (каждый обмен ставит число на место навсегда → обменов ≤ n−1), space `O(1)`.
**Где:** #448 Find All Disappeared, #442 Find All Duplicates, #268 Missing Number, #41 First Missing Positive, #645 Set Mismatch.
⚠️ Условие `nums[i] != i + 1` вместо `nums[i] != nums[j]` даёт **вечный цикл** на дубликатах.

## 16. Битовые приёмы ([Битовые приёмы](../Алгоритмы/Приёмы/Битовые%20приёмы.md))

**Когда:** «все парами, кроме одного»; двоичное представление; нужен $O(1)$ памяти вместо множества.

```python
# 1) XOR-самоуничтожение: x ^ x = 0, x ^ 0 = x
def single_number(nums):            # #136
    mask = 0
    for x in nums:
        mask ^= x
    return mask

# 2) пропавшее число через XOR индексов и значений (#268, не переполняется)
def missing_number(nums):
    acc = len(nums)
    for i, x in enumerate(nums):
        acc ^= i ^ x
    return acc

# 3) младший бит
n & 1                # чётность          n >> 1     # деление на 2
n & (n - 1)          # сбросить младшую единицу
n & -n               # выделить младшую единицу
n > 0 and n & (n - 1) == 0            # степень двойки (n > 0 обязательно!)

# 4) ДП по битам (#338)
memo[i] = memo[i >> 1] + (i & 1)
```
**Где:** #136 Single Number, #268 Missing Number, #338 Counting Bits, #191 Number of 1 Bits, #231 Power of Two.

## 17. Кадане — максимальный подмассив ([Алгоритм Кадане](../Алгоритмы/Приёмы/Алгоритм%20Кадане.md))

**Когда:** «максимальная сумма подряд идущих элементов»; «купить дешевле — продать дороже».

```python
def max_subarray(nums):             # #53
    best = cur = nums[0]            # НЕ 0 — иначе всё-отрицательный тест даст 0
    for x in nums[1:]:
        cur = max(cur + x, x)       # тащить хвост или начать заново
        best = max(best, cur)
    return best

def max_profit(prices):             # #121 — тот же Кадане на разностях цен
    lowest, best = prices[0], 0
    for p in prices:
        best = max(best, p - lowest)
        lowest = min(lowest, p)
    return best
```
**Сложность:** time `O(n)`, space `O(1)`.
**Где:** #53 Maximum Subarray, #121 Best Time to Buy and Sell Stock, #152 Maximum Product Subarray (там нужно хранить **и минимум**), #918 Circular Subarray.
