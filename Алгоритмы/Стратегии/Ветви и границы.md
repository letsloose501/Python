# Ветви и границы

**Ветви и границы** (branch and bound) — стратегия для задач **оптимизации** (найти минимум или максимум). Это умный полный перебор: дерево вариантов обходится как в [backtracking](../../Алгоритмы/Стратегии/Поиск%20с%20возвратом.md), но каждая ветвь оценивается **границей**, и если она заведомо хуже уже найденного решения — ветвь отбрасывается целиком, не разворачиваясь.

> **Аналогия:** ищешь самый дешёвый маршрут. Если у частично собранного маршрута цена уже выше лучшего найденного целиком — дальше его продолжать смысла нет, бросаешь.

---

### Две границы

- **Нижняя граница** ветви — минимально возможное значение, которого она может достичь.
- **Верхняя граница** — лучшее полное решение, найденное на данный момент (рекорд).

**Правило отсечения (для задачи минимума):** если нижняя граница ветви ≥ текущего рекорда — ветвь бесперспективна, отбрасываем.

Оценку границы получают **ослаблением** задачи — временно убирают часть ограничений (например, разрешают дробный предмет в рюкзаке), чтобы быстро посчитать оптимистичную оценку.

---

### Схема

```
ветвление: разбить на подзадачи (взять предмет / не взять)
для каждой ветви:
    посчитать границу (ослабленная оценка)
    если граница не лучше рекорда → отбросить (bound)
    иначе → углубиться (branch)
обновлять рекорд на полных решениях
```

Псевдокод отсечения для рюкзака 0/1:

```python
best = 0
def bound(взято, вес, остаток_предметов):
    # оптимистичная оценка: добираем дробно (ослабление)
    ...
def branch(i, вес, ценность):
    global best
    if вес > W:            # недопустимо
        return
    best = max(best, ценность)
    if bound(...) <= best: # ветвь не может побить рекорд
        return             # ← отсечение
    branch(i + 1, вес + w[i], ценность + v[i])   # взять предмет i
    branch(i + 1, вес,        ценность)          # не взять
```

---

### Отличие от backtracking

| |[Поиск с возвратом](../../Алгоритмы/Стратегии/Поиск%20с%20возвратом.md)|Ветви и границы|
|---|---|---|
|Задача|Найти **любые/все** допустимые решения|Найти **оптимальное** значение|
|Отсечение|По допустимости («ход возможен?»)|По **границе** («может ли побить рекорд?»)|

Backtracking проверяет «возможно ли», B&B — «стоит ли», используя числовую оценку.

---

### Когда применять

- Задачи **оптимизации** с большим пространством перебора: рюкзак 0/1, коммивояжёр (TSP), назначения.
- Есть дешёвый способ оценить границу через ослабление.
- Полный перебор велик, но границы отсекают большую его часть.
