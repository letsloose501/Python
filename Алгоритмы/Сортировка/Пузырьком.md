# Сортировка пузырьком

**Сортировка пузырьком** (Bubble Sort) — сравнивать соседние элементы и менять их местами, если они стоят не в том порядке. Повторять проходы, пока за весь проход не окажется ни одного обмена.

> **Аналогия:** пузырьки в воде — каждый «тяжёлый» элемент постепенно опускается вниз, каждый «лёгкий» всплывает наверх. После каждого прохода самый большой элемент гарантированно оказывается на своём месте в конце.

Самый простой для понимания алгоритм сортировки. Используется для обучения, в реальных задачах почти не применяется из-за скорости.

---

### Как работает

```
[5, 3, 1, 4, 2]

проход 1:
  5 > 3 → меняем → [3, 5, 1, 4, 2]
  5 > 1 → меняем → [3, 1, 5, 4, 2]
  5 > 4 → меняем → [3, 1, 4, 5, 2]
  5 > 2 → меняем → [3, 1, 4, 2, 5]  ← 5 на месте

проход 2:
  3 > 1 → меняем → [1, 3, 4, 2, 5]
  3 < 4 → ok
  4 > 2 → меняем → [1, 3, 2, 4, 5]  ← 4 на месте

проход 3:
  1 < 3 → ok
  3 > 2 → меняем → [1, 2, 3, 4, 5]  ← 3 на месте

проход 4:
  нет обменов → стоп
```

После каждого прохода крупнейший из оставшихся элементов «всплывает» на своё место. Можно не просматривать уже отсортированный хвост.

---

### Реализации

#### Базовая

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n - 1 - i):   # -i: хвост уже отсортирован
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

bubble_sort([5, 3, 1, 4, 2])   # → [1, 2, 3, 4, 5]
```

#### С ранней остановкой

Если за проход не было ни одного обмена — массив уже отсортирован. Лучший случай становится $O(n)$.

```python
def bubble_sort_optimized(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break       # массив уже отсортирован
    return arr

bubble_sort_optimized([1, 2, 3, 4, 5])   # → один проход, сразу стоп
```

#### Двунаправленная (шейкерная, коктейльная)

Ходит туда и обратно: вперёд всплывает максимум, назад тонет минимум. Быстрее обычной на почти отсортированных данных.

```python
def cocktail_sort(arr):
    left, right = 0, len(arr) - 1
    while left < right:
        # проход вперёд — максимум в конец
        for i in range(left, right):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]
        right -= 1
        # проход назад — минимум в начало
        for i in range(right, left, -1):
            if arr[i] < arr[i - 1]:
                arr[i], arr[i - 1] = arr[i - 1], arr[i]
        left += 1
    return arr

cocktail_sort([3, 1, 5, 2, 4])   # → [1, 2, 3, 4, 5]
```

#### Через класс с поддержкой ключа

```python
class BubbleSort:
    def __init__(self, reverse=False, key=None):
        self.reverse = reverse
        self.key = key or (lambda x: x)

    def sort(self, arr):
        arr = list(arr)
        n = len(arr)
        for i in range(n):
            swapped = False
            for j in range(n - 1 - i):
                a, b = self.key(arr[j]), self.key(arr[j + 1])
                нужен_обмен = a > b if not self.reverse else a < b
                if нужен_обмен:
                    arr[j], arr[j + 1] = arr[j + 1], arr[j]
                    swapped = True
            if not swapped:
                break
        return arr


sorter = BubbleSort(key=lambda x: x[1])   # сортировка по второму элементу пары
sorter.sort([(1, 3), (2, 1), (3, 2)])     # → [(2, 1), (3, 2), (1, 3)]

sorter = BubbleSort(reverse=True)
sorter.sort([3, 1, 4, 1, 5])              # → [5, 4, 3, 1, 1]
```

### Big O

|Случай|Сложность|Когда|
|---|---|---|
|Лучший|$O(n)$|Массив уже отсортирован (с флагом `swapped`)|
|Средний|$O(n^2)$|Произвольный порядок|
|Худший|$O(n^2)$|Массив отсортирован в обратном порядке|
|Память|$O(1)$|На месте, только переменная для обмена|

Без флага `swapped` лучший случай тоже $O(n^2)$ — проходы идут до конца в любом случае.

---

### Устойчивость

**Устойчивый** — равные элементы не меняют взаимный порядок. Пузырьковая сортировка устойчива: при `arr[j] > arr[j+1]` обмен не происходит если элементы равны, строгое неравенство сохраняет их порядок.

```python
данные = [("Аня", 2), ("Боря", 1), ("Вася", 2)]
BubbleSort(key=lambda x: x[1]).sort(данные)
# → [("Боря", 1), ("Аня", 2), ("Вася", 2)]
# Аня стоит перед Васей — исходный порядок сохранён
```

### Плюсы и минусы

**Плюсы:**

- Простейшая реализация — 5 строк
- $O(1)$ памяти — сортирует на месте
- Устойчивый алгоритм
- С флагом `swapped` определяет уже отсортированный массив за $O(n)$
- Хорошо работает на почти отсортированных данных

**Минусы:**

- $O(n^2)$ — катастрофически медленно на больших данных
- Много обменов — каждый элемент может перемещаться пошагово через весь массив
- Практически никогда не используется в реальных системах

---

### Применение

- Обучение — самый наглядный способ объяснить сортировку
- Почти отсортированные данные с редкими вставками (с флагом ранней остановки)
- Встроенная проверка «уже ли отсортировано» за $O(n)$
- Аппаратные ограничения где важна простота кода, а не скорость
