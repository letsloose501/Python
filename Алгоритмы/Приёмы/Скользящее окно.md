# Скользящее окно

**Скользящее окно** (sliding window) — техника, где по массиву или строке движется непрерывный отрезок `[left, right]` («окно»). При сдвиге пересчитывается только то, что **вошло** и **вышло** из окна, а не весь отрезок заново. Превращает $O(n^2)$ (перебор всех подотрезков) в $O(n)$.

> **Аналогия:** окно движущегося поезда. Пейзаж не пересматриваешь целиком на каждом метре — справа въезжает новый кусок, слева выезжает старый.

Частный случай двух указателей, идущих в одном направлении (см. [Два указателя](../../Алгоритмы/Приёмы/Два%20указателя.md#виды)). Для сумм на отрезке при отрицательных числах окно не годится — там нужны [Префиксные суммы](../../Алгоритмы/Приёмы/Префиксные%20суммы.md).

---

### Два вида окна

**Фиксированной ширины** `k` — окно всегда длины `k`, просто едет вправо: добавили правый элемент, убрали левый.

```
[2, 1, 5, 1, 3, 2]   k = 3
 └─────┘                окно 1: сумма 8
    └─────┘             окно 2: +1 −2 = 7
       └─────┘          окно 3: +3 −1 = 9  ← максимум
```

**Переменной ширины** — правая граница расширяет окно, левая сжимает его, пока нарушено условие. Ширина «дышит».

```
расширяем right, пока можно;
нарушилось условие → двигаем left, пока снова не станет можно.
```

### Реализации

#### Фиксированное окно — максимальная сумма подмассива длины k

```python
def max_sum_k(a, k):
    s = sum(a[:k])          # первое окно
    best = s
    for i in range(k, len(a)):
        s += a[i] - a[i - k]   # +вошедший  −вышедший
        best = max(best, s)
    return best

max_sum_k([2, 1, 5, 1, 3, 2], 3)   # → 9  (подмассив [5,1,3])
```

#### Переменное окно — самая длинная подстрока без повторов

Расширяем `right`; если символ уже в окне — сдвигаем `left` за его прошлую позицию.

```python
def longest_unique(s):
    last = {}                # символ → последний индекс
    left = best = 0
    for right, chair in enumerate(s):
        if chair in last and last[chair] >= left:
            left = last[chair] + 1     # выкидываем всё до дубликата
        last[chair] = right
        best = max(best, right - left + 1)
    return best

longest_unique("abcabcbb")   # → 3  ("abc")
longest_unique("bbbbb")      # → 1
```

#### Переменное окно — кратчайший подмассив с суммой ≥ target

Расширяем окно, а как только сумма достигла цели — жадно сжимаем слева, фиксируя минимальную длину.

```python
def min_subarray_len(target, nums):
    left = total = 0
    best = float("inf")
    for right, x in enumerate(nums):
        total += x
        while total >= target:               # окно годное — пробуем укоротить
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return best if best != float("inf") else 0

min_subarray_len(7, [2, 3, 1, 2, 4, 3])   # → 2  (подмассив [4,3])
```

#### Частотное окно — все анаграммы подстроки в строке

Окно фиксированной длины `len(p)`, сравниваем счётчики символов.

```python
from collections import Counter

def find_anagrams(s, p):
    need = Counter(p)
    window = Counter()
    k = len(p)
    res = []
    for i, ch in enumerate(s):
        window[ch] += 1
        if i >= k:               # выкидываем элемент, вышедший слева
            out = s[i - k]
            window[out] -= 1
            if window[out] == 0:
                del window[out]  # чтобы Counter'ы сравнивались корректно
        if window == need:
            res.append(i - k + 1)
    return res

find_anagrams("cbaebabacd", "abc")   # → [0, 6]
```

### Шаблон переменного окна

```python
left = 0
for right in range(len(a)):
    добавить a[right] в окно
    while окно нарушает условие:
        убрать a[left] из окна
        left += 1
    обновить ответ по окну [left..right]
```

### Big O

| | Наивно | Скользящее окно |
|---|---|---|
| Время | $O(n \cdot k)$ или $O(n^2)$ | $O(n)$ |
| Память | — | $O(1)$ или $O(\text{алфавит})$ |

Каждый индекс попадает в окно и покидает его максимум по разу → суммарно $O(n)$, хотя внутри есть вложенный `while`.

---

### Когда применять

- «Самая длинная / короткая **подстрока или подмассив** с условием».
- «Ровно / не более **K** различных символов», «без повторов».
- Фиксированная длина `k`: сумма/среднее/максимум окна.
- Сравнение частот (анаграммы, перестановка-подстрока).

**Важное ограничение:** окно работает, когда расширение и сжатие **монотонно** влияют на условие — обычно при неотрицательных величинах. Для сумм с отрицательными числами используй [Префиксные суммы](../../Алгоритмы/Приёмы/Префиксные%20суммы.md) + хеш.

---

### Плюсы и минусы

**Плюсы:**
- $O(n)$ вместо $O(n^2)$, $O(1)$ памяти для числовых окон.
- Один проход — удобно для потоков данных.

**Минусы:**
- Не универсально: нужна монотонность условия.
- Легко ошибиться, когда сжимать окно и как обновлять ответ (до или после сжатия).
- Для «максимум в окне» нужен не простой счётчик, а монотонный дек ([монотонная очередь](../../Алгоритмы/Приёмы/Монотонный%20стек.md)).
