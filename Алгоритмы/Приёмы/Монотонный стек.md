# Монотонный стек

**Монотонный стек** (monotonic stack) — обычный [Стек](../../Данные/АТД/Стек.md), в котором элементы всегда хранятся **упорядоченно** (по возрастанию или убыванию). Перед добавлением нового элемента из стека выталкиваются все, кто нарушает порядок. Позволяет находить «**следующий/предыдущий больший или меньший**» элемент для всего массива за $O(n)$.

> **Аналогия:** очередь по росту, где сзади видно только тех, кто выше впередистоящих. Когда подходит человек выше всех передних — те, кого он заслонил, больше не нужны, они «выталкиваются».

Заменяет двойной цикл $O(n^2)$ («для каждого ищем справа первый больший») на один проход. Часто хранит **индексы**, а не значения — чтобы считать расстояния.

---

### Как работает

Идём по массиву. Держим в стеке индексы так, чтобы соответствующие значения были монотонны. Когда приходит элемент, «ломающий» монотонность, — выталкиваем нарушителей: именно для них текущий элемент и есть искомый ответ (следующий больший/меньший).

```
next greater для [2, 1, 2, 4, 3], стек убывающих значений:

i=0 (2): стек пуст → push        стек=[2]
i=1 (1): 1<2, не ломает → push   стек=[2,1]
i=2 (2): 2>1 → для 1 ответ=2, pop; 2 не >2 → push   стек=[2,2]
i=3 (4): 4>2 → ответ=4 (дважды), pop, pop → push     стек=[4]
i=4 (3): 3<4 → push               стек=[4,3]
у оставшихся (4,3) большего справа нет → -1
```

**Правило выбора направления стека:**
- ищем **следующий больший** → стек **убывающих** значений (выталкиваем меньшие);
- ищем **следующий меньший** → стек **возрастающих** значений.

---

### Реализации

#### Следующий больший элемент (Next Greater Element)

```python
def next_greater(nums):
    res = [-1] * len(nums)
    stack = []                       # индексы; значения по стеку убывают
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x     # для вытолкнутого текущий x — первый больший
        stack.append(i)
    return res

next_greater([2, 1, 2, 4, 3])   # → [4, 2, 4, -1, -1]
```

#### Сколько дней до потепления (Daily Temperatures)

То же, но в ответ пишем **расстояние** (разность индексов) — вот зачем хранить индексы.

```python
def daily_temperatures(t):
    res = [0] * len(t)
    stack = []                       # индексы, температуры убывают
    for i, cur in enumerate(t):
        while stack and t[stack[-1]] < cur:
            j = stack.pop()
            res[j] = i - j
        stack.append(i)
    return res

daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73])
# → [1, 1, 4, 2, 1, 1, 0, 0]
```

#### Наибольший прямоугольник в гистограмме (классика, посложнее)

Стек **возрастающих** высот. Когда приходит столбец ниже вершины — вытолкнутый столбец не может тянуться дальше вправо, считаем его прямоугольник. Страж `0` в конце выталкивает всё.

```python
def largest_rectangle(heights):
    stack = []                       # индексы, высоты возрастают
    best = 0
    for i, h in enumerate(heights + [0]):     # +страж
        while stack and heights[stack[-1]] > h:
            top = stack.pop()
            left = stack[-1] if stack else -1  # граница слева
            width = i - left - 1               # ширина прямоугольника
            best = max(best, heights[top] * width)
        stack.append(i)
    return best

largest_rectangle([2, 1, 5, 6, 2, 3])   # → 10  (столбцы 5 и 6: 5×2)
```

Приписанный в конце `0` — **страж**: он ниже любого столбца, поэтому гарантированно вытолкнет из стека всё, что там осталось. Без него понадобился бы второй цикл, дословно повторяющий тело первого. Тот же приём в связных списках — [Фиктивный узел](../../Алгоритмы/Приёмы/Фиктивный%20узел.md).

### Big O

| | Наивно | Монотонный стек |
|---|---|---|
| Время | $O(n^2)$ | $O(n)$ |
| Память | $O(1)$ | $O(n)$ (стек) |

Ключ к $O(n)$: **каждый индекс кладётся в стек и выталкивается максимум по одному разу** — суммарно не более `2n` операций, несмотря на вложенный `while`.

---

### Когда применять

- «Следующий / предыдущий **больший** или **меньший**» элемент.
- «Сколько шагов до большего значения» (расстояния).
- Гистограммы, «вода в столбцах» (Trapping Rain Water).
- Диапазон, где текущий элемент — максимум/минимум (вклад элемента).
- Родственник — **монотонная очередь** (дек) для «максимума в скользящем окне» (см. [Скользящее окно](../../Алгоритмы/Приёмы/Скользящее%20окно.md)).

**Сигнал:** в задаче про массив требуется для каждого элемента «первый справа/слева, который …» — почти наверняка монотонный стек.

---

### Плюсы и минусы

**Плюсы:**
- Превращает $O(n^2)$ в $O(n)$ одним проходом.
- Простая реализация — обычный список как стек.
- Один шаблон закрывает целый класс задач «next/previous greater/smaller».

**Минусы:**
- Неочевидно с первого взгляда — легко перепутать направление монотонности.
- Нужно чётко решить: хранить индексы или значения, выталкивать по `<` или `<=` (влияет на обработку равных элементов).
- Работает только для задач с «односторонней» зависимостью соседей.
