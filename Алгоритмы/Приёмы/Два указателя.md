# Два указателя

**Два указателя** (Two Pointers) — техника обхода массива или строки с помощью двух индексов, которые двигаются по определённым правилам. Позволяет решать задачи за $O(n)$ вместо $O(n^2)$.

> **Аналогия:** ищешь пару слов в словаре, которые вместе дают нужную длину. Вместо перебора всех пар — один указатель с начала, другой с конца. Сумма велика — сдвинь правый, мала — сдвинь левый.

Сама по себе техника не является алгоритмом сортировки, но активно используется внутри сортировок (разбиение в quicksort, слияние в merge sort) и задачах на отсортированных массивах.

---

### Виды

**Противоположные концы** — один указатель с начала, другой с конца, движутся навстречу.

```
[1, 2, 3, 4, 5]
 ↑             ↑
left          right
```

**Скользящее окно** — оба указателя движутся в одном направлении, образуя окно переменной ширины.

```
[1, 2, 3, 4, 5]
 ↑  ↑
left right →→→
```

**Быстрый и медленный** (Floyd's) — один движется вдвое быстрее другого. Используется для обнаружения циклов и поиска середины.

```
[1, 2, 3, 4, 5]
 ↑
slow  fast →→ (вдвое быстрее)
```

### Применение в сортировке

#### Разбиение (partition) в быстрой сортировке

Два указателя `left` и `right` движутся навстречу, переставляя элементы относительно pivot. Это сердце quicksort.

```python
def partition_hoare(arr, low, high):
    pivot = arr[(low + high) // 2]
    left = low
    right = high
    while True:
        while arr[left] < pivot:    # двигаем left вправо пока элемент < pivot
            left += 1
        while arr[right] > pivot:   # двигаем right влево пока элемент > pivot
            right -= 1
        if left >= right:
            return right
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1

arr = [3, 1, 5, 2, 4]
boundary = partition_hoare(arr, 0, len(arr) - 1)
# элементы до boundary — меньше pivot, после — больше
```

#### Слияние (merge) в сортировке слиянием

Два указателя `i` и `j` идут по двум отсортированным половинам, берут меньший элемент.

```python
def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):   # два указателя
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

merge([1, 3, 5], [2, 4, 6])   # → [1, 2, 3, 4, 5, 6]
```

### Классические задачи

#### Сумма двух чисел (Two Sum) на отсортированном массиве

Найти пару элементов с заданной суммой. Наивно — $O(n^2)$, с двумя указателями — $O(n)$.

```python
def two_sum(arr, target):
    """arr должен быть отсортирован."""
    left, right = 0, len(arr) - 1
    while left < right:
        s = arr[left] + arr[right]
        if s == target:
            return (arr[left], arr[right])
        elif s < target:
            left += 1    # сумма мала → увеличить левый
        else:
            right -= 1   # сумма велика → уменьшить правый
    return None

two_sum([1, 2, 3, 4, 6], target=6)   # → (2, 4)
two_sum([1, 2, 3, 4, 6], target=10)  # → (4, 6)
```

#### Разворот массива на месте

```python
def reverse(arr):
    left, right = 0, len(arr) - 1
    while left < right:
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1
    return arr

reverse([1, 2, 3, 4, 5])   # → [5, 4, 3, 2, 1]
```

#### Проверка палиндрома

```python
def is_palindrome(s):
    left, right = 0, len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True

is_palindrome("abcba")   # → True
is_palindrome("шалаш")   # → True
is_palindrome("python")  # → False
```

#### Удаление дубликатов из отсортированного массива на месте

`slow` — граница уникальных. `fast` — сканирует весь массив.

```python
def remove_duplicates(arr):
    if not arr:
        return 0
    slow = 0
    for fast in range(1, len(arr)):
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1   # длина без дубликатов

arr = [1, 1, 2, 3, 3, 4]
k = remove_duplicates(arr)
print(arr[:k])   # → [1, 2, 3, 4]
```

#### Контейнер с наибольшим количеством воды

Максимальная площадь между двумя «стенками». Движем указатель с меньшей высотой — может найдём лучше.

```python
def max_water(heights):
    left, right = 0, len(heights) - 1
    max_area = 0
    while left < right:
        h = min(heights[left], heights[right])
        area = h * (right - left)
        max_area = max(max_area, area)
        if heights[left] < heights[right]:
            left += 1
        else:
            right -= 1
    return max_area

max_water([1, 8, 6, 2, 5, 4, 8, 3, 7])   # → 49
```

#### Скользящее окно — максимальная сумма подмассива длины k

```python
def max_sum_window(arr, k):
    window_sum = sum(arr[:k])
    max_sum = window_sum
    for i in range(k, len(arr)):
        window_sum += arr[i] - arr[i - k]   # добавить новый, убрать старый
        max_sum = max(max_sum, window_sum)
    return max_sum

max_sum_window([2, 1, 5, 1, 3, 2], k=3)   # → 9 (подмассив [5,1,3] или [2,1,5])
```

#### Наименьший подмассив с суммой ≥ target (окно переменной ширины)

```python
def min_subarray_len(arr, target):
    left = 0
    current_sum = 0
    min_len = float("inf")
    for right in range(len(arr)):
        current_sum += arr[right]
        while current_sum >= target:
            min_len = min(min_len, right - left + 1)
            current_sum -= arr[left]
            left += 1
    return min_len if min_len != float("inf") else 0

min_subarray_len([2, 3, 1, 2, 4, 3], target=7)   # → 2 (подмассив [4,3])
```

#### Обнаружение цикла в связном списке (алгоритм Флойда)

Быстрый указатель движется вдвое быстрее медленного. Если цикл есть — они встретятся.

```python
class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

# найти середину списка:
def find_middle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow   # slow указывает на середину
```

### Big O

|Задача|Наивно|Два указателя|
|---|---|---|
|Two Sum на отсортированном|$O(n^2)$|$O(n)$|
|Разворот массива|$O(n)$ / $O(n)$ памяти|$O(n)$ / $O(1)$ памяти|
|Удаление дубликатов|$O(n^2)$ (со сдвигами)|$O(n)$|
|Максимум воды|$O(n^2)$|$O(n)$|
|Скользящее окно суммы|$O(n \cdot k)$|$O(n)$|
|Обнаружение цикла|$O(n)$ памяти (множество)|$O(1)$ памяти|

Память — $O(1)$: только два индекса, никаких вспомогательных структур.

### Когда применять

Техника двух указателей работает когда:

- Массив (или строка) **отсортирован** — можно предсказывать направление движения
- Задача связана с **парами, тройками** элементов
- Нужно найти **подмассив или подстроку** с определённым свойством
- Требуется $O(1)$ памяти вместо хеш-таблицы

```python
# сигнал: двойной цикл → подумай о двух указателях
for i in range(n):
    for j in range(i + 1, n):   # ← часто заменяется двумя указателями
        ...
```

### Плюсы и минусы

**Плюсы:**

- Превращает $O(n^2)$ в $O(n)$
- $O(1)$ памяти — только два индекса
- Простая идея, лёгкая реализация
- Применима к строкам, массивам, связным спискам

**Минусы:**

- Обычно требует **отсортированного** массива
- Не универсальна — подходит для конкретного класса задач
- Нужно правильно определить условие движения каждого указателя — логика бывает неочевидна

### Применение в реальных задачах

- Merge в merge sort и partition в quicksort — внутри алгоритмов сортировки
- Поиск пар/троек с заданной суммой (LeetCode: Two Sum II, 3Sum)
- Скользящее окно — анализ временных рядов, сетевые пакеты
- Валидация палиндромов — DNS, строки
- Удаление дубликатов на месте — обработка потоков данных
- Обнаружение циклов — связные списки, графы (Floyd's cycle detection)
