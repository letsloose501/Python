# Дерево

**Дерево** — иерархическая структура данных. Узлы связаны рёбрами, один узел — корень, нет циклов. Каждый узел имеет ровно одного родителя (кроме корня).

> **Аналогия:** файловая система. Корневая папка, в ней папки, в них файлы. Каждый файл имеет ровно один родительский путь.

---

## Термины

|Термин|Описание|
|---|---|
|**Узел**|Ячейка с данными|
|**Ребро**|Связь между узлами|
|**Корень**|Единственный узел без родителя|
|**Лист**|Узел без дочерних|
|**Высота**|Длина пути от корня до самого глубокого листа|
|**Глубина узла**|Длина пути от корня до узла|
|**Поддерево**|Узел и все его потомки|

```
          8          ← корень, глубина 0
        /   \
       3     10      ← глубина 1
      / \      \
     1   6      14   ← глубина 2
        / \
       4   7         ← листья, глубина 3,  высота дерева = 3
```

**Главное свойство:** нет циклов — при обходе не нужно отслеживать посещённые.

**Дерево — частный случай [графа](../../Данные/Структуры%20данных/Граф.md):** связный ациклический ненаправленный граф.

---

## Двоичное дерево поиска (BST)

Каждый узел — не более двух дочерних. **Свойство BST:**
- левое поддерево < узел
- правое поддерево > узел
- выполняется рекурсивно

На каждом шаге поиска отбрасывается половина дерева → $O(\log n)$.

### Сложность

|Операция|Сбалансированное|Вырожденное|
|---|---|---|
|Поиск|$O(\log n)$|$O(n)$|
|Вставка|$O(\log n)$|$O(n)$|
|Удаление|$O(\log n)$|$O(n)$|

**Вырождение:** вставка в отсортированном порядке (1,2,3...) → цепочка вправо → высота $n$ вместо $\log n$.

## Реализация BST

```python
class BSTNode:
    def __init__(self, key, value=None):
        self.key = key
        self.value = value
        self.left = None
        self.right = None


class BST:
    def __init__(self):
        self._root = None
        self._size = 0

    # --- вставка ---
    def insert(self, key, value=None):
        self._root = self._insert(self._root, key, value)

    def _insert(self, node, key, value):
        if node is None:
            self._size += 1
            return BSTNode(key, value)
        if key < node.key:
            node.left = self._insert(node.left, key, value)
        elif key > node.key:
            node.right = self._insert(node.right, key, value)
        else:
            node.value = value    # обновить
        return node

    # --- поиск ---
    def search(self, key):
        node = self._find(self._root, key)
        return node.value if node else None

    def _find(self, node, key):
        if node is None or node.key == key:
            return node
        if key < node.key:
            return self._find(node.left, key)
        return self._find(node.right, key)

    # --- удаление ---
    def delete(self, key):
        self._root, deleted = self._delete(self._root, key)
        if deleted:
            self._size -= 1

    def _delete(self, node, key):
        if node is None:
            return node, False
        deleted = False
        if key < node.key:
            node.left, deleted = self._delete(node.left, key)
        elif key > node.key:
            node.right, deleted = self._delete(node.right, key)
        else:
            deleted = True
            if node.left is None:
                return node.right, deleted
            if node.right is None:
                return node.left, deleted
            # два потомка — заменить минимумом из правого поддерева
            преемник = self._min(node.right)
            node.key = преемник.key
            node.value = преемник.value
            node.right, _ = self._delete(node.right, преемник.key)
        return node, deleted

    def _min(self, node):
        while node.left:
            node = node.left
        return node

    # --- обходы ---
    def inorder(self):     # лево → узел → право → отсортированный порядок
        result = []
        def _go(n):
            if n:
                _go(n.left); result.append(n.key); _go(n.right)
        _go(self._root)
        return result

    def preorder(self):    # узел → лево → право
        result = []
        def _go(n):
            if n:
                result.append(n.key); _go(n.left); _go(n.right)
        _go(self._root)
        return result

    def postorder(self):   # лево → право → узел
        result = []
        def _go(n):
            if n:
                _go(n.left); _go(n.right); result.append(n.key)
        _go(self._root)
        return result

    def level_order(self): # BFS — уровень за уровнем
        from collections import deque
        if not self._root:
            return []
        result, q = [], deque([self._root])
        while q:
            n = q.popleft()
            result.append(n.key)
            if n.left:  q.append(n.left)
            if n.right: q.append(n.right)
        return result

    # --- магические методы ---
    def __len__(self):
        return self._size

    def __contains__(self, key):
        return self._find(self._root, key) is not None

    def __getitem__(self, key):
        return self.search(key)

    def __setitem__(self, key, value):
        self.insert(key, value)

    def __iter__(self):        # inorder — отсортированный порядок
        yield from self.inorder()

    def __repr__(self):
        return f"BST({self.inorder()})"


bst = BST()
for x in [5, 3, 7, 1, 4, 6, 8]:
    bst.insert(x)

print(bst)                # → BST([1, 3, 4, 5, 6, 7, 8])
print(5 in bst)           # → True
print(bst.inorder())      # → [1, 3, 4, 5, 6, 7, 8]
print(bst.level_order())  # → [5, 3, 7, 1, 4, 6, 8]
bst.delete(3)
print(bst.inorder())      # → [1, 4, 5, 6, 7, 8]
```

## Обходы

```
        5
       / \
      3   7
     / \ / \
    1  4 6  8
```

|Обход|Порядок|Результат|Применение|
|---|---|---|---|
|**Inorder** (LNR)|лево→узел→право|`1 3 4 5 6 7 8`|Отсортированный вывод|
|**Preorder** (NLR)|узел→лево→право|`5 3 1 4 7 6 8`|Копирование, сериализация|
|**Postorder** (LRN)|лево→право→узел|`1 4 3 6 8 7 5`|Удаление дерева|
|**Level order**|уровень за уровнем|`5 3 7 1 4 6 8`|BFS, печать уровнями|

## Двоичная куча

Особый вид двоичного дерева. Хранится в **массиве** — без указателей.

**Свойство:** каждый узел ≤ (min-куча) или ≥ (max-куча) своих потомков.

```
min-куча:       1           массив: [1, 3, 5, 7, 4, 10]
              /   \
             3     5        узел i: левый = 2i+1, правый = 2i+2
            / \   /         родитель = (i-1)//2
           7   4 10
```

```python
import heapq

куча = []
heapq.heappush(куча, 5)
heapq.heappush(куча, 1)
heapq.heappush(куча, 3)

heapq.heappop(куча)    # → 1  (всегда минимум)

# из готового списка за O(n):
heapq.heapify([5, 1, 3, 7, 4])

# n наибольших/наименьших:
heapq.nlargest(3, [5, 1, 3, 7, 4])    # → [7, 5, 4]
heapq.nsmallest(3, [5, 1, 3, 7, 4])   # → [1, 3, 4]
```

Как АТД — [очередь с приоритетом](../../Данные/АТД/Очередь.md#очередь-с-приоритетом).

## Самобалансирующиеся деревья

Гарантируют высоту $O(\log n)$ при любом порядке вставок.

|Тип|Стратегия|Применение|
|---|---|---|
|**АВЛ**|Коэффициент балансировки ±1, повороты при нарушении|Частые чтения|
|**Красно-чёрное**|Узлы окрашены в 2 цвета, правила перекраски|`dict`/`set` в Java, C++ `std::map`|
|**B-дерево**|Много ключей в узле, широкое ветвление|Базы данных, файловые системы — см. B+-дерево|
|**Splay**|Найденный узел → корень|Кэши с повторными запросами|

Python не имеет встроенных сбалансированных деревьев. Для отсортированного словаря — `sortedcontainers.SortedDict` (PyPI).

> Балансировку можно не поддерживать вовсе, а получить $O(\log n)$ случайностью — так работает [Список с пропусками](../../Данные/Структуры%20данных/Список%20с%20пропусками.md): те же гарантии в среднем, но без поворотов и потому проще для конкурентного доступа.

## Дерево vs другие структуры

| |[Массив](../../Данные/Структуры%20данных/Массив.md) (сорт.)|[Связный список](../../Данные/Структуры%20данных/Связный%20и%20двусвязный%20список.md)|BST (сбал.)|[Хеш-таблица](../../Данные/Структуры%20данных/Хеш-таблица.md)|
|---|---|---|---|---|
|Поиск|$O(\log n)$|$O(n)$|$O(\log n)$|$O(1)$|
|Вставка|$O(n)$|$O(1)$|$O(\log n)$|$O(1)$|
|Удаление|$O(n)$|$O(1)$|$O(\log n)$|$O(1)$|
|Порядок|Да|Да|Да (inorder)|Нет|
|Диапазонный поиск|$O(\log n + k)$|$O(n)$|$O(\log n + k)$|Нет|

BST — когда нужен **отсортированный порядок** и **диапазонные запросы**. Хеш-таблица — когда нужна только скорость без порядка.
