# Массив

**Массив** — базовая структура данных. Элементы хранятся **подряд** в памяти, каждый имеет числовой **индекс** начиная с нуля. Адрес любого элемента вычисляется за одну операцию.

> **Аналогия:** парковка с пронумерованными местами — называешь номер, сразу знаешь где машина.

Массив — физическая структура. АТД поверх него — [Список](../../Данные/АТД/Список.md), [Стек](../../Данные/АТД/Стек.md), [Кортеж](../../Данные/АТД/Множество%20и%20кортеж.md#атд-кортеж).

---

## Как хранится в памяти

```
Адреса:   1000  1004  1008  1012  1016
          ┌─────┬─────┬─────┬─────┬─────┐
Значения: │  A  │  B  │  C  │  D  │  E  │
          └─────┴─────┴─────┴─────┴─────┘
Индексы:    0     1     2     3     4
```

Адрес элемента `i`: `начало + i × размер_элемента`.

При `int` (4 байта): `lst[3]` → `1000 + 3×4 = 1012`. Именно поэтому доступ по индексу — $O(1)$ — вычисление, а не поиск.

Python `list` хранит не сами объекты, а **указатели** (8 байт каждый), поэтому может хранить элементы разных типов.

---

## Статический vs динамический

**Статический** — размер задаётся при создании и не меняется. Нет накладных расходов. Характерен для C/C++.

**Динамический** — при заполнении выделяется новый блок вдвое большего размера, все элементы копируются. Это $O(n)$, но происходит редко — амортизированная стоимость `append` остаётся $O(1)$.

```
size=4, capacity=4:  [A][B][C][D]
append(E) → новый блок capacity=8:
            [A][B][C][D][E][_][_][_]
```

Python `list` — динамический массив. Рост capacity: `0 → 4 → 8 → 16 → 25 → ...`

## Операции и сложность

|Операция|Сложность|Причина|
|---|---|---|
|`get(i)` / `set(i)`|$O(1)$|Прямое вычисление адреса|
|`append`|$O(1)$ аморт.|В конец — без сдвига|
|`insert(i, x)`|$O(n)$|Сдвиг всех элементов правее `i`|
|`delete(i)`|$O(n)$|Сдвиг всех элементов левее|
|`find(x)`|$O(n)$|Линейный перебор|

Вставка и удаление в середине:

```
Удалить B (индекс 1) из [A][B][C][D]:
→ [A][C][D][_]   ← сдвиг влево, O(n)

Вставить X на позицию 1 в [A][B][C]:
→ [A][_][B][C]   ← сдвиг вправо, затем записать X
```

## Реализация в Python

### Встроенный list

Полный разбор операций `list` — в [Составные типы данных Python](../../Данные/Составные%20типы%20данных%20Python.md#list--список).

```python
lst = [10, 20, 30, 40, 50]

lst[0]         # → 10   O(1)
lst[-1]        # → 50   O(1) — отрицательный индекс: с конца
lst[1:4]       # → [20, 30, 40]   срез — новый список O(k)
lst[::-1]      # → [50, 40, 30, 20, 10]   разворот

lst.append(60)     # O(1) амортизировано
lst.insert(1, 15)  # O(n) — сдвиг
lst.pop()          # O(1) — с конца
lst.pop(0)         # O(n) — с начала (сдвиг!)
```

### Класс с явным управлением capacity

```python
class Array:
    def __init__(self, capacity=4):
        self._data = [None] * capacity
        self._size = 0
        self._capacity = capacity

    def append(self, x):
        if self._size == self._capacity:
            self._resize()
        self._data[self._size] = x
        self._size += 1

    def insert(self, i, x):
        if self._size == self._capacity:
            self._resize()
        for j in range(self._size, i, -1):   # сдвиг вправо
            self._data[j] = self._data[j - 1]
        self._data[i] = x
        self._size += 1

    def delete(self, i):
        значение = self._data[i]
        for j in range(i, self._size - 1):   # сдвиг влево
            self._data[j] = self._data[j + 1]
        self._data[self._size - 1] = None
        self._size -= 1
        return значение

    def _resize(self):
        self._capacity *= 2
        новый = [None] * self._capacity
        for i in range(self._size):
            новый[i] = self._data[i]
        self._data = новый

    def __len__(self):           # len(arr)
        return self._size

    def __getitem__(self, i):    # arr[i]
        if not (0 <= i < self._size):
            raise IndexError(i)
        return self._data[i]

    def __setitem__(self, i, x): # arr[i] = x
        if not (0 <= i < self._size):
            raise IndexError(i)
        self._data[i] = x

    def __delitem__(self, i):    # del arr[i]
        self.delete(i)

    def __iter__(self):          # for x in arr
        for i in range(self._size):
            yield self._data[i]

    def __contains__(self, x):  # x in arr
        return any(v == x for v in self)

    def __bool__(self):
        return self._size > 0

    def __repr__(self):
        return f"Array({list(self)}, cap={self._capacity})"


arr = Array()
arr.append(10); arr.append(20); arr.append(30)
arr.insert(1, 15)
print(arr)         # → Array([10, 15, 20, 30], cap=4)
print(arr[2])      # → 20
del arr[0]
print(arr)         # → Array([15, 20, 30], cap=4)
```

## Многомерные массивы

```python
# ЛОВУШКА — все строки один объект:
матрица = [[0] * 3] * 3
матрица[0][0] = 9
print(матрица)    # → [[9,0,0],[9,0,0],[9,0,0]] — изменились все!

# ПРАВИЛЬНО — list comprehension создаёт независимые строки:
матрица = [[0] * 3 for _ in range(3)]
матрица[0][0] = 9
print(матрица)    # → [[9,0,0],[0,0,0],[0,0,0]]

# доступ:
матрица[1][2]     # строка 1, столбец 2

# транспонирование:
T = [[матрица[j][i] for j in range(3)] for i in range(3)]
```

## Типизированный массив

`array.array` — хранит сами значения (не указатели). Компактнее `list` для числовых данных.

```python
import array, sys

lst = list(range(1000))
arr = array.array('i', range(1000))   # 'i' = signed int

sys.getsizeof(lst)   # → ~8056 байт (указатели)
sys.getsizeof(arr)   # → ~4060 байт (int напрямую)
```

Для числовых вычислений — **NumPy**: ещё компактнее и векторные операции.
