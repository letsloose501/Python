# АТД Словарь

**Словарь** (Map, Associative Array) — АТД, хранящий пары **ключ → значение**. По ключу мгновенно получаешь связанное значение. Ключи уникальны.

> **Аналогия:** обычный словарь — слово (ключ) и его определение (значение). Знаешь слово — находишь определение сразу.

Физически реализуется через [хеш-таблицу](../../Данные/Структуры%20данных/Хеш-таблица.md) (`dict`) или сбалансированное дерево (`sortedcontainers.SortedDict`). Принцип работы хеш-таблицы, коллизии и хешируемость — в [Хеш-таблица](../../Данные/Структуры%20данных/Хеш-таблица.md).

О Python-типе `dict` с полным разбором методов — в [Составные типы данных Python](../../Данные/Составные%20типы%20данных%20Python.md#dict--словарь).

## Операции

| Операция                          | Описание            | Хеш-таблица   | Дерево      |
| --------------------------------- | ------------------- | ------------- | ----------- |
| `set(key, value)`                 | Добавить / обновить | $O(1)$ аморт. | $O(\log n)$ |
| `get(key)`                        | Получить по ключу   | $O(1)$ аморт. | $O(\log n)$ |
| `delete(key)`                     | Удалить пару        | $O(1)$ аморт. | $O(\log n)$ |
| `contains(key)`                   | Проверить ключ      | $O(1)$ аморт. | $O(\log n)$ |
| `keys()` / `values()` / `items()` | Перечислить         | $O(n)$        | $O(n)$      |

## Python dict — основные операции

```python
d = {}

# set
d["name"] = "Иван"
d["age"] = 25
d.update({"city": "Москва"})
d |= {"lang": "Python"}        # Python 3.9+

# get
d["name"]                      # → "Иван",  KeyError если нет
d.get("name")                  # → "Иван",  None если нет
d.get("missing", 0)            # → 0

# contains
"name" in d                    # → True,  O(1)

# delete
del d["age"]                   # KeyError если нет
d.pop("city")                  # → "Москва"
d.pop("xyz", None)             # → None, без ошибки

# setdefault
d.setdefault("tags", []).append("python")   # создать если нет

# перебор
for k in d:              print(k)
for k, v in d.items():   print(k, v)
for v in d.values():     print(v)

len(d)                         # → количество пар
```

## Реализация через класс

```python
class Dictionary:
    def __init__(self, items=None):
        self._data = dict(items) if items else {}

    def set(self, key, value):   self._data[key] = value
    def get(self, key, default=None): return self._data.get(key, default)
    def delete(self, key):       return self._data.pop(key)
    def contains(self, key):     return key in self._data

    def __setitem__(self, key, value):   self._data[key] = value
    def __getitem__(self, key):
        if key not in self._data: raise KeyError(key)
        return self._data[key]
    def __delitem__(self, key):          del self._data[key]
    def __contains__(self, key):         return key in self._data
    def __len__(self):                   return len(self._data)
    def __iter__(self):                  return iter(self._data)
    def __bool__(self):                  return bool(self._data)
    def __eq__(self, other):
        if isinstance(other, Dictionary): return self._data == other._data
        return self._data == other
    def __or__(self, other):             # d | other — слияние
        result = Dictionary(self._data)
        result._data.update(other._data if isinstance(other, Dictionary) else other)
        return result
    def __repr__(self):                  return f"Dictionary({self._data})"

    def keys(self):    return self._data.keys()
    def values(self):  return self._data.values()
    def items(self):   return self._data.items()


d = Dictionary()
d["name"] = "Иван"
d["age"] = 25
print(d)            # → Dictionary({'name': 'Иван', 'age': 25})
print(d["name"])    # → Иван
print("age" in d)   # → True
del d["age"]
d2 = Dictionary({"city": "Москва"})
print(d | d2)       # → Dictionary({'name': 'Иван', 'city': 'Москва'})
```

## Хешируемые ключи

Ключи словаря должны быть хешируемыми. Подробнее о механизме — в [Хеш-таблица](../../Данные/Структуры%20данных/Хеш-таблица.md#хешируемость).

```python
# допустимо:
d[42] = "int"
d["строка"] = "str"
d[(1, 2)] = "tuple"
d[frozenset({1, 2})] = "frozenset"

# недопустимо:
d[[1, 2]] = "?"    # TypeError: unhashable type: 'list'

# свой объект как ключ — нужен __hash__ и __eq__:
class Точка:
    def __init__(self, x, y): self.x, self.y = x, y
    def __eq__(self, other): return self.x == other.x and self.y == other.y
    def __hash__(self): return hash((self.x, self.y))

карта = {Точка(0, 0): "старт"}
карта[Точка(0, 0)]   # → "старт"
```

## Применения

### Подсчёт частот

```python
from collections import Counter

текст = "кот пёс кот кот пёс кролик"
c = Counter(текст.split())
# → Counter({'кот': 3, 'пёс': 2, 'кролик': 1})
c.most_common(2)   # → [('кот', 3), ('пёс', 2)]
```

### Мемоизация

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def фибоначчи(n):
    if n < 2: return n
    return фибоначчи(n-1) + фибоначчи(n-2)

фибоначчи(100)   # мгновенно
```

### Группировка

```python
from collections import defaultdict

данные = [("Иван","А"), ("Аня","Б"), ("Коля","А"), ("Маша","Б")]
группы = defaultdict(list)
for имя, группа in данные:
    группы[группа].append(имя)
# → {'А': ['Иван', 'Коля'], 'Б': ['Аня', 'Маша']}
```

### Граф как список смежности

```python
граф = {"A": ["B","C"], "B": ["D"], "C": ["D","E"], "D": [], "E": []}
граф.get("A", [])   # → ["B", "C"]
```

## defaultdict и Counter

```python
from collections import defaultdict, Counter

# defaultdict — автосоздаёт значение при отсутствии ключа:
dd = defaultdict(int)
dd["x"] += 1              # не нужно dd.get("x", 0) + 1

dd = defaultdict(list)
dd["key"].append(1)       # не нужно if "key" not in dd: dd["key"] = []

# Counter — счётчик с дополнительными операциями:
c = Counter([1, 2, 2, 3, 3, 3])
c[4]              # → 0 (не KeyError)
c + Counter([2, 3])   # сложение счётчиков
c.most_common(1)  # → [(3, 3)]
```
