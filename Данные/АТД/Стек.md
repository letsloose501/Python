# АТД Стек

**Стек** — АТД с доступом только к одному концу. Последний добавленный извлекается первым. Принцип **LIFO** — _Last In, First Out_.

> **Аналогия:** стопка тарелок — кладёшь сверху, берёшь тоже сверху.

Физически реализуется через [массив](../../Данные/Структуры%20данных/Массив.md) (Python `list`) или [связный список](../../Данные/Структуры%20данных/Связный%20и%20двусвязный%20список.md) (`deque`).

---

## Операции

|Операция|Описание|Сложность|
|---|---|---|
|`push(x)`|Положить элемент на вершину|$O(1)$|
|`pop()`|Снять и вернуть с вершины|$O(1)$|
|`peek()`|Посмотреть на вершину, не снимая|$O(1)$|
|`is_empty()`|Пустой ли стек|$O(1)$|
|`size()`|Количество элементов|$O(1)$|

`pop()` и `peek()` на пустом стеке — ошибка (underflow).

---

## Как работает

```
push(A)  push(B)  push(C)  pop()  pop()

 []  →  [A]  →  [A,B]  →  [A,B,C]  →  [A,B]  →  [A]
         ↑top      ↑top       ↑top       ↑top      ↑top
```

## Python — встроенные инструменты

```python
# list — стек из коробки
стек = []
стек.append(1)   # push — O(1)
стек.append(2)
стек.append(3)
стек[-1]         # peek — O(1)
стек.pop()       # pop  — O(1)

# deque — для больших данных (строго O(1), без амортизации)
from collections import deque
стек = deque()
стек.append(1)
стек.pop()
```

## Реализация через класс

```python
class Stack:
    def __init__(self):
        self._data = []

    def push(self, x):
        self._data.append(x)

    def pop(self):
        if self.is_empty():
            raise IndexError("pop из пустого стека")
        return self._data.pop()

    def peek(self):
        if self.is_empty():
            raise IndexError("peek на пустой стек")
        return self._data[-1]

    def is_empty(self):
        return not self._data

    def __len__(self):           # len(s)
        return len(self._data)

    def __bool__(self):          # if s:
        return bool(self._data)

    def __contains__(self, x):  # x in s
        return x in self._data

    def __iter__(self):          # for x in s — от вершины к основанию
        return reversed(self._data)

    def __repr__(self):
        return f"Stack({self._data})"


s = Stack()
s.push(1); s.push(2); s.push(3)
print(s)         # → Stack([1, 2, 3])
print(s.peek())  # → 3
print(s.pop())   # → 3
print(2 in s)    # → True
for x in s:
    print(x)     # → 2, 1
```

## Применения

### Проверка скобок

```python
def скобки_верны(s):
    стек = []
    пары = {")": "(", "]": "[", "}": "{"}
    for c in s:
        if c in "([{":
            стек.append(c)
        elif c in ")]}":
            if not стек or стек[-1] != пары[c]:
                return False
            стек.pop()
    return len(стек) == 0

скобки_верны("([]{})")  # → True
скобки_верны("([)]")    # → False
```

### Отмена действий (Ctrl+Z)

```python
история = []
текст = ""

def написать(буква):
    история.append(текст)   # сохранить состояние до изменения
    global текст
    текст += буква

def отменить():
    global текст
    if история:
        текст = история.pop()

написать("П"); написать("р"); написать("и")
print(текст)   # → "При"
отменить()
print(текст)   # → "Пр"
```

### Обход в глубину (DFS) итеративно

```python
def dfs(граф, старт):
    visited, stack = set(), [старт]
    while stack:
        v = stack.pop()
        if v not in visited:
            visited.add(v)
            print(v)
            for сосед in граф[v]:
                if сосед not in visited:
                    stack.append(сосед)
```

### Вычисление обратной польской записи

```python
def вычислить_ОПЗ(выражение):
    стек = []
    ops = {"+": lambda a,b: a+b, "-": lambda a,b: a-b,
           "*": lambda a,b: a*b, "/": lambda a,b: a/b}
    for токен in выражение.split():
        if токен in ops:
            b, a = стек.pop(), стек.pop()
            стек.append(ops[токен](a, b))
        else:
            стек.append(float(токен))
    return стек[0]

вычислить_ОПЗ("3 4 + 5 *")   # → 35.0   (3+4)*5
```

## Стек вызовов в Python

Каждый вызов функции кладёт фрейм на стек. Возврат — снимает.

```python
import inspect

def c():
    for frame in inspect.stack():
        print(frame.function)

def b(): c()
def a(): b()

a()
# → c → b → a → <module>
```

Слишком глубокая рекурсия: `RecursionError`. Лимит — `sys.getrecursionlimit()` (по умолчанию 1000).
