# АТД Список

**Список** — АТД для упорядоченной последовательности с доступом по позиции. В отличие от стека и очереди — доступ к любому элементу.

> **Аналогия:** нумерованный список задач — добавить в любое место, вычеркнуть любую, посмотреть под любым номером.

Физически реализуется через [массив](../../Данные/Структуры%20данных/Массив.md) (Python `list`) или [связный список](../../Данные/Структуры%20данных/Связный%20и%20двусвязный%20список.md). О выборе — в сравнительной таблице ниже.

О Python-типе `list` с полным разбором методов — в [Составные типы данных Python](../../Данные/Составные%20типы%20данных%20Python.md#list--список).

---

## Операции

|Операция|Описание|`list`|Связный список|
|---|---|---|---|
|`get(i)`|Получить по индексу|$O(1)$|$O(n)$|
|`set(i, x)`|Заменить по индексу|$O(1)$|$O(n)$|
|`insert(i, x)`|Вставить на позицию `i`|$O(n)$|$O(1)$*|
|`delete(i)`|Удалить по позиции|$O(n)$|$O(1)$*|
|`append(x)`|Добавить в конец|$O(1)$ аморт.|$O(1)$|
|`prepend(x)`|Добавить в начало|$O(n)$|$O(1)$|
|`find(x)`|Найти первое вхождение|$O(n)$|$O(n)$|

* при известном указателе; найти его — ещё $O(n)$.

---

## Python list — основные операции

```python
lst = []

lst.append(10)         # в конец — O(1)
lst.append(20)
lst.append(30)
lst.insert(1, 15)      # вставить — O(n)
# → [10, 15, 20, 30]

lst[0]                 # → 10   O(1)
lst[-1]                # → 30   O(1)
lst[1:3]               # → [15, 20]   срез O(k)

lst[0] = 99            # замена — O(1)
lst.pop()              # удалить последний — O(1)
lst.pop(0)             # удалить первый — O(n) (сдвиг!)
lst.remove(15)         # удалить по значению — O(n)

lst.index(20)          # индекс — O(n)
20 in lst              # → True — O(n)
```

## Реализация через класс

```python
class ArrayList:
    def __init__(self, items=None):
        self._data = list(items) if items else []

    def get(self, i):      return self._data[i]
    def set(self, i, x):   self._data[i] = x
    def insert(self, i, x): self._data.insert(i, x)
    def delete(self, i):   return self._data.pop(i)
    def append(self, x):   self._data.append(x)
    def find(self, x):
        try: return self._data.index(x)
        except ValueError: return -1

    def __len__(self):           return len(self._data)
    def __getitem__(self, i):    return self._data[i]
    def __setitem__(self, i, x): self._data[i] = x
    def __delitem__(self, i):    del self._data[i]
    def __contains__(self, x):  return x in self._data
    def __iter__(self):          return iter(self._data)
    def __reversed__(self):      return reversed(self._data)
    def __add__(self, other):    return ArrayList(self._data + list(other))
    def __mul__(self, n):        return ArrayList(self._data * n)
    def __eq__(self, other):
        if isinstance(other, ArrayList): return self._data == other._data
        return self._data == other
    def __bool__(self):          return bool(self._data)
    def __repr__(self):          return f"ArrayList({self._data})"


lst = ArrayList([1, 2, 3])
lst.append(4)
lst.insert(0, 0)
print(lst)               # → ArrayList([0, 1, 2, 3, 4])
print(lst[2])            # → 2
lst[0] = 99; del lst[0]
print(lst)               # → ArrayList([1, 2, 3, 4])
print(lst + ArrayList([5, 6]))   # → ArrayList([1, 2, 3, 4, 5, 6])
print(lst * 2)                   # → ArrayList([1, 2, 3, 4, 1, 2, 3, 4])
for x in reversed(lst): print(x) # → 4, 3, 2, 1
```

## Сортированный список

Элементы всегда упорядочены. `insert` находит позицию через бинарный поиск.

```python
import bisect

class SortedList:
    def __init__(self):
        self._data = []

    def insert(self, x):
        bisect.insort(self._data, x)   # O(log n) поиск + O(n) вставка

    def remove(self, x):
        i = bisect.bisect_left(self._data, x)
        if i < len(self._data) and self._data[i] == x:
            self._data.pop(i)
        else:
            raise ValueError(f"{x} не найден")

    def contains(self, x):             # O(log n) — бинарный поиск
        i = bisect.bisect_left(self._data, x)
        return i < len(self._data) and self._data[i] == x

    def __len__(self):      return len(self._data)
    def __iter__(self):     return iter(self._data)
    def __getitem__(self, i): return self._data[i]
    def __repr__(self):     return f"SortedList({self._data})"


sl = SortedList()
for x in [5, 2, 8, 1, 3]: sl.insert(x)
print(sl)               # → SortedList([1, 2, 3, 5, 8])
print(sl.contains(5))   # → True
sl.remove(2)
print(sl)               # → SortedList([1, 3, 5, 8])
```

## Массив vs Связный список

| |`list` (массив)|Связный список|
|---|---|---|
|Доступ по индексу|$O(1)$|$O(n)$|
|Вставка в начало|$O(n)$|$O(1)$|
|Вставка в конец|$O(1)$ аморт.|$O(1)$|
|Cache locality|Отличный|Плохой|
|Память|Компактная|+8 байт на указатель|

`list` — по умолчанию. `collections.deque` (двусвязный список) — при частых операциях с обоих концов.
