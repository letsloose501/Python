# АТД Очередь

**Очередь** — АТД с добавлением в конец и извлечением из начала. Принцип **FIFO** — _First In, First Out_.

> **Аналогия:** живая очередь в кассу. Кто пришёл первым — обслуживается первым.

Физически реализуется через [двусвязный список](../../Данные/Структуры%20данных/Связный%20и%20двусвязный%20список.md) — `collections.deque`. `list.pop(0)` — $O(n)$, для очереди не подходит.

---

## Операции

|Операция|Описание|Сложность|
|---|---|---|
|`enqueue(x)`|Добавить в конец|$O(1)$|
|`dequeue()`|Извлечь из начала|$O(1)$|
|`peek()`|Посмотреть на первый|$O(1)$|
|`is_empty()`|Пустая ли очередь|$O(1)$|
|`size()`|Количество элементов|$O(1)$|

---

## Python — встроенные инструменты

```python
from collections import deque

q = deque()
q.append(1)      # enqueue — O(1)
q.append(2)
q.append(3)
q[0]             # peek — O(1)
q.popleft()      # dequeue — O(1) → 1

# потокобезопасная очередь:
from queue import Queue
q = Queue()
q.put(x)         # enqueue — блокируется если полна
q.get()          # dequeue — блокируется если пуста
```

---

## Реализация через класс

```python
from collections import deque

class Queue:
    def __init__(self):
        self._data = deque()

    def enqueue(self, x):
        self._data.append(x)

    def dequeue(self):
        if self.is_empty():
            raise IndexError("dequeue из пустой очереди")
        return self._data.popleft()

    def peek(self):
        if self.is_empty():
            raise IndexError("peek на пустую очередь")
        return self._data[0]

    def is_empty(self):
        return not self._data

    def __len__(self):
        return len(self._data)

    def __bool__(self):
        return bool(self._data)

    def __contains__(self, x):
        return x in self._data

    def __iter__(self):          # for x in q — от front к rear
        return iter(self._data)

    def __repr__(self):
        return f"Queue({list(self._data)})"


q = Queue()
q.enqueue("A"); q.enqueue("B"); q.enqueue("C")
print(q)           # → Queue(['A', 'B', 'C'])
print(q.peek())    # → 'A'
print(q.dequeue()) # → 'A'
print(q)           # → Queue(['B', 'C'])
```

## Очередь с приоритетом

Каждый элемент имеет числовой приоритет. При `dequeue` извлекается элемент с **наименьшим** числом приоритета.

Реализуется через **двоичную кучу** — подробнее о структуре в [Дерево](../../Данные/Структуры%20данных/Дерево.md#двоичная-куча).

```python
import heapq

class PriorityQueue:
    def __init__(self):
        self._heap = []
        self._index = 0    # стабильная сортировка при равных приоритетах

    def enqueue(self, item, priority):
        heapq.heappush(self._heap, (priority, self._index, item))
        self._index += 1

    def dequeue(self):
        if not self._heap:
            raise IndexError("dequeue из пустой очереди")
        _, _, item = heapq.heappop(self._heap)
        return item

    def peek(self):
        if not self._heap:
            raise IndexError("peek на пустую очередь")
        return self._heap[0][2]

    def __len__(self):
        return len(self._heap)

    def __bool__(self):
        return bool(self._heap)

    def __repr__(self):
        return f"PriorityQueue({[(p, item) for p, _, item in self._heap]})"


pq = PriorityQueue()
pq.enqueue("задача C", 3)
pq.enqueue("задача A", 1)
pq.enqueue("задача B", 2)

pq.dequeue()   # → "задача A"  (priority=1)
pq.dequeue()   # → "задача B"
```

Встроенный вариант с потокобезопасностью — `queue.PriorityQueue`.

## Применения очереди

### BFS — обход в ширину

```python
from collections import deque

def bfs(граф, старт):
    visited = {старт}
    q = deque([старт])
    while q:
        v = q.popleft()
        print(v)
        for n in граф[v]:
            if n not in visited:
                visited.add(n)
                q.append(n)

граф = {"A": ["B","C"], "B": ["D","E"], "C": [], "D": [], "E": []}
bfs(граф, "A")   # → A B C D E
```

# АТД Дека

**Дека** (_deque_ — double-ended queue) — АТД, в котором добавление и извлечение возможны с **обоих концов**. Обобщение стека и очереди.

> **Аналогия:** колода карт — можно брать и класть как сверху, так и снизу.

Физически — [двусвязный список](../../Данные/Структуры%20данных/Связный%20и%20двусвязный%20список.md). В Python — `collections.deque`.

---

## Операции

|Операция|Описание|Сложность|
|---|---|---|
|`push_front(x)`|Добавить в начало|$O(1)$|
|`push_back(x)`|Добавить в конец|$O(1)$|
|`pop_front()`|Извлечь из начала|$O(1)$|
|`pop_back()`|Извлечь из конца|$O(1)$|
|`peek_front()`|Посмотреть на первый|$O(1)$|
|`peek_back()`|Посмотреть на последний|$O(1)$|

---

## Дека как стек и очередь

|Поведение|push|pop|
|---|---|---|
|**Стек** (LIFO)|`push_back`|`pop_back`|
|**Очередь** (FIFO)|`push_back`|`pop_front`|

### Очередь на двух стеках — что просят реализовать

У дека два физических исполнения: **двусвязный список** (так сделан `collections.deque`) и **два стека**. Второе выглядит фокусом, но именно его просят написать на секции — [Implement Queue using Stacks #232](https://leetcode.com/problems/implement-queue-using-stacks/).

Идея: один стек на вход, другой на выход. Забирать элемент нужно с «дальнего» конца — значит содержимое переливают из входного в выходной, и порядок при переливании разворачивается.

```python
class ОчередьНаСтеках:
    def __init__(self):
        self._вход = []                  # сюда кладём
        self._выход = []                 # отсюда берём (порядок уже развёрнут)

    def push(self, x):
        self._вход.append(x)             # O(1)

    def pop(self):
        if not self._выход:              # переливаем ТОЛЬКО когда выход пуст
            while self._вход:
                self._выход.append(self._вход.pop())
        return self._выход.pop()
```

> **Почему это $O(1)$ амортизированно, а не $O(n)$.** Переливание выглядит дорогим, но каждый элемент переезжает из входного стека в выходной **ровно один раз за свою жизнь**: $n$ операций дают $2n$ перемещений, то есть в среднем константу на операцию. Ключ — условие `if not self._выход`: переливать при каждом `pop` (а не только при пустом выходе) как раз и даёт $O(n)$. Это учебный пример амортизированного анализа, и разбирают его теми же словами, что рост `list.append`.

Тот же приём с двумя стеками даёт **очередь с минимумом**: рядом с каждым элементом хранят минимум своего стека, и минимум всей очереди — меньший из двух вершин. Родственник — «стек рекордов» [Min Stack #155](https://leetcode.com/problems/min-stack/).

## Python — collections.deque

```python
from collections import deque

d = deque()
d.append(1)        # push_back
d.append(2)
d.appendleft(0)    # push_front  → deque([0, 1, 2])
d[0]               # peek_front  → 0
d[-1]              # peek_back   → 2
d.popleft()        # pop_front   → 0
d.pop()            # pop_back    → 2

# maxlen — вытесняет элементы с противоположного конца:
буфер = deque(maxlen=3)
for i in range(5):
    буфер.append(i)
print(буфер)       # → deque([2, 3, 4])
```

`maxlen` — для хранения последних N элементов: логи, история.

## Реализация через класс

```python
from collections import deque

class Deque:
    def __init__(self, maxlen=None):
        self._data = deque(maxlen=maxlen)

    def push_front(self, x): self._data.appendleft(x)
    def push_back(self, x):  self._data.append(x)

    def pop_front(self):
        if not self._data: raise IndexError("пустая дека")
        return self._data.popleft()

    def pop_back(self):
        if not self._data: raise IndexError("пустая дека")
        return self._data.pop()

    def peek_front(self): return self._data[0]
    def peek_back(self):  return self._data[-1]

    def __len__(self):          return len(self._data)
    def __bool__(self):         return bool(self._data)
    def __contains__(self, x):  return x in self._data
    def __iter__(self):         return iter(self._data)
    def __getitem__(self, i):   return self._data[i]
    def __repr__(self):         return f"Deque({list(self._data)})"
```

## Применения деки

### Скользящее окно максимума — $O(n)$

Найти максимум в каждом окне размером `k`. Наивно — $O(n \cdot k)$. С декой — $O(n)$.

```python
from collections import deque

def максимумы_в_окне(nums, k):
    result = []
    дека = deque()   # индексы убывающих кандидатов

    for i, x in enumerate(nums):
        while дека and дека[0] < i - k + 1:
            дека.popleft()              # вышел из окна
        while дека and nums[дека[-1]] < x:
            дека.pop()                  # хуже текущего
        дека.append(i)
        if i >= k - 1:
            result.append(nums[дека[0]])
    return result

максимумы_в_окне([3, 1, 2, 5, 4, 2], k=3)   # → [3, 5, 5, 5]
```

### Палиндром

```python
from collections import deque

def палиндром(слово):
    d = deque(слово)
    while len(d) > 1:
        if d.popleft() != d.pop():
            return False
    return True

палиндром("шалаш")   # → True
```
