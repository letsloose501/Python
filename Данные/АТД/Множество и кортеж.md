# АТД Множество

**Множество** (Set) — АТД для неупорядоченной коллекции **уникальных** элементов. Дубли отбрасываются автоматически. Поддерживает операции теории множеств.

> **Аналогия:** список гостей — один человек не может быть приглашён дважды. Порядок не важен — важно только присутствие.

Физически реализуется через [хеш-таблицу](../../Данные/Структуры%20данных/Хеш-таблица.md) (`set`) — только ключи, без значений. Принцип работы, хешируемость — в [Хеш-таблица](../../Данные/Структуры%20данных/Хеш-таблица.md).

О Python-типе `set` с полным разбором методов — в [Составные типы данных Python](../../Данные/Составные%20типы%20данных%20Python.md#set--множество).

---

## Операции

|Операция|Описание|Сложность|
|---|---|---|
|`add(x)`|Добавить (игнорируется если есть)|$O(1)$ аморт.|
|`remove(x)`|Удалить|$O(1)$ аморт.|
|`contains(x)`|Проверить наличие|$O(1)$ аморт.|
|`union(B)`|A ∪ B|$O(n+m)$|
|`intersection(B)`|A ∩ B|$O(\min(n,m))$|
|`difference(B)`|A \ B|$O(n)$|

---

## Теория множеств

```
A = {1, 2, 3, 4}    B = {3, 4, 5, 6}

A ∪ B  объединение:          {1, 2, 3, 4, 5, 6}
A ∩ B  пересечение:          {3, 4}
A \ B  разность:             {1, 2}
A △ B  симметр. разность:    {1, 2, 5, 6}
```

---

## Python set — операции

```python
s = set()
s.add(1); s.add(2); s.add(1)   # → {1, 2}  дубль игнорируется
1 in s              # → True,  O(1)
s.remove(1)         # KeyError если нет
s.discard(99)       # без ошибки

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a | b               # объединение
a & b               # пересечение
a - b               # разность
a ^ b               # симм. разность

a |= b; a &= b; a -= b; a ^= b   # обновление на месте

{1, 2}.issubset({1, 2, 3})        # → True
{1, 2, 3}.issuperset({1, 2})      # → True
{1, 2}.isdisjoint({3, 4})         # → True  (нет общих)
```

## Реализация через класс

```python
class Set:
    def __init__(self, items=None):
        self._data = set(items) if items else set()

    def add(self, x):    self._data.add(x)
    def remove(self, x):
        if x not in self._data: raise KeyError(x)
        self._data.remove(x)
    def discard(self, x): self._data.discard(x)

    def __contains__(self, x):   return x in self._data
    def __len__(self):           return len(self._data)
    def __iter__(self):          return iter(self._data)
    def __bool__(self):          return bool(self._data)

    def __or__(self, other):     return Set(self._data | other._data)
    def __and__(self, other):    return Set(self._data & other._data)
    def __sub__(self, other):    return Set(self._data - other._data)
    def __xor__(self, other):    return Set(self._data ^ other._data)
    def __le__(self, other):     return self._data <= other._data   # ⊆
    def __ge__(self, other):     return self._data >= other._data   # ⊇
    def __eq__(self, other):
        if isinstance(other, Set): return self._data == other._data
        return self._data == other
    def __repr__(self):          return f"Set({self._data})"


a = Set([1, 2, 3, 4])
b = Set([3, 4, 5, 6])
print(a | b)           # → Set({1, 2, 3, 4, 5, 6})
print(a & b)           # → Set({3, 4})
print(a - b)           # → Set({1, 2})
print(Set([1, 2]) <= a)  # → True
```

## frozenset — неизменяемое множество

Нельзя добавлять/удалять. Зато **хешируемо** — можно как ключ словаря или элемент множества.

```python
fs = frozenset({1, 2, 3})
hash(fs)               # работает
d = {fs: "значение"}   # как ключ — работает
{fs, frozenset({4, 5})}  # как элемент set — работает

# поддерживает операции чтения и теории множеств:
1 in fs                # → True
fs | frozenset({4})    # → frozenset({1, 2, 3, 4})
```

---

## Применения

### Быстрая проверка принадлежности

```python
ДОПУСТИМЫЕ = frozenset({"admin", "user", "moderator"})
"admin" in ДОПУСТИМЫЕ   # O(1) vs O(n) у list
```

### Дедупликация с сохранением порядка

```python
lst = [1, 2, 3, 2, 1, 4]
seen = set()
уникальные = [x for x in lst if not (x in seen or seen.add(x))]
# → [1, 2, 3, 4]
```

### Общие/уникальные элементы

```python
янв = {"Иван", "Аня", "Коля"}
фев = {"Аня", "Маша", "Коля"}

янв & фев           # оба месяца: {'Аня', 'Коля'}
янв - фев           # только январь: {'Иван'}
фев - янв           # новые в феврале: {'Маша'}
```

### Есть ли дубликаты (#217 Contains Duplicate)

Классическая разминочная задача — и хороший пример того, что короче не всегда лучше:

```python
def contains_duplicate(nums):            # 1. короткое
    return len(set(nums)) != len(nums)

def contains_duplicate_early(nums):      # 2. с ранним выходом
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False
```

Обе версии — $O(n)$ по времени и $O(n)$ по памяти. Но первая **всегда** проходит массив целиком и строит множество из всех элементов, а вторая обрывается на первом же повторе: если дубликат стоит вторым, она сделает два шага вместо миллиона. На собеседовании стоит написать первую и вслух назвать вторую — это ровно тот разбор «а что если ответ найдётся рано», который ждут.

> Если дополнительная память запрещена, а числа лежат в диапазоне `1..n` — множество не нужно вовсе: работает [циклическая сортировка](../../Алгоритмы/Приёмы/Циклическая%20сортировка.md) за $O(1)$ памяти. Без такого ограничения на диапазон дешевле множества ничего нет.

# АТД Кортеж

**Кортеж** (Tuple) — АТД для упорядоченной **неизменяемой** последовательности фиксированной длины. После создания нельзя добавить, удалить или заменить элементы.

> **Аналогия:** анкета с заполненными полями — имя, дата рождения, город. Поля фиксированы, данные не редактируются.

Физически — **массив фиксированной длины**. Каждый элемент — указатель (8 байт). Память выделяется один раз.

О Python-типе `tuple` — в [Составные типы данных Python](../../Данные/Составные%20типы%20данных%20Python.md#tuple--кортеж).

---

## Операции

|Операция|Описание|Сложность|
|---|---|---|
|`get(i)`|Получить по индексу|$O(1)$|
|`size()`|Количество элементов|$O(1)$|
|`contains(x)`|Проверить наличие|$O(n)$|
|`index(x)`|Индекс первого вхождения|$O(n)$|

Изменение — `set`, `add`, `remove` — **недоступно**.

---

## Неизменяемость → хешируемость

Неизменяемость даёт стабильный хеш → кортеж можно использовать как ключ словаря и элемент множества.

```python
d = {(0, 0): "старт", (1, 0): "вправо"}
d[(0, 0)]   # → "старт"

s = {(0, 0), (1, 0)}
```

> Если хотя бы один элемент изменяем — кортеж нехешируем, даже если сам неизменяем.

```python
t = (1, [2, 3])
hash(t)         # TypeError: unhashable type: 'list'
```

---

## Python tuple — основные операции

```python
t = (10, 20, 30, 20, 10)

t[0]         # → 10
t[-1]        # → 10
t[1:3]       # → (20, 30)   срез — новый кортеж
t.count(20)  # → 2
t.index(30)  # → 2
len(t)       # → 5

(1, 2) + (3, 4)   # → (1, 2, 3, 4)   конкатенация
(1, 2) * 3        # → (1, 2, 1, 2, 1, 2)
```

---

## Реализация через класс

```python
class Tuple:
    def __init__(self, *args):
        self._data = tuple(args)

    def get(self, i):    return self._data[i]
    def size(self):      return len(self._data)
    def index(self, x):  return self._data.index(x)

    def __getitem__(self, i):     return self._data[i]
    def __len__(self):            return len(self._data)
    def __contains__(self, x):   return x in self._data
    def __iter__(self):           return iter(self._data)
    def __hash__(self):           return hash(self._data)   # хешируем!
    def __eq__(self, other):
        if isinstance(other, Tuple): return self._data == other._data
        return self._data == other
    def __add__(self, other):
        other_data = other._data if isinstance(other, Tuple) else tuple(other)
        return Tuple(*self._data, *other_data)
    def __mul__(self, n):         return Tuple(*self._data * n)
    def __bool__(self):           return bool(self._data)
    def __repr__(self):           return f"Tuple{self._data}"


t = Tuple(1, 2, 3)
print(t)             # → Tuple(1, 2, 3)
print(t[1])          # → 2
print(hash(t))       # → число
d = {t: "значение"}
d[Tuple(1, 2, 3)]    # → "значение"
```

## Распаковка

```python
a, b, c = (1, 2, 3)       # базовая
a, b = b, a                # обмен без temp
_, важное, _ = (1, 42, 3)  # игнорировать

# расширенная:
первый, *остальные = (1, 2, 3, 4, 5)
# первый=1, остальные=[2, 3, 4, 5]

*начало, последний = (1, 2, 3, 4, 5)
# начало=[1, 2, 3, 4], последний=5

# вложенная:
a, (b, c) = (1, (2, 3))

# в цикле:
for число, буква in [(1,"a"),(2,"b")]:
    print(число, буква)
```

## Именованные кортежи

```python
from collections import namedtuple

Точка = namedtuple("Точка", ["x", "y"])
p = Точка(3, 4)
p.x    # → 3   по имени
p[0]   # → 3   по индексу — тоже работает
x, y = p   # распаковка

p._replace(x=10)   # новый кортеж с изменённым полем
p._asdict()        # → {'x': 3, 'y': 4}

# с аннотациями типов:
from typing import NamedTuple

class Пользователь(NamedTuple):
    имя: str
    возраст: int
    город: str = "Москва"   # дефолт

u = Пользователь("Иван", 25)
print(u)    # → Пользователь(имя='Иван', возраст=25, город='Москва')
hash(u)     # хешируемый
```

## Кортеж vs Список

| |Список|Кортеж|
|---|---|---|
|Изменяемость|Изменяемый|Неизменяемый|
|Хешируемость|Нет|Да (если элементы хешируемы)|
|Ключ словаря|Нет|Да|
|Семантика|Однородная коллекция|Запись с позициями|
|Память|Чуть больше|Чуть меньше|

**Список** — однородные изменяемые данные. **Кортеж** — фиксированная запись: `(x, y)`, `(id, имя, возраст)`.
