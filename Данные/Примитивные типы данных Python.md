## int — целое число

**Что это:** целое число без дробной части. В Python `int` не имеет ограничения по размеру — число растёт до тех пор, пока хватает памяти.

**Магические методы:** `__add__`, `__sub__`, `__mul__`, `__truediv__`, `__floordiv__`, `__mod__`, `__pow__`, `__neg__`, `__abs__`, `__eq__`, `__lt__` и др. — все [арифметические и сравнительные операторы](../Ядро%20языка/Операторы%20Python.md).

```python
x = 42
y = -7
z = 0
big = 2 ** 1000   # работает — нет переполнения

# разные системы счисления
bin_num = 0b1010    # двоичное → 10
oct_num = 0o17      # восьмеричное → 15
hex_num = 0xFF      # шестнадцатеричное → 255
```

> Подробно про основания, перевод и `int(s, base)` — в Системы счисления.

### Методы int

```python
n = 255

n.bit_length()          # → 8   — количество бит нужных для хранения числа
n.bit_count()           # → 8   — количество единичных бит (Python 3.10+)
n.to_bytes(2, 'big')    # → b'\x00\xff' — число в байты
int.from_bytes(b'\xff', 'big')  # → 255 — байты в число

# из числовой башни (int реализует интерфейс Rational):
(5).as_integer_ratio()  # → (5, 1)  — дробь p/q (Python 3.8+)
(5).is_integer()        # → True    — всегда True для int (Python 3.12+, для совместимости с float)
(5).numerator           # → 5       — числитель
(5).denominator         # → 1       — знаменатель (у int всегда 1)
(5).real, (5).imag      # → (5, 0)  — как у комплексного: реальная и мнимая часть
(5).conjugate()         # → 5       — сопряжённое (для int = само число)
```

### Встроенные функции для int

```python
abs(-5)         # → 5    — модуль числа
pow(2, 10)      # → 1024
pow(2, 10, 100) # → 24   — (2**10) % 100, быстрое возведение с остатком
bin(10)         # → '0b1010' — в двоичную строку
oct(8)          # → '0o10'  — в восьмеричную строку
hex(255)        # → '0xff'  — в шестнадцатеричную строку
int("42")       # → 42   — строку в число
int("ff", 16)   # → 255  — строку с указанием основания системы счисления
int(3.9)        # → 3    — float в int (усечение, не округление)
divmod(17, 5)   # → (3, 2) — возвращает частное и остаток от деления
```

### Плюсы

- Нет переполнения — `2 ** 1000` работает
- Поддерживает все системы счисления из коробки
- `//` и `%` работают предсказуемо для отрицательных чисел (floor, а не truncate)

### Минусы

- Большие числа медленнее — требуют дополнительных аллокаций
- Каждый `int` — объект в памяти (~28 байт против 4 байт в C)

### Практика

```python
# проверка чётности
def чётный(n):
    return n % 2 == 0

# цифры числа
def цифры(n):
    return [int(d) for d in str(abs(n))]

# быстрая степень двойки через сдвиг
1 << 10     # → 1024 (быстрее чем 2**10 в некоторых случаях)

# целочисленное деление с остатком сразу
quotient, remainder = divmod(17, 5)   # → (3, 2)
```

## float — число с плавающей точкой

**Что это:** вещественное число. Реализовано как 64-битный `double` из C (стандарт IEEE 754). Хранит около 15–17 значащих цифр.

**Магические методы:** те же что у `int` — `__add__`, `__sub__`, `__mul__`, `__truediv__`, `__eq__`, `__lt__` и т.д.

```python
x = 3.14
y = -0.001
z = 1.5e10    # научная нотация → 15000000000.0
w = 1.5e-3    # → 0.0015

# специальные значения
float('inf')   # → inf  — бесконечность
float('-inf')  # → -inf
float('nan')   # → nan  — Not a Number
```

> Арифметика с `inf`/`nan` (`inf - inf → nan`, `nan == nan → False`, проверки `math.isnan`/`isinf`/`isfinite`) — в [Специальные типы данных Python](../Данные/Специальные%20типы%20данных%20Python.md#специальные-значения-float).

### Главная ловушка float

```python
0.1 + 0.2           # → 0.30000000000000004
0.1 + 0.2 == 0.3    # → False!
```

Причина: `0.1` не представимо точно в двоичной системе (как `1/3` не представимо точно в десятичной). Это не баг Python — это IEEE 754.

```python
# правильное сравнение float:
import math
math.isclose(0.1 + 0.2, 0.3)           # → True
abs(0.1 + 0.2 - 0.3) < 1e-9            # → True

# для финансовых вычислений — decimal:
from decimal import Decimal
Decimal("0.1") + Decimal("0.2")         # → Decimal('0.3') — точно
```

### Методы float

```python
x = 3.7

x.is_integer()      # → False — целое ли число
(3.0).is_integer()  # → True
x.as_integer_ratio()  # → (8346268691193005, 2251799813685248)
                      # — точная дробь p/q равная числу
(0.5).as_integer_ratio()  # → (1, 2)

(3.5).hex()         # → "0x1.c000000000000p+1" — точное 16-ричное представление
float.fromhex("0x1.cp+1")  # → 3.5 — обратно из hex-строки
                    # hex/fromhex сохраняют float без потерь — для сериализации
```

### Встроенные функции для float

```python
round(3.14159, 2)   # → 3.14   — округление
round(2.5)          # → 2      — банковское округление (к чётному!)
round(3.5)          # → 4

import math
math.floor(3.7)     # → 3    — вниз
math.ceil(3.2)      # → 4    — вверх
math.trunc(3.9)     # → 3    — к нулю (то же что int())
math.sqrt(16)       # → 4.0
math.log(100, 10)   # → 2.0
math.pi             # → 3.141592653589793
math.e              # → 2.718281828459045
math.isnan(x)       # проверить nan
math.isinf(x)       # проверить бесконечность
math.isclose(a, b)  # безопасное сравнение float
```

### Плюсы

- Быстрый — реализован на уровне железа (FPU)
- Поддерживает `inf` и `nan` — удобно для численных алгоритмов

### Минусы

- Погрешности представления — `0.1 + 0.2 ≠ 0.3`
- Нельзя использовать для денег — только `decimal.Decimal`
- `nan != nan` — единственный объект в Python не равный самому себе; проверка через `math.isnan()`, а не `==`

### Практика

```python
# безопасное деление
def safe_div(a, b):
    return a / b if b != 0 else float('inf')

# округление до n знаков без банковского эффекта
import decimal
def round_half_up(x, n):
    d = decimal.Decimal(str(x))
    return float(d.quantize(decimal.Decimal(10) ** -n,
                            rounding=decimal.ROUND_HALF_UP))
```

## bool — логический тип

**Что это:** подкласс `int`. `True == 1` и `False == 0` — буквально. Все арифметические операции с `bool` работают через `int`.

**Магический метод:** `__bool__(self)` — определяет истинность объекта. Также влияет `__len__`: если `__bool__` не определён, Python смотрит `__len__`.

```python
True == 1       # → True
False == 0      # → True
isinstance(True, int)   # → True — bool — подкласс int

# арифметика с bool работает:
True + True     # → 2
True * 5        # → 5
sum([True, False, True, True])  # → 3 — считаем True как 1
```

### Правила истинности (truthy / falsy)

```python
# Ложные значения (falsy):
bool(False)     # → False
bool(0)         # → False
bool(0.0)       # → False
bool("")        # → False — пустая строка
bool([])        # → False — пустой список
bool({})        # → False — пустой словарь
bool(())        # → False — пустой кортеж
bool(set())     # → False — пустое множество
bool(None)      # → False

# Все остальные — истинные (truthy):
bool(1)         # → True
bool(-1)        # → True — ненулевое число
bool("0")       # → True — непустая строка
bool([0])       # → True — непустой список
```

### Встроенные функции для bool

```python
bool(значение)  # явное приведение к bool
all([True, True, False])   # → False — все ли истинны
any([False, False, True])  # → True  — хотя бы один истинен
all([])         # → True  (vacuous truth — пустая последовательность)
any([])         # → False
```

### Плюсы

- Является подклассом `int` — можно использовать в арифметике и `sum()`
- `all()` и `any()` — ленивые, останавливаются при первом решающем элементе

### Минусы

- `True + True = 2` удивляет новичков
- Легко спутать `is True` и ` == True`:

```python
x = 1
x == True       # → True  (1 == 1)
x is True       # → False (1 — не тот же объект что True)

# правильно:
if x:           # проверка истинности — не сравнивать с True
    ...
```

### Практика

```python
# подсчёт элементов удовлетворяющих условию:
данные = [1, -2, 3, -4, 5]
count_positive = sum(x > 0 for x in данные)   # → 3

# ранняя остановка:
if any(x < 0 for x in данные):
    print("Есть отрицательные")

if all(x > 0 for x in данные):
    print("Все положительные")
```

## str — строка


[Строки. Функции и методы строк \| Python 3 для начинающих и чайников](https://pythonworld.ru/tipy-dannyx-v-python/stroki-funkcii-i-metody-strok.html)


**Что это:** неизменяемая последовательность Unicode-символов. Каждый символ — кодовая точка Unicode, а не байт.

**Магические методы:** `__add__` (конкатенация), `__mul__` (повторение), `__len__`, `__getitem__`, `__contains__`, `__iter__`, `__eq__`, `__lt__` (лексикографическое сравнение).

```python
s = "Привет"
s = 'Привет'        # одинарные и двойные кавычки — одно и то же
s = """Многострочная
строка"""
s = r"\n не перенос строки"   # raw-строка, обратный слэш — литерал
s = b"байты"                  # bytes, не str
s = f"2 + 2 = {2 + 2}"        # f-строка → "2 + 2 = 4"
s = u"Привет"                 # u-строка = обычная str (наследие Python 2)
s = t"Привет, {имя}!"         # t-строка → Template, не str (Python 3.14+)
```

**Сравнение всех строковых префиксов:**

|Префикс|Тип результата|Пример|Версия|
|---|---|---|---|
|(нет)|`str`|`"текст"`|всегда|
|`r`|`str`|`r"\n"` → литерал `\n`|всегда|
|`b`|`bytes`|`b"байты"`|всегда|
|`f`|`str`|`f"{x+1}"`|3.6+|
|`u`|`str`|`u"текст"` = `"текст"`|наследие Py2|
|`t`|`Template`|`t"{x}"`|3.14+|

Префиксы комбинируются: `rb"…"` (сырые байты), `rf"…"` (сырая f-строка). `u` ни с чем не сочетается.

### Неявная склейка соседних литералов

Два строковых литерала, записанные **подряд** (через пробел или перенос строки), Python склеивает в один **на этапе компиляции** — без всякого `+`:

```python
'привет' 'мир'          # → 'приветмир'
"foo" "bar" "baz"       # → 'foobarbaz'
```

Это удобно, чтобы разбить длинную строку на несколько строк кода — без лишних объектов и без `+` в рантайме:

```python
текст = ("это очень длинная строка, "
         "которую разбили на части "
         "для читаемости")            # → одна строка целиком
```

> **Работает только для литералов, не для переменных.** `имя 'мир'` — синтаксическая ошибка; для переменной нужен `+` (`имя + 'мир'`) или f-строка (`f"{имя}мир"`).

#### Ловушка: пропущенная запятая в списке

Из-за неявной склейки забытая запятая между строками **не вызывает ошибку**, а молча превращает два элемента в один:

```python
# НЕПРАВИЛЬНО — потеряна запятая после 'Богдан':
names = ['Аня', 'Богдан' 'Вика']    # → ['Аня', 'БогданВика']  — 2 элемента, не 3!

# ПРАВИЛЬНО
names = ['Аня', 'Богдан', 'Вика']   # → 3 элемента
```

### Экранирование и escape-последовательности

**Экранирование (escaping)** — способ вставить в строку символ, который иначе сломал бы литерал (кавычку) или не набирается напрямую (перевод строки). Делается **обратным слэшем** `\`:

```python
'It\'s ok'          # \' — кавычка внутри тех же кавычек
"Строка1\nСтрока2"  # \n — перевод строки
"Столбец\tтаб"      # \t — табуляция
"Слэш: \\"          # \\ — сам обратный слэш
```

Частые escape-последовательности:

| Escape | Значение |
|---|---|
| `\'` `\"` | кавычка |
| `\\` | обратный слэш |
| `\n` `\r` `\t` | перевод строки, возврат каретки, табуляция |
| `\0` | нулевой байт |
| `\xHH` | символ по hex-коду (2 цифры) — `\x41` → `A` |
| `\ooo` | символ по восьмеричному коду — `\101` → `A` |
| `\uHHHH` `\U00HHHHHH` | Unicode по hex-коду — `A` → `A` |
| `\N{имя}` | Unicode по имени — `\N{BULLET}` → `•` |

> Коды символов задаются в разных системах счисления: `\x` — hex, `\ooo` — octal, `\u` — Unicode hex. Один и тот же символ `A`: `\x41` = `\101` = `A`.

**Сырая строка `r"..."`** отключает экранирование — слэш становится обычным символом. Незаменима для регулярок и путей Windows:

```python
print("C:\new")     # → C:   (\n = перевод строки!)  ew
print(r"C:\new")    # → C:\new    — слэш буквальный
```

#### Ловушка: строка не может кончаться на слэш

```python
# НЕПРАВИЛЬНО — SyntaxError: строка не закрыта
print("C:\new\")    # \" экранирует кавычку → литерал не закрывается
print(r"C:\new\")   # даже raw! r отменяет смысл \, но не мешает ему «съесть» кавычку

# ПРАВИЛЬНО
print("C:\\new\\")      # удвоить слэши
print(r"C:\new" + "\\") # raw + отдельный слэш
print("C:/new/")        # прямые слэши — Python принимает их в путях
```

Причина: на этапе разбора `\` перед закрывающей кавычкой всегда экранирует её, поэтому **сырая строка не может заканчиваться нечётным числом слэшей**.

**Ограничения строковых литералов** — ещё и в кавычках:
- одинарные/двойные `'…'` `"…"` — **одна строка**, перенос внутри запрещён (нужны `\n` или тройные кавычки `"""…"""`);
- ту же кавычку, что обрамляет строку, внутри надо экранировать (или взять другой тип кавычек);
- неизвестная escape вроде `\d` — `SyntaxWarning` (с Python 3.12), слэш сохраняется буквально.

### Неизменяемость строк

```python
s = "hello"
s[0] = "H"      # TypeError — строку нельзя изменить

# создаётся новая строка:
s = "H" + s[1:]  # → "Hello"
```

### t-строки (Python 3.14+)

**t-строка** (template string, PEP 750) — синтаксически как f-строка, но **возвращает не `str`**, а объект `Template` из модуля `string.templatelib`. Строка не собирается сразу — статические части и вставки хранятся отдельно, и ты сам решаешь как их объединить.
```python
from string.templatelib import Template, Interpolation

имя = "Андрей"
tmpl = t"Привет, {имя}!"

type(tmpl)              # → <class 'string.templatelib.Template'>
tmpl.strings            # → ('Привет, ', '!')     — статические части
tmpl.values             # → ('Андрей',)            — значения вставок
```

**Зачем нужны:** f-строка немедленно собирает результат в `str` и теряет информацию о том, что было динамическим. t-строка сохраняет структуру — можно обработать значения **до** сборки. Это решает проблемы безопасности.

```python
# f-строка — уязвимость SQL-инъекции:
имя = "Robert'); DROP TABLE users;--"
query = f"SELECT * FROM users WHERE name = '{имя}'"
# база выполнит вредоносный код!

# t-строка — библиотека сама экранирует:
query = sql(t"SELECT * FROM users WHERE name = '{имя}'")
# библиотека видит что '{имя}' — вставка, экранирует правильно
```

Сами по себе t-строки **ничего не делают** — нет встроенных обработчиков. Обработчик (`sql()`, `html()`, `log()`) пишешь сам или берёшь из библиотеки:

```python
def render(tmpl: Template) -> str:
    parts = []
    for часть in tmpl:
        if isinstance(часть, Interpolation):
            parts.append(str(часть.value))
        else:
            parts.append(часть)
    return "".join(parts)

render(t"Привет, {имя}!")   # → "Привет, Андрей!"
```

### Индексация и срезы

Строка — последовательность, каждый символ доступен по индексу.
```python
s = "Привет"

s[0]        # → "П"   — первый символ
s[-1]       # → "т"   — последний
s[-2]       # → "е"   — предпоследний
```

**Срез `[start:stop:step]`** — `stop` не включается:

- `start` — с какого индекса начать (включительно), по умолчанию `0`
- `stop` — до какого индекса (не включается), по умолчанию конец строки
- `step` — шаг, по умолчанию `1`. Отрицательный — идти справа налево

```python
s = "abcdef"

s[1:4]      # → "bcd"
s[:3]       # → "abc"  — от начала
s[3:]       # → "def"  — до конца
s[:]        # → "abcdef" — копия строки
s[::2]      # → "ace"  — каждый второй символ
s[::-1]     # → "fedcba" — разворот (step=-1, идёт с конца)
s[5:2:-1]   # → "fed"  — с 5-го до 3-го, назад
s[1:5:2]    # → "bd"   — с шагом 2
```

**Срезы за пределами — не ошибка:**
```python
s = "abc"
s[10]       # → IndexError — одиночный индекс за пределами
s[1:100]    # → "bc"  — срез молча обрезается по длине
s[-100:2]   # → "ab"
```


**Срезы возвращают новую строку** — оригинал не меняется.
```python
s = "Hello, World!"
s[7:]           # → "World!"
s[:5]           # → "Hello"
s[7:12]         # → "World"
s[-6:-1]        # → "World"  — отрицательные индексы работают в срезах
```

### Методы str

**Регистр:**
```python
"hello".upper()         # → "HELLO"
"HELLO".lower()         # → "hello"
"hello world".title()   # → "Hello World"
"hello".capitalize()    # → "Hello" — только первый символ
"Hello World".swapcase()  # → "hELLO wORLD"
"Hello".casefold()      # → "hello" — агрессивнее lower(), для сравнения
```

**Поиск и проверка:**
```python
s = "hello world"

s.find("world")         # → 6    — индекс первого вхождения, -1 если нет
s.rfind("o")            # → 7    — поиск с конца
s.index("world")        # → 6    — как find, но ValueError если нет
s.rindex("o")           # → 7    — как rfind, но ValueError если нет
s.count("l")            # → 3    — количество вхождений
s.startswith("hello")   # → True
s.endswith("world")     # → True
"hello".startswith(("he", "ho"))  # → True — кортеж префиксов

"abc123".isdigit()      # → False — все ли цифры
"123".isdigit()         # → True
"abc".isalpha()         # → True  — все ли буквы
"abc123".isalnum()      # → True  — буквы или цифры
"   ".isspace()         # → True  — все ли пробельные символы
"Hello".isupper()       # → False
"HELLO".isupper()       # → True
"hello".islower()       # → True  — все ли строчные (парный к isupper)
"Hello World".istitle() # → True  — каждое слово с большой буквы
"имя_1".isidentifier()  # → True  — годится ли как имя переменной
"2var".isidentifier()   # → False — нельзя начинать с цифры
"abc".isprintable()     # → True  — нет непечатаемых символов (\t, \n → False)
"abc".isascii()         # → True  — только ASCII
"Привет".isascii()      # → False

# три разных проверки «числа» — различаются на Unicode:
"123".isdigit()         # → True
"²".isdigit()           # → True   — надстрочная 2 считается цифрой
"²".isdecimal()         # → False  — но не десятичная (можно ли собрать int)
"½".isnumeric()         # → True   — дробь ½ — числовая, но не digit/decimal
```

> `isdecimal()` — самая строгая (только 0–9 и их Unicode-аналоги), `isdigit()` шире (плюс надстрочные), `isnumeric()` самая широкая (дроби, римские). Для валидации ввода перед `int()` бери `isdecimal()`.

**Замена и разбивка:**
```python
"hello world".replace("world", "Python")  # → "hello Python"
"hello".replace("l", "L", 1)              # → "heLlo" — только первое

"a,b,c".split(",")          # → ["a", "b", "c"]
"a,b,c".split(",", 1)       # → ["a", "b,c"] — максимум 1 разбивка слева
"a.b.c.d".rsplit(".", 1)    # → ["a.b.c", "d"] — split, но с конца
"line1\nline2".splitlines() # → ["line1", "line2"]

",".join(["a", "b", "c"])   # → "a,b,c" — объединить список в строку
" ".join(["hello", "world"]) # → "hello world"

# partition / rpartition — разбить на 3 части по первому/последнему разделителю
"path/to/file".partition("/")   # → ("path", "/", "to/file")
"path/to/file".rpartition("/")  # → ("path/to", "/", "file") — по последнему
"abc".rpartition("/")           # → ("", "", "abc") — разделитель не найден
```

**Срезать префикс/суффикс (Python 3.9+):**
```python
"TestHook".removeprefix("Test")  # → "Hook"   — убрать начало если есть
"image.png".removesuffix(".png") # → "image"  — убрать конец если есть
"hello".removeprefix("xyz")      # → "hello"  — нет совпадения → без изменений

# в отличие от strip() — strip убирает ЛЮБЫЕ символы из набора, а не подстроку:
"mississippi".strip("ips")       # → "m"           — грызёт по символам!
"mississippi".removesuffix("ppi")  # → "mississi"  — убирает ровно подстроку
```

**Замена по таблице символов — `translate` + `maketrans`:**
```python
таблица = str.maketrans("aeiou", "AEIOU")   # карта замен символ→символ
"hello world".translate(таблица)            # → "hEllO wOrld"

# третий аргумент maketrans — символы на удаление:
удалить = str.maketrans("", "", "aeiou")
"hello world".translate(удалить)            # → "hll wrld"

# быстрее цепочки replace() — один проход по строке
```

**Обрезка:**
```python
"  hello  ".strip()         # → "hello"    — убрать пробелы с обеих сторон
"  hello  ".lstrip()        # → "hello  "  — только слева
"  hello  ".rstrip()        # → "  hello"  — только справа
"xxhelloxx".strip("x")      # → "hello"    — убрать конкретные символы
```

**Выравнивание и заполнение:**
```python
"hi".center(10)             # → "    hi    "
"hi".center(10, "-")        # → "----hi----"
"hi".ljust(10)              # → "hi        "
"hi".rjust(10)              # → "        hi"
"42".zfill(5)               # → "00042"    — заполнить нулями слева
```

**Форматирование:**
```python
# f-строки (Python 3.6+) — предпочтительный способ
имя = "Андрей"
f"Привет, {имя}!"               # → "Привет, Андрей!"
f"Pi = {3.14159:.2f}"           # → "Pi = 3.14"
f"{1000000:,}"                  # → "1,000,000"
f"{255:#010x}"                  # → "0x000000ff"
f"{'left':<10}"                 # → "left      " — выравнивание
f"{'right':>10}"                # → "     right"
f"{'center':^10}"               # → "  center  "

# format() — более старый способ
"Привет, {}!".format("мир")
"Привет, {name}!".format(name="мир")
"{:.2f}".format(3.14159)        # → "3.14"

# format_map() — как format(**словарь), но без копирования словаря
данные = {"имя": "Иван", "город": "Москва"}
"{имя} из {город}".format_map(данные)   # → "Иван из Москва"

# % — устаревший способ (Python 2)
"Привет, %s! Тебе %d лет." % ("Иван", 25)
```

### Плюсы

- Unicode из коробки — работает с любым языком
- Огромное количество методов
- Неизменяемость = можно использовать как ключ в словаре

### Минусы

- Неизменяемость — конкатенация в цикле через `+` работает за `O(n²)`
- Хранит Unicode → занимает больше памяти чем байтовые строки
```python
# медленно: O(n²)
result = ""
for слово in слова:
    result += слово

# быстро: O(n)
result = "".join(слова)
```

### Практика
```python
# палиндром через срез:
def палиндром(s):
    s = s.lower().replace(" ", "")
    return s == s[::-1]

палиндром("abba")       # → True
палиндром("abc")        # → False

# разворот строки:
"Привет"[::-1]          # → "тевирП"

# каждый второй символ:
"abcdef"[::2]           # → "ace"

# последние n символов:
s[-3:]                  # → последние 3 символа

# убрать первый и последний символ:
s[1:-1]

# срез как замена strip для конкретного числа символов:
"##hello##"[2:-2]       # → "hello"

# подсчёт слов
def слова(текст):
    return len(текст.split())

# форматирование таблицы
заголовки = ["Имя", "Возраст", "Город"]
```

## bytes — байтовая строка

**Что это:** неизменяемая последовательность байтов (целых чисел от 0 до 255). Не текст — сырые данные.

**Магические методы:** `__add__`, `__mul__`, `__len__`, `__getitem__`, `__contains__`, `__iter__`, `__eq__`.
```python
b = b"hello"
b = bytes([72, 101, 108, 108, 111])   # из списка байтов
b = bytes(5)                           # → b'\x00\x00\x00\x00\x00' — 5 нулей

b[0]        # → 72 — не символ, а число!
b[0:3]      # → b"hel"
```

### Методы bytes

Большинство методов `str` доступны и у `bytes`:
```python
b"hello".upper()            # → b"HELLO"
b"hello world".split(b" ")  # → [b"hello", b"world"]
b"hello".replace(b"l", b"L") # → b"heLLo"
b"hello".find(b"ll")        # → 2
b" hello ".strip()          # → b"hello"
b"hello".startswith(b"he")  # → True
b",".join([b"a", b"b"])     # → b"a,b"
```

**Конвертация:**
```python
b"hello".decode("utf-8")    # → "hello" — bytes → str
b"hello".hex()              # → "68656c6c6f" — в hex-строку
bytes.fromhex("68656c6c6f") # → b"hello"
```

### bytearray — изменяемые байты
```python
ba = bytearray(b"hello")
ba[0] = 72      # можно изменять
ba.append(33)   # → bytearray(b"hello!")
```

### Плюсы

- Работа с бинарными данными, сетью, файлами
- Компактнее str для ASCII-данных

### Минусы

- Нельзя смешивать `str` и `bytes` — TypeError
```python
"hello" + b"world"    # TypeError!
```
