# Grab

> _Загрузка + парсинг в одном инструменте — «комбайн» для скрейпинга_

---

**Grab** — фреймворк веб-скрейпинга для [Python](../../../Python.md): объединяет HTTP-клиент и парсер в одном объекте, чтобы скачать страницу и сразу вытащить из неё данные. Внутри опирается на pycurl (сеть) и lxml (разбор HTML). Для больших краулеров есть компонент **Spider** — движок с очередью задач и параллельными запросами.

> **Статус: режим поддержки.** Последний полноценный релиз (0.6.41) — 2018 год; библиотека обновляется под новые версии Python, но новых возможностей не получает. Для новых проектов мейнстрим — **Scrapy** (полноценный краулер) или связка [requests](../../../Библиотеки/Сторонние/Работа%20с%20WEB/requests.md) + [BeautifulSoup](../../../Библиотеки/Сторонние/Работа%20с%20WEB/BeautifulSoup.md). Grab встречается в старых проектах и русскоязычных туториалах.

```bash
pip install grab
```

## Базовое использование

Один объект `Grab` и скачивает, и парсит: после `go(url)` результат лежит в `g.doc`, откуда данные достают CSS-селекторами или XPath:

```python
from grab import Grab

g = Grab()
g.go('https://example.com')          # скачать страницу

g.doc.select('//h1').text()          # текст первого <h1> (XPath)
g.doc('//a/@href').text()            # атрибут href первой ссылки
for elem in g.doc.select('//article'):
    print(elem.select('.//h2').text())
```

## Spider — краулер

**Spider** — каркас для масштабных скрейперов: описываешь стартовые задачи и обработчики, а Spider сам гоняет запросы параллельно и обходит очередь. Идея та же, что у Scrapy: разделить «что качать» и «что делать с ответом».

## Grab против альтернатив

| Инструмент | Что это | Когда |
|---|---|---|
| [requests](../../../Библиотеки/Сторонние/Работа%20с%20WEB/requests.md) + [BeautifulSoup](../../../Библиотеки/Сторонние/Работа%20с%20WEB/BeautifulSoup.md) | клиент + парсер вручную | простой скрейпинг, полный контроль |
| **Grab** | комбайн клиент+парсер, Spider | нишевый, старые проекты |
| Scrapy | полноценный краулер-фреймворк | новые крупные краулеры (мейнстрим) |
| [Selenium](../../../Библиотеки/Сторонние/Работа%20с%20WEB/Selenium.md) | реальный браузер | страницы на JavaScript |

## Связи

- [requests](../../../Библиотеки/Сторонние/Работа%20с%20WEB/requests.md), [BeautifulSoup](../../../Библиотеки/Сторонние/Работа%20с%20WEB/BeautifulSoup.md) — их связка — актуальная альтернатива Grab;
- [Selenium](../../../Библиотеки/Сторонние/Работа%20с%20WEB/Selenium.md) — когда контент отрисовывается JavaScript (Grab, как и requests, видит только статику);
- [Asyncio Event Loop и aiohttp](../../../Библиотеки/Модули/Параллелизм/Asyncio%20Event%20Loop%20и%20aiohttp.md) — асинхронные запросы, если нужен свой быстрый скрейпер.
