# pandas

> _Excel-таблица внутри Python: читаешь, фильтруешь, группируешь — кодом_

---

**pandas** — библиотека для анализа табличных данных на [Python](../../Python.md). Её главный объект — **DataFrame**, таблица со строками и столбцами (как лист Excel или SQL-таблица). pandas построена на [numpy](../../Библиотеки/Сторонние/numpy.md), поэтому операции над столбцами быстрые и векторизованные. Ей читают CSV/Excel, чистят данные, фильтруют, группируют и считают статистику.

## Series и DataFrame

Две основные структуры:

- **Series** — одномерный массив с **индексом** (подписанный столбец): значения + метки.
- **DataFrame** — двумерная таблица: набор Series с общим индексом (строки) и именами столбцов.

```python
import pandas as pd

s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])   # столбец с метками

df = pd.DataFrame({                                   # таблица из словаря
    'name': ['Alex', 'Maria', 'Ivan'],
    'age': [25, 30, 22],
    'city': ['Москва', 'Казань', 'Москва'],
})
```

Series ведёт себя как столбец с подписями: элементы берутся по метке, арифметика идёт поэлементно (как в [numpy](../../Библиотеки/Сторонние/numpy.md)), фильтрация — маской.

```python
s['a']              # 10      по метке
s[['a', 'c']]       # 10, 30  сразу несколько
s[1:]               # 20, 30  срез по позиции
s + s               # 20, 40, 60  — поэлементно
s[s > 15]           # 20, 30  — булева маска

s.name = 'продажи'          # имя Series → станет именем столбца в DataFrame
s.index.name = 'месяц'      # имя самого индекса
```

> **Series из словаря берёт ключи как индекс.** Если передать ещё и `index=`, pandas оставит только перечисленные метки, а для отсутствующих подставит `NaN` — это самый частый способ получить пропуски на ровном месте.

## Чтение и запись

Чаще всего данные не создают руками, а читают из файла — и тем же способом кладут обратно:

```python
df = pd.read_csv('data.csv')          # из CSV
df = pd.read_excel('data.xlsx')       # из Excel (нужен пакет openpyxl)
df = pd.read_json('data.json')        # из JSON

df.to_csv('out.csv', index=False)     # index=False — не писать столбец с номерами строк
df.to_excel('out.xlsx', index=False)
df.to_json('out.json', force_ascii=False, orient='records', indent=2)
```

> `to_csv` по умолчанию пишет индекс отдельным безымянным столбцом — при следующем `read_csv` он всплывёт как `Unnamed: 0`. Почти всегда нужен `index=False`. У `to_json` та же история с кириллицей: без `force_ascii=False` она уедет в `аб` (как `ensure_ascii` в [json](../../Библиотеки/Модули/Форматы%20данных/json.md)).

```python
df.head()        # первые 5 строк

df.columns       # имена столбцов
```

## Выбор данных

Столбец, строки по позиции/метке и фильтрация по условию:

```python
df['age']              # один столбец (Series)
df[['name', 'age']]    # несколько столбцов

df.iloc[0]             # строка по номеру (позиция)
df.loc[0]              # строка по метке индекса
df.loc[0, 'name']      # ячейка
df[10:13]              # срез СТРОК по позиции — строки 10, 11, 12

# булева фильтрация — как маска в NumPy
df[df['age'] > 24]                         # строки, где age > 24
df[(df['age'] > 24) & (df['city'] == 'Москва')]   # два условия через &
```

> **`loc` vs `iloc`.** `iloc` — по **числовой позиции** (`iloc[0]` — первая строка). `loc` — по **метке** индекса (`loc['a']`). Путаница между ними — частая ошибка новичков.

> **Квадратные скобки двулики:** `df['age']` берёт **столбец** по имени, а `df[10:13]` — **строки** по срезу. Это не опечатка в библиотеке, а исторический синтаксис; чтобы не гадать, для строк пиши `df.iloc[10:13]` явно.

> **Условия — только через `&`, `|`, `~` и обязательно в скобках.** Питоновские `and`/`or` здесь не работают: они пытаются привести весь столбец к одному `True`/`False` и падают с `ValueError: truth value of a Series is ambiguous`. Скобки нужны потому, что `&` по приоритету старше сравнения.

## Сортировка

**`sort_values`** сортирует по значениям столбца, **`sort_index`** — по индексу:

```python
df.sort_values('age')                              # по возрастанию
df.sort_values('age', ascending=False)             # по убыванию
df.sort_values(['city', 'age'])                    # по двум: сначала город, внутри — возраст
df.sort_values(['city', 'age'], ascending=[True, False])   # направление для каждого

df.sort_index()                                    # по меткам строк
df['age'].sort_values().head(3)                    # три самых молодых
```

Сортировка возвращает **новую** таблицу, исходная не меняется. Индексы при этом едут вместе со строками — если после сортировки нужна сквозная нумерация, добавь `.reset_index(drop=True)`.

## Новые столбцы и изменение

```python
df['age_next'] = df['age'] + 1              # новый столбец из операции
df['adult'] = df['age'] >= 18               # булев столбец
df = df.drop(columns=['age_next'])          # удалить столбец
df = df.rename(columns={'name': 'имя'})     # переименовать
```

### assign — то же самое, но без изменения исходной таблицы

`df['x'] = ...` меняет таблицу **на месте**. **`assign`** возвращает **копию** с новым столбцом, а исходную не трогает — за это его любят в цепочках преобразований.

```python
новый = df.assign(age_next=df['age'] + 1)          # df остался прежним

# лямбда получает таблицу на текущем шаге — можно опираться на только что созданный столбец
df.assign(
    age_next=lambda t: t['age'] + 1,
    группа=lambda t: t['age_next'] // 10,          # видит age_next из строки выше
)

# отсюда стиль «одна цепочка вместо десяти присваиваний»:
итог = (df
        .assign(revenue=lambda t: t['price'] * t['qty'])
        .query('revenue > 1000')
        .sort_values('revenue', ascending=False))
```

> **Зачем избегать присваивания.** Цепочка читается сверху вниз как последовательность шагов и не оставляет промежуточных таблиц-полуфабрикатов, в которых легко запутаться. Плюс `df['x'] = ...` на срезе другой таблицы выдаёт `SettingWithCopyWarning` — pandas не знает, менять копию или оригинал; у `assign` такой неоднозначности нет.

## Группировка

**`groupby`** — разбить данные по значению столбца и посчитать агрегат для каждой группы (как `GROUP BY` в SQL):

```python
df.groupby('city')['age'].mean()      # средний возраст по городам
df.groupby('city').size()             # сколько записей в каждом городе
df.groupby('city').agg({'age': ['mean', 'max']})   # несколько агрегатов
```

## Пропущенные значения

Реальные данные полны пропусков (`NaN`). pandas даёт инструменты их найти и обработать:

```python
df.isna().sum()             # сколько пропусков в каждом столбце
df.dropna()                 # удалить строки с пропусками
df.fillna(0)                # заполнить пропуски значением
df['age'].fillna(df['age'].mean())   # заполнить средним
```

## График: matplotlib

**matplotlib** — стандартная библиотека графиков в Python; pandas умеет рисовать через неё прямо из таблицы. Быстрый взгляд на данные глазами часто находит то, что не видно в `describe()`: выбросы, два горба вместо одного, дыру в середине.

```bash
pip install matplotlib
```

Самый короткий путь — метод `.plot()` у DataFrame и Series:

```python
import matplotlib.pyplot as plt

df['age'].plot(kind='hist', bins=20)      # гистограмма распределения
df['age'].plot(kind='box')                # ящик с усами — выбросы
df.plot(x='date', y='revenue')            # линейный график по времени
df.groupby('city')['age'].mean().plot(kind='bar')   # столбики из результата группировки

plt.show()                                # открыть окно с графиком
```

Оформление — отдельными вызовами до `show()`:

```python
plt.hist(df['score'], bins=20, label='баллы')
plt.xlabel('Балл')                        # подпись оси X
plt.ylabel('Сколько человек')             # подпись оси Y
plt.title('Распределение баллов')
plt.legend()                              # легенда — берёт label из вызова выше
plt.savefig('scores.png', dpi=150)        # сохранить в файл
plt.show()                                # показать (и очистить текущую фигуру)
```

| `kind=` | Когда брать |
|---|---|
| `hist` | распределение одной величины: где сгущается, есть ли второй горб |
| `bar` / `barh` | сравнить категории между собой (результат `groupby`) |
| `line` | изменение во времени |
| `scatter` | связь двух величин: есть ли зависимость |
| `box` | разброс и выбросы |

> **`plt.show()` очищает фигуру.** Если после него дописать `plt.savefig(...)`, в файл уйдёт пустая картинка. Порядок всегда такой: рисуем → оформляем → сохраняем → показываем.

## Сквозной пример: анализ продаж

От CSV до ответа «сколько выручки по категориям».

```python
import pandas as pd

# 1. прочитать данные
df = pd.read_csv('sales.csv')     # columns: product, category, price, qty

# 2. посчитать выручку в новом столбце (векторизация)
df['revenue'] = df['price'] * df['qty']

# 3. отфильтровать значимые продажи
big = df[df['revenue'] > 1000]

# 4. сгруппировать по категории и просуммировать
result = big.groupby('category')['revenue'].sum().sort_values(ascending=False)
print(result)
```

**Как это читать.** Читаем таблицу → считаем выручку сразу для всех строк (`price * qty` — поэлементно, как в [numpy](../../Библиотеки/Сторонние/numpy.md)) → отбираем нужные строки булевой маской → группируем по категории и суммируем. Четыре шага заменяют десятки строк ручных циклов.
