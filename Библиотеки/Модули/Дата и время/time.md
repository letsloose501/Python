# time

> _Момент времени как одно число — секунды от начала эпохи. Для измерения длительности и пауз, а не для календаря._

---

**time** — модуль низкоуровневой работы со временем: текущий момент как число, паузы, измерение длительности. В отличие от [datetime](../../../Библиотеки/Модули/Дата%20и%20время/datetime.md) (который про **календарь** — даты, месяцы, часовые пояса), `time` работает с **метками времени** (timestamp) и подходит для замеров и задержек.

Зачем: измерить, сколько работал участок кода (бенчмарк), поставить паузу, получить Unix-время для меток.

## Unix-время: секунды от эпохи

**`time.time()`** возвращает число секунд, прошедших с **1 января 1970 UTC** (начало «эпохи Unix»). Это компактный способ хранить момент времени.

```python
import time

time.time()      # → 1783346400.123   секунды с 1970 года (float)
```

Такую метку удобно хранить в БД и сравнивать; человекочитаемую дату из неё делает `datetime.fromtimestamp()`.

## Паузы

```python
time.sleep(2)        # приостановить выполнение на 2 секунды
time.sleep(0.1)      # можно дробные
```

## Измерение длительности: perf_counter

Для замеров бери **`perf_counter`** — он монотонный и максимально точный. `time.time()` для этого **не годится**: системные часы могут перевести (синхронизация, переход на зимнее время) — и разница получится отрицательной или скачком.

```python
start = time.perf_counter()
тяжёлая_функция()
прошло = time.perf_counter() - start        # секунды, точно
print(f"заняло {прошло:.3f} с")
```

| Функция | Для чего |
|---|---|
| `time.time()` | момент как Unix-timestamp (хранить, сравнивать) |
| `time.perf_counter()` | измерять длительность (бенчмарк) |
| `time.monotonic()` | таймауты — часы, которые не идут назад |
| `time.sleep(s)` | пауза |

> **Ловушка:** не измеряй время работы кода через `time.time()`. Используй `perf_counter` — он не зависит от перевода системных часов.

## time vs datetime

- **time** — число-момент, паузы, замеры длительности (машинный взгляд на время);
- **[datetime](../../../Библиотеки/Модули/Дата%20и%20время/datetime.md)** — календарные даты, арифметика дней, форматирование, часовые пояса (человеческий взгляд).

Их связывает `fromtimestamp`:

```python
from datetime import datetime
datetime.fromtimestamp(time.time())     # timestamp → читаемая дата
```

## Связи

- [datetime](../../../Библиотеки/Модули/Дата%20и%20время/datetime.md) — календарные даты и форматирование поверх момента времени;
- Вычислительная сложность — `perf_counter` для эмпирического замера скорости алгоритма;
- [sys](../../../Библиотеки/Модули/Система%20и%20окружение/sys.md) — вместе используются в контест-скриптах (замер, ограничение времени).
