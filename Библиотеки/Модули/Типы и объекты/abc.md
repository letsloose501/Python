# abc

> _Класс-контракт: описывает, какие методы обязан иметь наследник, но сам работать отказывается._

---

**abc** (Abstract Base Classes) — модуль для создания **абстрактных базовых классов**: классов, которые задают **интерфейс** (набор обязательных методов), но не предназначены для создания объектов напрямую. Наследник обязан реализовать все абстрактные методы — иначе Python не даст создать его экземпляр.

Зачем: зафиксировать общий контракт для группы классов. «Любая фигура умеет считать площадь», «любое хранилище умеет `save`/`load`» — база объявляет требование, наследники его выполняют. Это опора [абстракции](../../../ООП/Принципы/Абстракция%20Python.md) и [полиморфизма](../../../ООП/Принципы/Полиморфизм%20Python.md).

## Проблема без abc

Обычный базовый класс не заставляет наследника ничего реализовывать — забытый метод всплывёт ошибкой лишь при вызове, возможно в проде.

```python
from abc import ABC, abstractmethod

class Фигура(ABC):                       # наследуем ABC
    @abstractmethod
    def площадь(self):                   # обязателен для всех наследников
        ...

Фигура()          # → TypeError: нельзя создать экземпляр абстрактного класса
```

## Наследник обязан реализовать

```python
class Круг(Фигура):
    def __init__(self, r):
        self.r = r
    def площадь(self):                   # реализовали абстрактный метод
        return 3.14159 * self.r ** 2

Круг(5).площадь()      # → 78.5   работает

class Пустой(Фигура):
    pass

Пустой()          # → TypeError: не реализован метод площадь
```

> Ошибка возникает **в момент создания объекта**, а не при вызове метода. Контракт проверяется раньше — забытую реализацию замечаешь сразу.

## Зачем это

- **Единый интерфейс** — весь код, работающий с `Фигура`, уверен, что у объекта есть `площадь()`;
- **Ранняя ошибка** — недоделанный класс не создастся, а не упадёт потом;
- **Документация намерения** — база явно говорит, что должен уметь наследник.

Абстрактная база может содержать и **обычные** методы (общие для всех наследников) — так абстрактные и готовые методы соседствуют.

## collections.abc

Подмодуль `collections.abc` содержит готовые интерфейсы контейнеров — `Iterable`, `Sequence`, `Mapping`, `Hashable`. По ним проверяют «умеет ли объект итерироваться / индексироваться», не привязываясь к конкретному типу.

```python
from collections.abc import Iterable
isinstance([1, 2], Iterable)      # → True
```
