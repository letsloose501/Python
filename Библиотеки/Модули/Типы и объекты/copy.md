# copy

> _`b = a` не создаёт копию — это два имени одного объекта. Настоящая копия — это `copy`, и у неё есть две глубины._

---

**copy** — модуль для **копирования объектов**. В Python присваивание `b = a` не копирует данные — оно даёт второе имя тому же объекту. Для изменяемых объектов ([списки, словари](../../../Данные/Составные%20типы%20данных%20Python.md)) это значит: меняешь через одно имя — меняется и «второе». `copy` создаёт настоящую копию, и делает это на выбор — **поверхностно** или **глубоко**.

Зачем: когда нужно изменить структуру, не задев оригинал (черновик данных, независимая версия конфига).

## Присваивание не копирует

```python
a = [1, 2, 3]
b = a               # НЕ копия — то же самое, второе имя
b.append(4)
a                   # → [1, 2, 3, 4]   изменился и a (это один объект)
```

Причина — переменная хранит **ссылку** на объект, а не сам объект. `b = a` копирует ссылку, не данные.

## Поверхностная копия — copy.copy

**`copy.copy`** создаёт новый внешний объект, но вложенные объекты остаются **общими** (копируются их ссылки).

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)        # новый внешний список, но внутренние списки — те же

b.append([5, 6])        # внешний уровень независим:
a                       # → [[1, 2], [3, 4]]   (не изменился)

b[0].append(99)         # но вложенный список ОБЩИЙ:
a                       # → [[1, 2, 99], [3, 4]]   (изменился!)
```

## Глубокая копия — copy.deepcopy

**`copy.deepcopy`** рекурсивно копирует **всё** дерево объектов — оригинал и копия полностью независимы.

```python
a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)    # копируется всё, включая вложенные списки

b[0].append(99)
a                       # → [[1, 2], [3, 4]]   оригинал нетронут
```

## Сравнение

| Способ | Внешний объект | Вложенные объекты |
|---|---|---|
| `b = a` | тот же | те же |
| `copy.copy(a)` | новый | **те же** (общие) |
| `copy.deepcopy(a)` | новый | новые (независимые) |

> Для плоских структур (список чисел, простой словарь) хватает поверхностной копии — или `list(a)` / `a.copy()` / `dict(a)`. `deepcopy` нужен, когда есть **вложенность** и её тоже надо развязать. `deepcopy` дороже — не применяй без нужды.
