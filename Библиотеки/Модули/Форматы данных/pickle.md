# pickle

> _Сохранить любой объект Python в байты и восстановить обратно — но только для доверенных данных._

---

**pickle** — модуль **сериализации** объектов Python: превращает почти любой объект (список, словарь, экземпляр класса, вложенную структуру) в поток байтов и обратно. В отличие от [json](../../../Библиотеки/Модули/Форматы%20данных/json.md), который знает лишь простые типы и понятен любому языку, `pickle` сохраняет **произвольные объекты Python**, но результат читается только Python'ом.

Зачем: сохранить состояние программы на диск, кэшировать сложные объекты, передать данные между процессами ([multiprocessing](../../../Библиотеки/Модули/Параллелизм/multiprocessing.md) использует pickle под капотом).

## Сериализация и обратно

```python
import pickle

data = {"числа": [1, 2, 3], "объект": SomeClass()}

# в байты / из байтов:
b = pickle.dumps(data)          # объект → bytes
back = pickle.loads(b)          # bytes → объект

# сразу в файл / из файла (режим бинарный!):
with open("state.pkl", "wb") as f:
    pickle.dump(data, f)
with open("state.pkl", "rb") as f:
    data = pickle.load(f)
```

## pickle vs json

| | `pickle` | `json` |
|---|---|---|
| Что сохраняет | почти любой объект Python | только dict/list/str/число/bool/None |
| Читается | только Python | любой язык |
| Формат | двоичный | текстовый, человекочитаемый |
| Безопасность | **опасен** на чужих данных | безопасен |

## Ловушка безопасности

> **Никогда не делай `pickle.loads` данных из недоверенного источника.** Распаковка pickle может **выполнить произвольный код** — специально собранный «пикл» запустит что угодно при загрузке. Для данных извне (API, загрузки пользователей) используй [json](../../../Библиотеки/Модули/Форматы%20данных/json.md). `pickle` — только для своих данных, которым доверяешь.

## Когда что

- **pickle** — сохранить состояние своей программы, кэш, обмен между своими процессами;
- **[json](../../../Библиотеки/Модули/Форматы%20данных/json.md)** — обмен с внешним миром, API, конфиги, всё, что читают не-Python или чему не доверяешь.

## Связи

- [json](../../../Библиотеки/Модули/Форматы%20данных/json.md) — безопасная и кроссязычная альтернатива для внешних данных;
- [multiprocessing](../../../Библиотеки/Модули/Параллелизм/multiprocessing.md) — использует pickle для передачи аргументов и результатов между процессами;
- Форматы данных — сериализация как общий приём (pickle, JSON, protobuf);
- Криптография и безопасность — почему загрузка pickle из сети опасна.
