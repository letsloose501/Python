# csv

> _«Разбить строку по запятой» ломается на первой же запятой внутри кавычек. `csv` разбирает таблицы правильно._

---

**csv** — модуль чтения и записи таблиц в формате **CSV** (Comma-Separated Values): строки-записи, значения через запятую. Кажется, что это тривиально (`line.split(",")`), но CSV полон подвохов: запятые внутри значений, кавычки, переносы строк в ячейках. `csv` обрабатывает их по стандарту.

Зачем: экспорт/импорт таблиц, выгрузки из БД и Excel, обмен табличными данными — CSV повсюду.

## Почему не split(",")

```python
# строка CSV:  Иванов,"Москва, Россия",30
"Иванов,\"Москва, Россия\",30".split(",")
# → ['Иванов', '"Москва', ' Россия"', '30']   — сломалось на запятой внутри кавычек!
```

`csv` знает про кавычки и не режет по запятой внутри них.

## Чтение

```python
import csv

with open("data.csv", newline="", encoding="utf-8") as f:
    for строка in csv.reader(f):
        print(строка)          # каждая строка → список значений: ['Иванов', 'Москва, Россия', '30']
```

> **Ловушка:** открывай файл с `newline=""`. Иначе на Windows переносы строк могут задвоиться, и `csv` разберёт данные неверно. Это прямо предписано документацией.

## DictReader — строки как словари

Удобнее читать по именам колонок из заголовка, а не по индексам:

```python
with open("data.csv", newline="", encoding="utf-8") as f:
    for строка in csv.DictReader(f):
        print(строка["город"])     # доступ по имени колонки, а не строка[1]
```

## Запись

```python
with open("out.csv", "w", newline="", encoding="utf-8") as f:
    писатель = csv.writer(f)
    писатель.writerow(["имя", "город", "возраст"])      # заголовок
    писатель.writerow(["Иванов", "Москва, Россия", 30]) # запятая в значении экранируется сама

# по словарям:
with open("out.csv", "w", newline="", encoding="utf-8") as f:
    писатель = csv.DictWriter(f, fieldnames=["имя", "город"])
    писатель.writeheader()
    писатель.writerow({"имя": "Иванов", "город": "Москва"})
```

## Другой разделитель

CSV не всегда через запятую — бывает `;` (европейский Excel) или `\t` (TSV):

```python
csv.reader(f, delimiter=";")
```

## csv vs pandas

Для простого чтения/записи хватает `csv` (стандартная библиотека, ничего не ставить). Для анализа — фильтры, группировки, статистика — берут [pandas](../../../Библиотеки/Сторонние/pandas.md), который читает CSV одной строкой `read_csv`.
