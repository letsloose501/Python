# struct

> _Перевести числа Python в точную последовательность байтов и обратно — для двоичных файлов и сетевых протоколов._

---

**struct** — модуль упаковки данных в **байты** по заданному двоичному формату и распаковки обратно. Когда формат файла или сетевой протокол требует «4 байта — целое, потом 2 байта — короткое», `struct` собирает именно такую последовательность байтов и читает её назад в числа Python.

Зачем: чтение бинарных форматов (изображения, аудио, `.zip`), сетевые протоколы, взаимодействие с кодом на C. На бэкенде — редко, но незаменимо, когда данные не текст, а точная раскладка байтов.

## Проблема: число ≠ байты напрямую

Число `1000` в памяти — это байты, но их **раскладка** (сколько байт, порядок) зависит от формата. `struct` описывает раскладку строкой формата и делает перевод.

```python
import struct

struct.pack("i", 1000)          # → b'\xe8\x03\x00\x00'  int (4 байта) в байты
struct.unpack("i", b'\xe8\x03\x00\x00')   # → (1000,)     байты обратно в число
```

`unpack` всегда возвращает **кортеж** — даже для одного значения.

## Коды формата

Строка формата описывает типы по порядку:

```python
struct.pack("ihb", 1000, 50, 7)     # int + short + signed char подряд
struct.calcsize("ihb")               # → 7   сколько байт займёт
```

| Код | Тип | Байт |
|---|---|---|
| `b` / `B` | signed/unsigned char | 1 |
| `h` / `H` | short | 2 |
| `i` / `I` | int | 4 |
| `q` / `Q` | long long | 8 |
| `f` / `d` | float / double | 4 / 8 |
| `s` | байтовая строка | n |

## Порядок байтов (endianness)

Первый символ формата задаёт **порядок байтов** — критично для сетевых данных и чужих файлов:

```python
struct.pack(">i", 1000)     # big-endian (сетевой порядок, старший байт первым)
struct.pack("<i", 1000)     # little-endian (порядок x86)
```

> **Ловушка:** если читаешь чужой бинарный формат (сеть, файл с другой машины) и не указал порядок байтов — числа получатся «перевёрнутыми». Сетевые протоколы почти всегда big-endian (`>`).

## Сквозной пример: разбор заголовка

```python
import struct

# заголовок пакета: 2 байта тип + 4 байта длина (big-endian)
данные = b"\x00\x01\x00\x00\x04\x00"
тип, длина = struct.unpack(">HI", данные)     # H=short, I=int
# тип=1, длина=1024
```
