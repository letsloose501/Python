# contextlib

> _Ресурс нужно освободить в любом случае — даже если посреди работы вылетело исключение. За это отвечает менеджер контекста._

---

**contextlib** — модуль-помощник для **менеджеров контекста** — объектов, работающих с оператором `with`. Менеджер контекста гарантирует, что ресурс (файл, соединение, блокировка) будет **освобождён** при выходе из блока, что бы внутри ни случилось. `contextlib` упрощает создание таких менеджеров без написания целого класса.

Зачем: `with open(...)` закрывает файл сам; тот же приём нужен для своих ресурсов — и `contextlib` даёт его в одну функцию.

## Что делает with

Оператор `with` вызывает у объекта `__enter__` на входе и `__exit__` на выходе — **даже если внутри исключение**. Это надёжнее, чем `try/finally` вручную.

```python
with open("файл.txt") as f:      # __enter__: открыть
    данные = f.read()
# __exit__: файл закрыт автоматически, даже если read() упал
```

Раньше это делали через [try/finally](../../../Ядро%20языка/Обработка%20ошибок%20Python.md); `with` — тот же смысл, но короче и без риска забыть `finally`.

## @contextmanager — менеджер из генератора

Обычно менеджер контекста — это класс с `__enter__`/`__exit__`. Декоратор **`@contextmanager`** позволяет обойтись **функцией-генератором**: код до `yield` — вход, после — выход.

```python
from contextlib import contextmanager

@contextmanager
def таймер(имя):
    import time
    старт = time.perf_counter()      # ← setup (аналог __enter__)
    try:
        yield                        # ← здесь выполняется тело with
    finally:
        прошло = time.perf_counter() - старт
        print(f"{имя}: {прошло:.3f}с")   # ← teardown (аналог __exit__)

with таймер("загрузка"):
    тяжёлая_работа()
# → загрузка: 1.234с
```

`try/finally` вокруг `yield` гарантирует teardown даже при исключении в теле.

## Готовые помощники

**`suppress`** — подавить конкретное исключение без пустого `except`:

```python
from contextlib import suppress

with suppress(FileNotFoundError):
    os.remove("временный.txt")       # нет файла — молча идём дальше
```

| Инструмент | Что делает |
|---|---|
| `@contextmanager` | менеджер из функции-генератора |
| `suppress(Ошибка)` | проглотить указанное исключение |
| `closing(объект)` | гарантированно вызвать `.close()` на выходе |
| `redirect_stdout(f)` | временно перенаправить вывод `print` |
| `ExitStack` | управлять переменным числом менеджеров сразу |
