# pprint

> _Вложенный словарь, распечатанный обычным `print`, — стена в одну строку. `pprint` раскладывает его по отступам._

---

**pprint** (pretty-print) — модуль красивого вывода вложенных структур данных: словарей, списков, кортежей. Обычный `print` печатает сложную структуру одной длинной строкой, которую невозможно читать; `pprint` разбивает её по строкам с отступами.

Зачем: отладка. Когда нужно глазами разобрать ответ API, конфиг или вложенный словарь — `pprint` экономит время.

## print vs pprint

```python
from pprint import pprint

data = {"user": {"name": "Аня", "roles": ["admin", "editor"]},
        "active": True, "scores": [95, 88, 76, 91]}

print(data)      # всё в одну строку — нечитаемо
pprint(data)
# {'active': True,
#  'scores': [95, 88, 76, 91],
#  'user': {'name': 'Аня', 'roles': ['admin', 'editor']}}
```

По умолчанию `pprint` **сортирует ключи словаря** — вывод стабилен между запусками.

## Полезные параметры

```python
pprint(data, indent=4)          # величина отступа
pprint(data, width=40)          # ширина строки: когда переносить
pprint(data, depth=2)           # глубже уровня 2 показать как ...
pprint(data, sort_dicts=False)  # не сортировать ключи (оставить исходный порядок)
```

`pformat` — то же, но возвращает **строку** вместо печати (удобно, чтобы записать в лог):

```python
from pprint import pformat
log.debug(pformat(data))
```
