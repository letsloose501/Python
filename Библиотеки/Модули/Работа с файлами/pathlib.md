# pathlib

> _Путь — это объект, а не строка. `/` вместо склейки строк, методы вместо разрозненных функций._

---

**pathlib** — современный объектный способ работы с путями. Вместо строк и функций [os.path](../../../Библиотеки/Модули/Работа%20с%20файлами/os.md#пути-к-файлам--ospath) ты работаешь с объектом **`Path`**, у которого есть методы (`.exists()`, `.read_text()`) и удобный оператор `/` для сборки пути. Это стандарт для нового кода.

Зачем: код с путями становится читаемым и переносимым. `Path` сам знает про разделители ОС, умеет читать/писать файл одной строкой и искать по маске.

## Path и оператор /

Пути собираются оператором `/` — наглядно и без ручных разделителей:

```python
from pathlib import Path

база = Path("проект")
файл = база / "data" / "config.json"     # 'проект/data/config.json' (или \ на Windows)

Path.cwd()      # текущая папка
Path.home()     # домашняя папка пользователя
```

## Разбор пути — свойства, а не функции

Части пути доступны как атрибуты объекта:

```python
p = Path("/дом/аня/отчёт.txt")

p.name      # → 'отчёт.txt'   имя с расширением
p.stem      # → 'отчёт'       имя без расширения
p.suffix    # → '.txt'        расширение
p.parent    # → Path('/дом/аня')   родительская папка
p.parts     # → ('/', 'дом', 'аня', 'отчёт.txt')
```

## Проверки и файловые операции

```python
p.exists()          # существует ли
p.is_file()         # это файл
p.is_dir()          # это папка
p.mkdir(parents=True, exist_ok=True)   # создать папку с родителями, не падать если есть
p.unlink()          # удалить файл
p.rename(новый)     # переименовать/переместить
```

## Чтение и запись одной строкой

`Path` умеет читать/писать файл без ручного `open`:

```python
config = Path("config.txt")

config.write_text("данные", encoding="utf-8")    # записать строку целиком
текст = config.read_text(encoding="utf-8")        # прочитать целиком

data = Path("файл.bin").read_bytes()              # бинарно
```

Для построчной обработки больших файлов всё же нужен `open`/`with` — `read_text` тянет весь файл в память.

## Поиск по маске — glob

`.glob()` ищет по шаблону в папке, `.rglob()` — рекурсивно во всех подпапках:

```python
for py in Path("src").glob("*.py"):        # все .py в src
    print(py.name)

for md in Path("docs").rglob("*.md"):      # все .md во всём дереве docs
    print(md)
```

## os.path vs pathlib

| Задача | os.path | pathlib |
|---|---|---|
| Собрать путь | `os.path.join(a, b)` | `Path(a) / b` |
| Имя файла | `os.path.basename(p)` | `p.name` |
| Расширение | `os.path.splitext(p)[1]` | `p.suffix` |
| Родитель | `os.path.dirname(p)` | `p.parent` |
| Прочитать файл | `open(p).read()` | `p.read_text()` |

> Оба рабочие. `pathlib` предпочтителен в новом коде за читаемость; `os.path` встречается в существующих проектах и иногда чуть быстрее.
