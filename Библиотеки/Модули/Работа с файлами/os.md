# os

> _Портативный доступ к операционной системе: файлы, папки, переменные окружения — одинаково на Windows и Linux._

---

**os** — модуль связи с операционной системой: перемещаться по файловой системе, создавать и удалять файлы/папки, читать переменные окружения. Его ценность — **переносимость**: один код работает и на Windows, и на Linux, потому что `os` прячет различия (например, разделитель путей `\` против `/`).

Зачем на бэкенде: секреты и настройки читаются из переменных окружения (`os.environ`), скрипты ходят по папкам и файлам. Для путей современный код чаще берёт объектный [pathlib](../../../Библиотеки/Модули/Работа%20с%20файлами/pathlib.md), но `os` знать нужно — он повсюду.

## Переменные окружения — как приходят настройки

**`os.environ`** — словарь переменных окружения процесса. Стандартный способ передать в приложение секреты (пароли БД, ключи API), не зашивая их в код.

```python
import os

os.environ["PATH"]              # значение переменной (KeyError, если нет)
os.getenv("DB_HOST", "localhost")   # безопасно: значение или дефолт, без ошибки
```

> Правило бэкенда: пароли и ключи — в переменных окружения, а не в коде. Так секрет не попадёт в репозиторий.

## Пути к файлам — os.path

Подмодуль **`os.path`** собирает и разбирает пути правильно для текущей ОС.

```python
os.path.join("папка", "файл.txt")   # 'папка/файл.txt' или 'папка\\файл.txt' — по ОС
os.path.exists("файл.txt")          # существует ли путь
os.path.isfile(p) / os.path.isdir(p)   # это файл / папка
os.path.basename("/a/b/файл.txt")   # → 'файл.txt'   имя
os.path.dirname("/a/b/файл.txt")    # → '/a/b'       папка
os.path.splitext("файл.txt")        # → ('файл', '.txt')   имя и расширение
```

> **Ловушка:** не склеивай пути через `+` и `/` вручную (`"папка" + "/" + имя`) — на Windows разделитель другой. Всегда `os.path.join`.

## Операции с файловой системой

```python
os.getcwd()                 # текущая рабочая папка
os.listdir(".")             # список имён в папке
os.mkdir("новая")           # создать папку (ошибка, если есть)
os.makedirs("a/b/c", exist_ok=True)   # создать всю цепочку, не падать если есть
os.remove("файл.txt")       # удалить файл
os.rename("старое", "новое")   # переименовать/переместить
```

**`os.walk`** рекурсивно обходит дерево папок:

```python
for корень, папки, файлы in os.walk("проект"):
    for имя in файлы:
        print(os.path.join(корень, имя))
```

## os vs pathlib

`os.path` работает со строками-путями; [pathlib](../../../Библиотеки/Модули/Работа%20с%20файлами/pathlib.md) даёт объект `Path` с методами и оператором `/`. Для новых проектов рекомендуют `pathlib` — читаемее.

```python
# os.path:
import os
os.path.join(os.path.dirname(__file__), "data", "файл.txt")

# pathlib — то же самое, но нагляднее:
from pathlib import Path
Path(__file__).parent / "data" / "файл.txt"
```

## Связи

- [pathlib](../../../Библиотеки/Модули/Работа%20с%20файлами/pathlib.md) — объектная и более читаемая альтернатива `os.path`;
- Терминал — `os` повторяет команды оболочки (`cd`, `ls`, `mkdir`) из Python;
- [sys](../../../Библиотеки/Модули/Система%20и%20окружение/sys.md) — `sys` про интерпретатор, `os` про операционную систему;
- [Развертывание проекта](../../../DevOps/Развертывание%20проекта.md) — переменные окружения как способ конфигурации.
