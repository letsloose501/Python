# zipfile

> _Читать и создавать ZIP-архивы прямо из Python — без вызова внешних программ._

---

**zipfile** — модуль работы с **ZIP-архивами**: распаковать, создать, дописать, прочитать содержимое без распаковки. ZIP объединяет много файлов в один и сжимает их, поэтому это частый формат для выгрузок, бэкапов и передачи наборов файлов.

Зачем на бэкенде: отдать пользователю пачку файлов одним архивом, принять и распаковать загруженный ZIP, читать данные из архива не разворачивая его на диск.

## Прочитать архив

```python
import zipfile

with zipfile.ZipFile("data.zip") as z:
    z.namelist()                    # → ['a.txt', 'папка/b.csv']  список файлов внутри
    z.extractall("куда/")           # распаковать всё
    z.extract("a.txt", "куда/")     # распаковать один файл

    with z.open("a.txt") as f:      # прочитать файл ИЗ архива, не распаковывая
        данные = f.read()
```

## Создать архив

Режимы как у `open`: `"r"` — читать, `"w"` — создать (перезаписать), `"a"` — дописать.

```python
with zipfile.ZipFile("out.zip", "w", zipfile.ZIP_DEFLATED) as z:
    z.write("отчёт.txt")                     # добавить файл с диска
    z.write("данные.csv", arcname="d.csv")   # добавить под другим именем в архиве
    z.writestr("сгенерировано.txt", "текст") # записать прямо из строки, без файла на диске
```

> **Сжатие нужно указать явно:** по умолчанию `ZIP_STORED` — файлы просто складываются без сжатия. Для реального уменьшения размера передавай `compression=zipfile.ZIP_DEFLATED`.

## Архив в памяти

В связке с [BytesIO](../../../Библиотеки/Модули/Работа%20с%20файлами/io.md) можно собрать ZIP, не создавая временный файл, — удобно для отдачи в HTTP-ответ:

```python
import io, zipfile

буфер = io.BytesIO()
with zipfile.ZipFile(буфер, "w", zipfile.ZIP_DEFLATED) as z:
    z.writestr("файл.txt", "содержимое")
архив_байты = буфер.getvalue()       # готовый ZIP как bytes — можно отправить
```

## Связи

- [io](../../../Библиотеки/Модули/Работа%20с%20файлами/io.md) — `BytesIO` для сборки архива в памяти без файла на диске;
- [pathlib](../../../Библиотеки/Модули/Работа%20с%20файлами/pathlib.md) / [os](../../../Библиотеки/Модули/Работа%20с%20файлами/os.md) — пути к архивируемым файлам и папке распаковки;
- Форматы данных — ZIP как контейнерный формат среди прочих;
- [base64](../../../Библиотеки/Модули/Форматы%20данных/base64.md) — если архив нужно передать в текстовом канале (JSON).
