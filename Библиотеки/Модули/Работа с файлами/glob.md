# glob

> _Найти все файлы по маске — `*.txt`, `data/**/*.csv` — как это делает оболочка, но из Python._

---

**glob** — модуль поиска файлов по **маске** (шаблону с подстановочными знаками), как в командной оболочке. `*.txt` означает «все файлы с расширением txt». Это простой способ собрать список путей, не перебирая папку вручную.

Зачем: обработать «все CSV в папке», «все логи за месяц», «все картинки в дереве проекта».

## Подстановочные знаки

```python
import glob

glob.glob("*.txt")            # все .txt в текущей папке → ['a.txt', 'b.txt']
glob.glob("data/*.csv")       # все .csv в папке data
glob.glob("файл?.log")        # файл1.log, файлA.log — ? это один любой символ
glob.glob("[abc]*.py")        # файлы, начинающиеся с a, b или c
```

| Знак | Значение |
|---|---|
| `*` | любое число любых символов (кроме `/`) |
| `?` | ровно один любой символ |
| `[abc]` | один символ из набора |
| `**` | любое число вложенных папок (с `recursive=True`) |

## Рекурсивный поиск

`**` с флагом `recursive=True` ищет во всех подпапках на любую глубину:

```python
glob.glob("проект/**/*.py", recursive=True)   # все .py во всём дереве проекта
```

## iglob — итератор

`iglob` возвращает результаты по одному (итератор), не собирая весь список в память — для больших деревьев:

```python
for путь in glob.iglob("logs/**/*.log", recursive=True):
    обработать(путь)
```

## Ловушка: glob — это не regex

Маски `glob` — **шелл-шаблоны**, а не [регулярные выражения](../../../Библиотеки/Модули/Текст%20и%20строки/re.md). `*` в glob = «любые символы», а в regex `*` = «повтор предыдущего». Не путай: для имён файлов — `glob`, для содержимого текста — `re`.

## glob vs pathlib

`pathlib` умеет то же через метод, возвращая объекты `Path` вместо строк:

```python
from pathlib import Path
list(Path("проект").glob("**/*.py"))       # то же, но Path-объекты
list(Path("проект").rglob("*.py"))         # rglob = рекурсивный glob
```

> В новом коде часто берут [`Path.glob`/`Path.rglob`](../../../Библиотеки/Модули/Работа%20с%20файлами/pathlib.md) — результаты сразу объекты `Path` с методами. Модуль `glob` возвращает строки-пути.

## Связи

- [pathlib](../../../Библиотеки/Модули/Работа%20с%20файлами/pathlib.md) — `Path.glob`/`rglob` как объектная альтернатива, возвращающая `Path`;
- [os](../../../Библиотеки/Модули/Работа%20с%20файлами/os.md) — `os.walk` для полного обхода дерева, когда маски недостаточно;
- [re](../../../Библиотеки/Модули/Текст%20и%20строки/re.md) — регулярные выражения для текста; не путать с шелл-масками glob.
