# shutil

> _[os](../../../Библиотеки/Модули/Работа%20с%20файлами/os.md) умеет удалить один файл. `shutil` копирует деревья папок, перемещает и упаковывает — операции «целиком»._

---

**shutil** (shell utilities) — модуль **высокоуровневых** операций с файлами и папками: скопировать дерево, переместить, удалить папку со всем содержимым, собрать архив. Там, где [os](../../../Библиотеки/Модули/Работа%20с%20файлами/os.md) даёт поштучные примитивы (`os.remove`, `os.rename`), `shutil` работает с целыми деревьями за одну команду.

Зачем: бэкапы, развёртывание, подготовка данных — задачи вида «скопировать всю папку», «удалить каталог», «запаковать релиз».

## Копирование

```python
import shutil

shutil.copy("a.txt", "b.txt")           # скопировать файл (без метаданных времени)
shutil.copy2("a.txt", "b.txt")          # + сохранить метаданные (время создания и т.п.)
shutil.copytree("проект", "бэкап")      # скопировать ПАПКУ целиком, рекурсивно
```

## Перемещение и удаление

```python
shutil.move("файл.txt", "папка/")       # переместить (или переименовать)
shutil.rmtree("временная_папка")        # удалить папку СО ВСЕМ содержимым, рекурсивно
```

> **Ловушка:** `shutil.rmtree` удаляет **безвозвратно** всю папку и вложенное, без корзины. Ошибка в пути сотрёт не то. Проверяй путь перед вызовом — `os.remove` удаляет один файл, а `rmtree` — целое дерево.

## Архивы

Собрать и распаковать архив одной командой (использует [zipfile](../../../Библиотеки/Модули/Работа%20с%20файлами/zipfile.md)/`tarfile` под капотом):

```python
shutil.make_archive("релиз", "zip", "папка_проекта")   # → релиз.zip из папки
shutil.unpack_archive("релиз.zip", "куда")             # распаковать
```

## Полезные утилиты

```python
shutil.which("python")          # путь к исполняемому файлу в PATH (как which в shell)
shutil.disk_usage("/")          # → (total, used, free) в байтах
```

## os vs shutil

| Задача | os | shutil |
|---|---|---|
| Удалить один файл | `os.remove` | — |
| Удалить папку с содержимым | ручной обход | `shutil.rmtree` |
| Скопировать файл | вручную читать/писать | `shutil.copy` |
| Скопировать дерево | ручной обход | `shutil.copytree` |
| Архив | `zipfile` вручную | `make_archive` |

## Связи

- [os](../../../Библиотеки/Модули/Работа%20с%20файлами/os.md) — низкоуровневые операции с одним файлом (`remove`, `rename`);
