# tempfile

> _Нужен файл на время работы — не выдумывай имя в `/tmp` руками. `tempfile` даст безопасный и сам его уберёт._

---

**tempfile** — модуль создания **временных** файлов и папок: для промежуточных данных, которые не нужны после работы. Он сам придумывает уникальное имя в системной временной папке и (с менеджером контекста) удаляет файл автоматически.

Зачем: обработать загруженный файл, сложить промежуточный результат, дать внешней программе путь — не засоряя проект и не изобретая имена вручную.

## Почему не создавать файл в /tmp самому

Ручной путь вроде `/tmp/myfile.txt` порождает проблемы:

- **Коллизии** — два запуска возьмут одно имя и перезапишут данные друг друга;
- **Гонки и безопасность** — между проверкой «есть ли файл» и созданием кто-то может подставить свой (атака через симлинк);
- **Мусор** — забыл удалить, файлы копятся.

`tempfile` решает всё это: уникальное имя, безопасное создание, авто-очистка.

## Временный файл

```python
import tempfile

with tempfile.TemporaryFile(mode="w+", encoding="utf-8") as f:
    f.write("промежуточные данные")
    f.seek(0)
    f.read()
# файл удалён автоматически при выходе из with
```

**`NamedTemporaryFile`** — когда нужно **имя** файла (чтобы передать другой программе):

```python
with tempfile.NamedTemporaryFile(suffix=".txt", delete=True) as f:
    f.write(b"данные")
    f.flush()
    путь = f.name        # реальный путь на диске — можно отдать внешнему инструменту
```

## Временная папка

`TemporaryDirectory` создаёт каталог и рекурсивно удаляет его со всем содержимым на выходе:

```python
with tempfile.TemporaryDirectory() as каталог:
    файл = os.path.join(каталог, "результат.csv")
    # ... работать внутри каталога ...
# вся папка удалена автоматически
```

> Авто-очистка — главная ценность: файлы и папки исчезают даже при исключении, потому что это [менеджеры контекста](../../../Библиотеки/Модули/Отладка%20и%20утилиты/contextlib.md) (`with`).
