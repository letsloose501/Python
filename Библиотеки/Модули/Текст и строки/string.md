# string

> _Не путать модуль `string` с методами строк: почти всё, что делают со строками, — это методы `str`, а не этот модуль._

---

**string** — небольшой модуль, в котором живут в основном **готовые наборы символов** (константы) и класс `Template` для подстановки. Исторически здесь были строковые функции, но в современном Python они стали **методами `str`** (`"abc".upper()`, `"a,b".split(",")`), и модуль почти не нужен — кроме удобных констант.

Зачем на контесте: константы вроде `ascii_lowercase` и `digits` избавляют от ручного набора `"abcdefghijklmnopqrstuvwxyz"` — например, для шифров сдвига, проверки символов, генерации строк.

> **Развод понятий:** `string.upper(s)` не существует. Приведение регистра — это `s.upper()` (метод самой строки). Модуль `string` — это про **константы**, а не про операции.

## Константы-наборы символов

```python
import string

string.ascii_lowercase    # 'abcdefghijklmnopqrstuvwxyz'
string.ascii_uppercase    # 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'
string.ascii_letters      # строчные + прописные
string.digits             # '0123456789'
string.hexdigits          # '0123456789abcdefABCDEF'
string.punctuation        # '!"#$%&\'()*+,-./:;<=>?@[\\]^_`{|}~'
string.whitespace         # ' \t\n\r\x0b\x0c'
string.printable          # все печатаемые символы
```

Применение — быстрый набор алфавита и проверка принадлежности:

```python
# шифр Цезаря (сдвиг на 3) через индекс в алфавите:
алфавит = string.ascii_lowercase
def сдвиг(ch, k):
    if ch in алфавит:
        return алфавит[(алфавит.index(ch) + k) % 26]
    return ch

"".join(сдвиг(c, 3) for c in "abc")     # → 'def'
```

Вместе с [random](../../../Библиотеки/Модули/Работа%20с%20числами/random.md) константы дают генерацию случайных строк:

```python
import random, string
"".join(random.choices(string.ascii_letters + string.digits, k=8))   # случайный токен из 8 символов
```

## string.Template — безопасная подстановка

**`Template`** подставляет значения по `$имя`. В отличие от f-строк и `.format`, синтаксис минимальный — удобно для шаблонов, которые редактируют не-программисты (письма, конфиги), и безопаснее при подстановке пользовательских данных.

```python
from string import Template

t = Template("Привет, $name! Тебе $age.")
t.substitute(name="Аня", age=25)        # → 'Привет, Аня! Тебе 25.'
```

`safe_substitute` не упадёт, если какого-то ключа нет — оставит `$name` как есть.
