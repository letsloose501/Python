# re

> _Сам язык шаблонов один на все языки; `re` — то, как Python ими пользуется._

---

**re** — модуль регулярных выражений в Python: искать, проверять и заменять текст по шаблону. Синтаксис самих шаблонов (`\d`, `+`, `[...]`, группы) разобран в заметке Регулярные выражения — здесь про **API модуля**: какие функции есть и чем отличаются.

Зачем на контесте и бэкенде: разбор строк ввода, валидация формата (телефон, email, дата), извлечение чисел из текста — всё это `re` делает короче, чем ручной посимвольный разбор.

## raw-строки: почему r"..."

Шаблоны пиши в **raw-строках** `r"..."`. Иначе `\` сначала съест обычная строка Python, и `\b` (граница слова) превратится в `\b` (backspace).

```python
r"\d+"        # правильно: цифры
"\d+"         # опасно: Python может по-своему истолковать \d
```

## Пять основных функций

```python
import re

re.search(r"\d+", "год 2024")        # первое совпадение где угодно → Match('2024')
re.match(r"\d+", "год 2024")         # совпадение ТОЛЬКО с начала строки → None
re.fullmatch(r"\d+", "2024")         # вся строка целиком должна совпасть → Match('2024')
re.findall(r"\d+", "1 и 2 и 3")      # список всех совпадений → ['1', '2', '3']
re.sub(r"\d+", "#", "a1b22c")        # замена всех → 'a#b#c'
```

> **Ловушка:** `match` привязан к **началу** строки, `search` ищет **везде**. `re.match(r"\d+", "год 2024")` вернёт `None`, хотя цифры в строке есть. Нужен «где угодно» — бери `search`.

| Функция | Что возвращает | Где ищет |
|---|---|---|
| `search` | первый `Match` или `None` | в любом месте |
| `match` | `Match` или `None` | только с начала |
| `fullmatch` | `Match` или `None` | вся строка целиком |
| `findall` | список строк | все совпадения |
| `finditer` | итератор `Match` | все совпадения (с позициями) |
| `sub` | новую строку | заменяет все |
| `split` | список частей | режет по шаблону |

## Объект Match и группы

Функции поиска возвращают объект **`Match`**, из которого достают совпавший текст и группы.

```python
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "дата 2024-03-15")
m.group(0)      # → '2024-03-15'   всё совпадение
m.group(1)      # → '2024'         первая группа (...)
m.groups()      # → ('2024', '03', '15')
m.start(), m.end()   # → позиции совпадения
```

**Именованные группы** `(?P<имя>...)` — читаемее, чем номера:

```python
m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})", "2024-03")
m.group("year")     # → '2024'
m.groupdict()       # → {'year': '2024', 'month': '03'}
```

> **Ловушка `findall` с группами:** если в шаблоне есть группы, `findall` вернёт **группы**, а не всё совпадение. `re.findall(r"(\d)(\d)", "12 34")` → `[('1','2'), ('3','4')]`, а не `['12','34']`. Нужны полные совпадения с позициями — используй `finditer`.

## Флаги

Меняют поведение шаблона; передаются параметром `flags=`.

```python
re.findall(r"[a-z]+", "Hello", re.IGNORECASE)   # игнорировать регистр → ['Hello']
re.search(r"^строка", текст, re.MULTILINE)       # ^ и $ на каждой строке
re.search(r"a.b", "a\nb", re.DOTALL)             # точка ловит и перенос строки
```

| Флаг | Эффект |
|---|---|
| `re.IGNORECASE` (`re.I`) | без учёта регистра |
| `re.MULTILINE` (`re.M`) | `^`/`$` — на каждой строке |
| `re.DOTALL` (`re.S`) | `.` совпадает и с `\n` |
| `re.VERBOSE` (`re.X`) | игнорировать пробелы и `#`-комментарии в шаблоне → разбить регулярку на строки с пояснениями |

```python
pattern = re.compile(r"""
    (\d{4})   # год
    -(\d{2})  # месяц
    -(\d{2})  # день
""", re.VERBOSE)     # те же пробелы/переносы не влияют на смысл
```

## compile — скомпилировать один раз

Если один шаблон применяется много раз — скомпилируй его заранее, чтобы не разбирать каждый раз.

```python
pattern = re.compile(r"\d+")
pattern.findall("1 2 3")      # методы те же: search, match, findall, sub…
```

## Сквозной пример — нормализация телефонов

Классическая задача: телефоны приходят в разном виде (`+7 (999) 123-45-67`, `8(999)1234567`, `8 999 123 45 67 доб.1234`), нужно привести к единому формату. Приём — `re.sub(r"\D", "", ...)` **выкидывает всё, кроме цифр**, дальше собираем строку срезами.

```python
import re

def normalize_phone(phone: str):
    digits = re.sub(r"\D", "", phone)      # \D — любой НЕ-цифровой символ → удалить
    if digits.startswith("8"):
        digits = "7" + digits[1:]          # 8 → 7: единый код страны

    if len(digits) > 11:                   # есть добавочный
        return (f"+{digits[:1]}({digits[1:4]}){digits[4:7]}-"
                f"{digits[7:9]}-{digits[9:11]} доб. {digits[11:]}")
    elif len(digits) < 1:
        return ""                          # пустой/мусорный ввод
    else:
        return (f"+{digits[:1]}({digits[1:4]}){digits[4:7]}-"
                f"{digits[7:9]}-{digits[9:11]}")

normalize_phone("+7 (999) 123-45-67")        # → '+7(999)123-45-67'
normalize_phone("8(999)1234567")             # → '+7(999)123-45-67'
normalize_phone("8 999 123 45 67 доб.1234")  # → '+7(999)123-45-67 доб. 1234'
```

Здесь одна регулярка `\D` заменяет ручной перебор символов: `re.sub` за один проход отбрасывает пробелы, скобки, дефисы, слово «доб.» — остаётся чистая последовательность цифр, которую легко резать по позициям. Такой `normalize_phone` — типичный шаг перед дедупликацией контактов (например, из CSV через модуль [csv](../../../Библиотеки/Модули/Форматы%20данных/csv.md)).
