# heapq

> _Всегда нужен минимум из меняющегося набора — держи его в куче, а не сортируй заново._

---

**heapq** — модуль, превращающий обычный **список** в [min-кучу](../../../Алгоритмы/Иные/Двоичная%20куча%20и%20очередь%20с%20приоритетом.md): минимальный элемент всегда доступен за $O(1)$, добавление и извлечение — за $O(\log n)$. Это стандартный способ сделать **очередь с приоритетом** в Python.

Зачем на контесте: как только в задаче нужно «каждый раз брать наименьший/наибольший из того, что осталось» ([Дейкстра](../../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md), k наибольших, слияние потоков, планировщик) — это куча. Альтернатива (искать минимум перебором за $O(n)$) на больших данных не пройдёт по времени.

> Как куча устроена внутри (хранение в массиве, sift up/down, `heapify` за $O(n)$) — в [Двоичная куча и очередь с приоритетом](../../../Алгоритмы/Иные/Двоичная%20куча%20и%20очередь%20с%20приоритетом.md). Здесь — практический API модуля.

## Ключевая особенность: куча живёт в обычном списке

`heapq` не создаёт объект — он работает с твоим `list`, поддерживая в нём **свойство кучи**. Минимум всегда в `heap[0]`, но остальные элементы **не отсортированы**.

```python
import heapq

heap = []
heapq.heappush(heap, 5)
heapq.heappush(heap, 1)
heapq.heappush(heap, 3)

heap[0]                 # → 1  (peek — минимум, за O(1), без извлечения)
heapq.heappop(heap)     # → 1  (извлечь минимум, за O(log n))
heapq.heappop(heap)     # → 3
```

## Основные функции

```python
heapq.heappush(heap, x)     # добавить x, O(log n)
heapq.heappop(heap)         # извлечь и вернуть минимум, O(log n)
heap[0]                     # посмотреть минимум, O(1)
heapq.heapify(lst)          # превратить список в кучу на месте, O(n)
```

`heapify` дешевле, чем `n` раз `heappush`: $O(n)$ против $O(n \log n)$.

```python
данные = [5, 1, 3, 7, 4]
heapq.heapify(данные)       # данные → куча, минимум в данные[0]
```

## push + pop за один проход

Два оптимизированных сочетания — экономят один `sift`:

| Функция | Что делает | Порядок |
|---|---|---|
| `heapreplace(heap, x)` | извлечь минимум, **потом** вставить `x` | pop → push |
| `heappushpop(heap, x)` | вставить `x`, **потом** извлечь минимум | push → pop |

Разница на границе: `heappushpop` может вернуть сам `x` (если он меньше текущего минимума), `heapreplace` — всегда сначала отдаёт старый минимум.

## Готовые утилиты

```python
heapq.nlargest(3, [5, 1, 3, 7, 4])    # → [7, 5, 4]
heapq.nsmallest(3, [5, 1, 3, 7, 4])   # → [1, 3, 4]

# слить отсортированные последовательности в один отсортированный поток (лениво):
list(heapq.merge([1, 3, 5], [2, 4, 6]))   # → [1, 2, 3, 4, 5, 6]
```

`nlargest/nsmallest` с маленьким `k` работают за $O(n \log k)$ — дешевле, чем сортировать всё ради нескольких элементов.

## Max-куча и приоритет кортежами

`heapq` — **только min-куча**. Нужен максимум — храни отрицания:

```python
max_heap = []
for x in [5, 1, 3, 7, 4]:
    heapq.heappush(max_heap, -x)
-heapq.heappop(max_heap)      # → 7  (реальный максимум)
```

Приоритет отдельно от данных — храни **кортеж** `(приоритет, элемент)`; куча сравнивает по первому полю:

```python
heap = []
heapq.heappush(heap, (2, "задача B"))
heapq.heappush(heap, (1, "задача A"))
heapq.heappop(heap)           # → (1, 'задача A')
```

> **Ловушка:** при равных приоритетах Python начнёт сравнивать **вторые** поля. Если элемент несравним (например, словарь) — будет `TypeError`. Приём: вставлять `(приоритет, счётчик, элемент)`, где растущий счётчик разрывает ничью и гарантирует FIFO при равенстве.

## Контест-паттерны

**[Дейкстра](../../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md)** — кратчайшие пути (куча по расстоянию):

```python
def дейкстра(граф, старт):                      # граф: {v: [(сосед, вес), ...]}
    dist = {старт: 0}
    heap = [(0, старт)]
    while heap:
        d, v = heapq.heappop(heap)              # ближайшая ещё не финализированная вершина
        if d > dist.get(v, float("inf")):
            continue                             # устаревшая запись — пропустить
        for сосед, вес in граф[v]:
            new = d + вес
            if new < dist.get(сосед, float("inf")):
                dist[сосед] = new
                heapq.heappush(heap, (new, сосед))
    return dist
```

Другие типовые задачи — **k наибольших в потоке** за $O(n \log k)$ и **медиана потока** на двух кучах — разобраны в [Двоичная куча и очередь с приоритетом](../../../Алгоритмы/Иные/Двоичная%20куча%20и%20очередь%20с%20приоритетом.md#применение-в-алгоритмах).

## Ограничения

- Нет доступа по ключу — только `heap[0]` (min); поиск произвольного элемента — $O(n)$.
- Нельзя эффективно **изменить приоритет** элемента в середине. Приём: пометить старую запись устаревшей и вставить новую (как в Дейкстре выше).
- Куча **не устойчива** — порядок равных не гарантирован без счётчика-разрывателя.
