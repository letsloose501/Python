# collections

> _Когда обычных `list` и `dict` не хватает — в стандартной библиотеке уже есть специализированный контейнер._

---

**collections** — модуль со специализированными контейнерами поверх базовых `list`, `dict`, `tuple`. Каждый решает конкретную боль: очередь с быстрыми концами, подсчёт частот, словарь со значением по умолчанию, читаемый кортеж.

Зачем на контесте: `deque`, `Counter` и `defaultdict` — три инструмента, которые сокращают половину задач на строки, графы и подсчёты до нескольких строк. Их стоит знать наизусть.

## deque — очередь с двумя концами

**`deque`** (double-ended queue) — список, у которого **оба конца** работают за $O(1)$. У обычного `list` вставка/удаление в начало — $O(n)$ (сдвиг всех элементов).

```python
from collections import deque

d = deque([1, 2, 3])
d.append(4)         # справа  → deque([1, 2, 3, 4])
d.appendleft(0)     # слева   → deque([0, 1, 2, 3, 4])
d.pop()             # → 4     (справа)
d.popleft()         # → 0     (слева, O(1) — главное отличие от list)
```

**`maxlen`** превращает deque в **скользящее окно**: при переполнении элементы вытесняются с другого конца.

```python
окно = deque(maxlen=3)
for x in [1, 2, 3, 4, 5]:
    окно.append(x)      # → deque([3, 4, 5], maxlen=3): всегда последние 3
```

`rotate(k)` циклически сдвигает элементы.

> **Где нужен:** очередь для [BFS](../../../Алгоритмы/Поиск/BFS.md) (`popleft` — брать вершину), скользящее окно (`maxlen`), любая структура, где добавляешь/убираешь с обоих концов. Это стандартная реализация очереди и удобный [стек](../../../Данные/АТД/Стек.md).

## Counter — подсчёт частот

**`Counter`** — словарь `элемент → сколько раз встретился`. Считает за один проход.

```python
from collections import Counter

c = Counter("абракадабра")
c                       # → Counter({'а': 5, 'б': 2, 'р': 2, 'к': 1, 'д': 1})
c["а"]                  # → 5
c["ю"]                  # → 0  (отсутствующий ключ не даёт KeyError, а 0)

c.most_common(2)        # → [('а', 5), ('б', 2)]  — топ по частоте
list(c.elements())      # развернуть обратно в элементы
```

Counter'ы можно **складывать и вычитать** как мультимножества:

```python
Counter("aab") + Counter("abc")     # → Counter({'a': 3, 'b': 2, 'c': 1})
Counter("aab") - Counter("abc")     # → Counter({'a': 1})  (отрицательные отбрасываются)
```

> Классика: «являются ли две строки анаграммами» → `Counter(s1) == Counter(s2)`.

## defaultdict — словарь со значением по умолчанию

**`defaultdict(factory)`** — при обращении к отсутствующему ключу сам создаёт значение через `factory`, вместо `KeyError`. Убирает ручную проверку «есть ли ключ».

```python
from collections import defaultdict

# группировка — самый частый случай:
слова = ["apple", "banana", "avocado", "cherry"]
по_букве = defaultdict(list)
for w in слова:
    по_букве[w[0]].append(w)        # ключа ещё нет → создаётся пустой список
# → {'a': ['apple', 'avocado'], 'b': ['banana'], 'c': ['cherry']}

# подсчёт вручную (аналог Counter):
счёт = defaultdict(int)
for ch in "абракадабра":
    счёт[ch] += 1                   # отсутствующий ключ → 0, потом +1
```

Фабрика — любой вызов без аргументов: `int` → `0`, `list` → `[]`, `set` → `set()`.

> **Список смежности графа** пишется одной строкой: `граф = defaultdict(list)`, затем `граф[u].append(v)`. Ровно это нужно для [BFS](../../../Алгоритмы/Поиск/BFS.md)/[DFS](../../../Алгоритмы/Поиск/DFS.md).

## namedtuple — кортеж с именами полей

**`namedtuple`** — кортеж, к полям которого можно обращаться по имени, а не по индексу. Читаемость без накладных расходов класса.

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
p.x, p.y            # → (3, 4)   вместо p[0], p[1]
p[0]                # → 3        индексация тоже работает
```

Для изменяемого аналога с типами есть [dataclasses](../../../Библиотеки/Модули/Типы%20и%20объекты/dataclass.md).

## OrderedDict и ChainMap

- **`OrderedDict`** — словарь, помнящий порядок вставки. С Python 3.7 обычный `dict` **тоже** упорядочен, поэтому OrderedDict нужен редко — в основном ради `move_to_end()` и `popitem(last=False)` (например, для **[LRU-кэша](../../../Алгоритмы/Задачки/LRU-кэш.md)**: это готовая связка «словарь + двусвязный список», где `move_to_end` — «пометить свежим», а `popitem(last=False)` — «вытеснить самый старый», обе за $O(1)$).
- **`ChainMap`** — объединяет несколько словарей в один вид без копирования; поиск идёт по цепочке. Удобно для слоёв настроек (аргументы → env → значения по умолчанию).

## Каталог

| Контейнер | Зачем | Ключевое |
|---|---|---|
| `deque` | очередь/стек с быстрыми концами | `appendleft`/`popleft` $O(1)$, `maxlen` |
| `Counter` | подсчёт частот | `most_common`, арифметика |
| `defaultdict` | значение по умолчанию | группировка, adjacency-list |
| `namedtuple` | читаемый неизменяемый кортеж | доступ по имени |
| `OrderedDict` | порядок + `move_to_end` | LRU-кэш |
| `ChainMap` | слои словарей | настройки |
