# array

> _Список чисел одного типа, упакованный компактно — как массив в C, а не как список объектов Python._

---

**array** — модуль компактного массива чисел **одного типа**. Обычный [list](../../../Данные/АТД/Список.md) хранит указатели на объекты-числа, разбросанные по памяти; `array` хранит сами значения подряд, как [массив в C](../../../Данные/Структуры%20данных/Массив.md). Это экономит память в разы, когда чисел много.

Зачем: большие последовательности чисел (аудио-сэмплы, координаты, буферы), где `list` занимает слишком много памяти. Для вычислений всё же чаще берут [numpy](../../../Библиотеки/Сторонние/numpy.md) — но `array` есть в стандартной библиотеке и не требует установки.

## Проблема памяти у list

```python
[1, 2, 3]          # список: 3 указателя + 3 отдельных объекта int, каждый ~28 байт
```

Список из миллиона чисел тратит память и на указатели, и на объекты. `array` хранит только сырые значения фиксированного размера — в разы компактнее.

## Создание: тип задаётся кодом

Первый аргумент — **код типа**, определяющий, какие числа хранятся и сколько байт занимает каждое.

```python
from array import array

a = array("i", [1, 2, 3])       # 'i' — signed int (обычно 4 байта)
a.append(4)                     # ведёт себя как список
a[0]                            # → 1
```

| Код | Тип C | Python-тип |
|---|---|---|
| `'b'` / `'B'` | signed/unsigned char | int (1 байт) |
| `'i'` / `'I'` | signed/unsigned int | int |
| `'l'` / `'L'` | long | int |
| `'f'` | float | float (4 байта) |
| `'d'` | double | float (8 байт) |

> **Ограничение:** все элементы — одного типа. Попытка положить не тот тип (`a.append("x")`) вызовет `TypeError`. Это плата за компактность.

## Что умеет

Поддерживает привычные операции списка (`append`, `pop`, срезы, итерацию) плюс работу с байтами — удобно для двоичных файлов:

```python
a.tobytes()             # → сырые байты массива
a.frombytes(данные)     # заполнить из байтов
with open("f.bin", "rb") as f:
    a.fromfile(f, 100)  # прочитать 100 чисел из бинарного файла
```

## array vs list vs numpy

| | `list` | `array` | `numpy` |
|---|---|---|---|
| Типы элементов | любые | один числовой | один числовой |
| Память | большая | компактная | компактная |
| Векторные операции | нет | нет | да (`a + b`, суммы) |
| Зависимость | встроен | встроен | сторонняя |

> `array` — редкий выбор: если нужна экономия памяти и стандартная библиотека. Если нужны быстрые вычисления над массивом — сразу [numpy](../../../Библиотеки/Сторонние/numpy.md).
