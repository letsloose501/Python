# hashlib

> _Превратить любые данные в короткий отпечаток фиксированной длины — так, что обратно не восстановить._

---

**hashlib** — модуль криптографических хеш-функций (SHA-256, MD5, BLAKE2 и др.). **Хеш** — необратимый отпечаток данных фиксированной длины: одинаковый вход всегда даёт одинаковый хеш, но по хешу нельзя восстановить исходные данные. Малейшее изменение входа полностью меняет отпечаток.

Зачем на бэкенде: проверка целостности файлов (контрольные суммы), дедупликация по содержимому, идентификаторы контента, а также (с оговорками) хранение паролей.

## Посчитать хеш

Хеш-функции работают с **байтами**, поэтому строку сначала кодируют (`.encode()`):

```python
import hashlib

h = hashlib.sha256(b"привет")           # или "привет".encode()
h.hexdigest()      # → 'a5b8…' шестнадцатеричная строка фиксированной длины (64 симв. для SHA-256)
```

Для больших данных — добавлять частями через `.update()`:

```python
h = hashlib.sha256()
h.update(b"часть 1")
h.update(b"часть 2")        # эквивалентно хешу от "часть 1часть 2"
h.hexdigest()
```

## Свойства хеша

- **Детерминизм** — один вход → всегда один хеш;
- **Фиксированная длина** — что байт, что гигабайт → одинаковый размер отпечатка;
- **Лавинный эффект** — смена одного бита меняет весь хеш;
- **Необратимость** — по хешу нельзя восстановить вход;
- **Стойкость к коллизиям** — трудно найти два разных входа с одним хешом (у хороших алгоритмов).

## Какой алгоритм выбрать

| Алгоритм | Статус | Применение |
|---|---|---|
| `md5`, `sha1` | **сломаны** (коллизии) | только контрольные суммы, НЕ безопасность |
| `sha256`, `sha512` | надёжны | целостность, подписи, общего назначения |
| `blake2b`, `blake2s` | надёжны, быстрее SHA | современная замена |

> **Ловушка:** `md5` и `sha1` подходят для быстрой проверки «не побились ли данные», но **не для защиты** — для них умеют подбирать коллизии. Где важна безопасность — `sha256`+.

## Пароли — отдельная история

Быстрый хеш (`sha256`) для паролей **недостаточен**: злоумышленник переберёт миллиарды вариантов в секунду. Пароли хешируют **медленными** функциями с солью — `hashlib.pbkdf2_hmac`, а лучше специализированными `bcrypt`/`argon2` (сторонние). Выбор функции, параметры OWASP и что делать вокруг хеширования — [Пароли — хранение и проверка](../../../Пароли%20—%20хранение%20и%20проверка.md).

```python
import hashlib, os

соль = os.urandom(16)
ключ = hashlib.pbkdf2_hmac("sha256", b"пароль", соль, 100_000)   # намеренно медленно
```

## Сквозной пример: контрольная сумма файла

```python
import hashlib
from pathlib import Path

def sha256_файла(путь):
    h = hashlib.sha256()
    with open(путь, "rb") as f:
        for блок in iter(lambda: f.read(8192), b""):   # читать кусками, не весь файл в память
            h.update(блок)
    return h.hexdigest()

sha256_файла("архив.zip")      # сравни с эталоном — совпал ли файл
```
