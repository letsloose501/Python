# secrets

> _Там, где случайность защищает (пароли, токены, ключи), обычный `random` предсказуем. `secrets` — криптостойкий._

---

**secrets** — модуль генерации **криптографически стойких** случайных значений: токенов, паролей, ключей. В отличие от [random](../../../Библиотеки/Модули/Работа%20с%20числами/random.md) (который предсказуем и годится для симуляций), `secrets` берёт случайность из источника операционной системы, пригодного для безопасности.

Зачем: токены сброса пароля, идентификаторы сессий, API-ключи, одноразовые коды — всё, что не должно быть угадано злоумышленником.

## Проблема random

[random](../../../Библиотеки/Модули/Работа%20с%20числами/random.md) — псевдослучаен: последовательность полностью определена зерном, и по нескольким значениям можно предсказать остальные. Для игры это неважно, для токена сессии — **дыра**: предсказал токен → зашёл под чужим аккаунтом.

```python
# НЕПРАВИЛЬНО — предсказуемый токен:
import random, string
"".join(random.choices(string.ascii_letters, k=32))
```

## Готовые токены

```python
import secrets

secrets.token_hex(16)        # → 'f9a1c3...'  32 hex-символа (16 байт)
secrets.token_urlsafe(16)    # → 'Drmhze6EPcv...'  безопасно для URL
secrets.token_bytes(16)      # → b'...'  сырые случайные байты
```

`token_urlsafe` — самый частый выбор для ссылок подтверждения и сессионных токенов.

## Выбор и сравнение

```python
secrets.choice(["A", "B", "C"])      # криптостойкий выбор элемента
secrets.randbelow(100)               # случайное целое [0, 100)

# сравнение секретов — защита от timing-атаки:
secrets.compare_digest(token, ожидаемый)   # постоянное время, не выдаёт совпавший префикс
```

> **`compare_digest` вместо `==`:** обычное сравнение строк завершается на первом несовпавшем символе, и по времени ответа можно подбирать секрет посимвольно (timing-атака). `compare_digest` сравнивает за постоянное время.

## random vs secrets

| | `random` | `secrets` |
|---|---|---|
| Предсказуемость | предсказуем (зерно) | криптостойкий |
| Скорость | быстрее | медленнее |
| Воспроизводимость | да (`seed`) | нет (и не нужна) |
| Для чего | симуляции, тесты, игры | пароли, токены, ключи |

> Простое правило: значение **защищает** что-то → `secrets`. Иначе → `random`.

## Связи

- [random](../../../Библиотеки/Модули/Работа%20с%20числами/random.md) — быстрый псевдослучайный генератор для несекретных задач;
- [hashlib](../../../Библиотеки/Модули/Безопасность%20и%20интернет/hashlib.md) — вместе используются: соль из `secrets`, хеш из `hashlib`;
- [uuid](../../../Библиотеки/Модули/Безопасность%20и%20интернет/uuid.md) — тоже уникальные значения, но `uuid4` не гарантирует криптостойкость для секретов;
- Криптография и безопасность — зачем нужна непредсказуемость и что такое timing-атака;
- [JWT — подпись и проверка токенов](../../../JWT%20—%20подпись%20и%20проверка%20токенов.md) — opaque-токены и `jti` генерируют именно этим модулем.
