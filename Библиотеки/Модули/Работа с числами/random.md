# random

> _Псевдослучайность: числа выглядят случайными, но полностью определены начальным зерном._

---

**random** — модуль генерации псевдослучайных значений: числа, выбор из последовательности, перемешивание. «Псевдо» — потому что это детерминированный алгоритм: одно и то же **зерно** (`seed`) даёт одну и ту же последовательность. Это плюс для воспроизводимости (тесты, эксперименты) и минус для безопасности.

Зачем: тестовые данные, перемешивание, симуляции, случайный выбор. Для паролей и токенов нужен другой модуль — см. ловушку в конце.

## Числа

```python
import random

random.random()          # → 0.0 ≤ x < 1.0   вещественное
random.uniform(1, 10)    # вещественное в [1, 10]
random.randint(1, 6)     # целое в [1, 6]  — ОБЕ границы включены (как кубик)
random.randrange(0, 10, 2)   # целое из 0,2,4,6,8  (как range: конец не включён)
```

> **Ловушка границ:** `randint(a, b)` включает `b`, а `randrange(a, b)` — **нет** (ведёт себя как `range`). Частый источник ошибок «на единицу».

## Выбор из последовательности

```python
цвета = ["красный", "зелёный", "синий"]

random.choice(цвета)                 # один случайный элемент
random.choices(цвета, k=5)           # k штук С ПОВТОРАМИ (можно веса: weights=[...])
random.sample(цвета, k=2)            # k штук БЕЗ повторов (уникальные)
```

| Функция | Повторы | Сколько |
|---|---|---|
| `choice` | — | один элемент |
| `choices` | да (с возвращением) | `k` штук, можно веса |
| `sample` | нет (без возвращения) | `k` уникальных |

## Перемешивание — на месте

**`shuffle`** перемешивает список **in-place** (меняет исходный, возвращает `None`).

```python
колода = [1, 2, 3, 4, 5]
random.shuffle(колода)       # колода изменена; НЕ писать колода = random.shuffle(...)
```

> Классическая ошибка: `x = random.shuffle(lst)` — `x` станет `None`. `shuffle` ничего не возвращает.

Внутри — **тасование Фишера — Йетса**: идём с конца списка и меняем текущий элемент со случайным из ещё не обработанных. За один проход $O(n)$ и все перестановки равновероятны. Одного вызова достаточно — в отличие от реальных карт, где для перемешивания колоды нужно семь риффл-тасовок.

> **Ловушка для больших колод.** Генератор `random` инициализируется состоянием ограниченного размера, поэтому `shuffle` физически не может выдать все $52! \approx 8\cdot10^{67}$ перестановок — достижима лишь их часть. Для тестов и симуляций это не важно, для карточной игры на деньги — критично; там нужен [secrets](../../../Библиотеки/Модули/Безопасность%20и%20интернет/secrets.md).

## Воспроизводимость: seed

Зафиксируй зерно — получишь ту же «случайность» при каждом запуске. Незаменимо для тестов и отладки.

```python
random.seed(42)
random.randint(1, 100)       # всегда одно и то же число после seed(42)
```

## Ловушка: random небезопасен для секретов

`random` предсказуем — по нескольким значениям можно восстановить состояние генератора. Для паролей, токенов, ключей используй модуль **[secrets](../../../Библиотеки/Модули/Безопасность%20и%20интернет/secrets.md)** (криптостойкий).

```python
# НЕПРАВИЛЬНО для токена:
import random, string
"".join(random.choices(string.ascii_letters, k=16))

# ПРАВИЛЬНО:
import secrets
secrets.token_hex(16)
```
