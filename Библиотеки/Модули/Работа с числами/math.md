# math

> _Всё, что нужно от школьной и олимпиадной математики, — уже в стандартной библиотеке и работает на скорости C._

---

**math** — модуль математических функций над числами: корни, логарифмы, тригонометрия, теория чисел, константы. Это тонкие обёртки над C-функциями, поэтому быстрые.

Зачем на контесте: `gcd`, `isqrt`, `comb`, `factorial` закрывают типовую «числовую» математику задач, а `math.inf` даёт удобную бесконечность для инициализации в [Дейкстре](../../../Алгоритмы/Поиск/Алгоритм%20Дейкстры.md) и [ДП](../../../Алгоритмы/Стратегии/Динамическое%20программирование.md).

## Теория чисел (частое на контесте)

```python
import math

math.gcd(12, 18)        # → 6    наибольший общий делитель
math.lcm(4, 6)          # → 12   наименьшее общее кратное (Python 3.9+)
math.isqrt(17)          # → 4    ЦЕЛОЧИСЛЕННЫЙ корень (пол √17), без float
math.factorial(5)       # → 120
math.comb(5, 2)         # → 10   сочетаний C(5,2)  (3.8+)
math.perm(5, 2)         # → 20   размещений         (3.8+)
```

> **Ловушка:** `math.sqrt(n)` возвращает **float** и на больших числах теряет точность — `sqrt(10**18)` может дать неверный последний разряд. Для целочисленного корня и проверки «точный ли квадрат» бери **`isqrt`**: `isqrt(n)**2 == n`.

## Округление и знаки

```python
math.floor(3.7)     # → 3    вниз
math.ceil(3.2)      # → 4    вверх
math.trunc(-3.7)    # → -3   к нулю (отбросить дробную часть)
math.fabs(-5)       # → 5.0  модуль как float
```

`floor`/`ceil` отличаются от `round`: `round` округляет к ближайшему (и «к чётному» на .5), а эти — строго вниз/вверх.

## Степени, корни, логарифмы

```python
math.sqrt(16)       # → 4.0
math.pow(2, 10)     # → 1024.0   (всегда float; для int лучше 2**10)
math.log(8, 2)      # → 3.0      логарифм по основанию 2
math.log2(8)        # → 3.0      точнее и быстрее
math.log10(1000)    # → 3.0
math.exp(1)         # → 2.718…   e^1
```

## Тригонометрия

Нужна в геометрических задачах: углы, повороты, расстояния на плоскости.

```python
math.sin(math.pi / 2)      # → 1.0    синус
math.cos(0)                # → 1.0    косинус
math.tan(math.pi / 4)      # → 0.999… тангенс (float, точного 1.0 не жди)

math.asin(1)               # → 1.5707…  обратные: возвращают УГОЛ
math.acos(0)               # → 1.5707…
math.atan(1)               # → 0.7853…  = π/4
math.atan2(y, x)           # угол точки (x, y) от оси X, с учётом четверти
```

> **Главная ловушка: всё в радианах, а не в градусах.** `math.sin(30)` — это синус 30 **радиан** (≈ −0.988), а не 30 градусов. Переводи явно:

```python
math.radians(180)          # → 3.14159…  градусы → радианы
math.degrees(math.pi)      # → 180.0     радианы → градусы

math.sin(math.radians(30)) # → 0.5       вот так считают синус 30 градусов
```

**`atan2(y, x)` вместо `atan(y / x)`** — потому что знает четверть по знакам обоих аргументов и не делит на ноль:

```python
math.degrees(math.atan2(1, 1))     # → 45.0     первая четверть
math.degrees(math.atan2(1, -1))    # → 135.0    вторая — atan бы дал −45
math.degrees(math.atan2(1, 0))     # → 90.0     x = 0, деления на ноль нет
```

Есть и гиперболические (`sinh`, `cosh`, `tanh` и обратные `asinh`, `acosh`, `atanh`) и `math.gamma(x)` — обобщение факториала на дробные числа (`gamma(n) = (n−1)!`). В прикладных задачах встречаются редко.

## Константы

```python
math.pi        # 3.141592…
math.e         # 2.718281…
math.tau       # 2π
math.inf       # положительная бесконечность
math.nan       # «не число» (Not a Number)
```

`math.inf` удобен как стартовое значение «ещё не найденного минимума»:

```python
лучшее = math.inf
for x in данные:
    лучшее = min(лучшее, стоимость(x))
```

## Работа с float: сравнение и суммы

Числа с плавающей точкой неточны: `0.1 + 0.2 != 0.3`. Сравнивай через **`isclose`**, а не `==`.

```python
0.1 + 0.2 == 0.3               # → False  (!)
math.isclose(0.1 + 0.2, 0.3)   # → True

math.fsum([0.1] * 10)          # → 1.0    точная сумма float (обычный sum даёт 0.999…)
math.hypot(3, 4)               # → 5.0    √(3²+4²) — длина вектора
math.dist((0, 0), (3, 4))      # → 5.0    евклидово расстояние между точками
```

## Каталог

| Функция | Что делает |
|---|---|
| `gcd` / `lcm` | НОД / НОК |
| `isqrt` | целочисленный квадратный корень |
| `factorial` / `comb` / `perm` | факториал / сочетания / размещения |
| `floor` / `ceil` / `trunc` | округление вниз / вверх / к нулю |
| `sqrt` / `pow` / `log*` / `exp` | корень / степень / логарифмы / экспонента |
| `sin` / `cos` / `tan` + `a*` | тригонометрия и обратные функции (в радианах) |
| `radians` / `degrees` | перевод градусов ↔ радианов |
| `atan2` | угол точки с учётом четверти |
| `pi` / `e` / `tau` / `inf` / `nan` | константы |
| `isclose` | безопасное сравнение float |
| `hypot` / `dist` | длина вектора / расстояние |
| `prod` / `fsum` | произведение / точная сумма |
