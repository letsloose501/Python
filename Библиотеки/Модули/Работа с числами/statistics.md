# statistics

> _Среднее, медиана, разброс — без установки numpy, прямо из стандартной библиотеки._

---

**statistics** — модуль базовой описательной статистики: среднее, медиана, мода, стандартное отклонение. Для небольших наборов чисел он избавляет и от ручных формул, и от тяжёлого [numpy](../../../Библиотеки/Сторонние/numpy.md) — всё уже готово в стандартной библиотеке.

Зачем: быстро посчитать характеристики выборки — в анализе данных, отчётах, проверках.

## Меры центра

```python
import statistics as st

данные = [4, 8, 15, 16, 23, 42]

st.mean(данные)        # → 18.0    среднее арифметическое
st.median(данные)      # → 15.5    медиана (середина упорядоченного ряда)
st.mode([1, 1, 2, 3])  # → 1       мода (самое частое значение)
```

> **Среднее vs медиана:** среднее чувствительно к выбросам, медиана — нет. Для зарплат `[30, 32, 35, 40, 500]` среднее ≈ 127 (искажено одним значением), медиана = 35 (отражает типичное). Где есть выбросы — медиана честнее.

## Меры разброса

```python
st.stdev(данные)       # стандартное отклонение выборки (sample)
st.variance(данные)    # дисперсия выборки
st.pstdev(данные)      # стандартное отклонение всей совокупности (population)
st.pvariance(данные)   # дисперсия совокупности
```

> **Выборка vs совокупность:** `stdev`/`variance` — когда данные это **выборка** из большего целого (делят на `n−1`). `pstdev`/`pvariance` — когда это **вся** совокупность (делят на `n`). По умолчанию для оценки берут `stdev`.

## Прочее

```python
st.fmean(данные)               # среднее как float, быстрее mean (3.8+)
st.quantiles(данные, n=4)      # квартили — границы, делящие данные на 4 части
```

## statistics vs numpy

- **statistics** — стандартная библиотека, точные результаты, удобно для небольших наборов;
- **[numpy](../../../Библиотеки/Сторонние/numpy.md)** — на порядки быстрее на больших массивах (миллионы чисел), нужен для серьёзного анализа и ML.

Правило: пара сотен чисел и не хочется зависимостей → `statistics`; большие данные → `numpy`.

## Связи

- [math](../../../Библиотеки/Модули/Работа%20с%20числами/math.md) — элементарные функции; `statistics` строится поверх подобных операций;
- [numpy](../../../Библиотеки/Сторонние/numpy.md) — быстрая альтернатива для больших массивов;
- Анализ данных — где описательные статистики применяются;
- Машинное обучение — среднее/дисперсия как базовые признаки и нормализация.
