# decimal

> _`0.1 + 0.2 != 0.3`. Для денег и точных расчётов обычного `float` недостаточно — нужен `Decimal`._

---

**decimal** — модуль точной десятичной арифметики. Обычный `float` хранит числа в двоичной системе и не может точно представить многие десятичные дроби (как `1/3` в десятичной), отсюда `0.1 + 0.2 = 0.30000000000000004`. **`Decimal`** считает в десятичной системе — так, как человек на бумаге, без накопления ошибки.

Зачем: деньги, финансы, счета, любые расчёты, где расхождение в копейку недопустимо. Классическое правило бэкенда: **деньги — не `float`**.

## Проблема float

```python
0.1 + 0.2               # → 0.30000000000000004   (!)
0.1 + 0.2 == 0.3        # → False
```

Причина — в [двоичном представлении float](../../../Данные/Примитивные%20типы%20данных%20Python.md): `0.1` в двоичной системе бесконечна, хранится приближённо. Для науки погрешность не важна, для денег — критична.

## Decimal: точно

```python
from decimal import Decimal

Decimal("0.1") + Decimal("0.2")             # → Decimal('0.3')   точно
Decimal("0.1") + Decimal("0.2") == Decimal("0.3")   # → True
```

> **Ключевая ловушка:** создавай `Decimal` из **строки**, а не из float. `Decimal(0.1)` возьмёт уже испорченный float и сохранит его погрешность: `Decimal('0.1000000000000000055...')`. Правильно — `Decimal("0.1")`.

## Точность и округление

Контекст задаёт число значащих цифр и правило округления:

```python
from decimal import Decimal, getcontext, ROUND_HALF_UP

getcontext().prec = 10          # значащих цифр в операциях

цена = Decimal("19.99")
итог = цена * 3                 # → Decimal('59.97')

# округлить до копеек:
итог.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)   # → Decimal('59.97')
```

`quantize` приводит число к нужному числу знаков после запятой — то, что нужно для денежных сумм.

## Decimal vs float

| | `float` | `Decimal` |
|---|---|---|
| Система | двоичная | десятичная |
| Точность | приближённая | точная (в пределах `prec`) |
| Скорость | быстрее | медленнее |
| Когда | наука, графика, ML | деньги, финансы, счета |

> Для приблизительных вычислений с float правильное сравнение — `math.isclose` ([math](../../../Библиотеки/Модули/Работа%20с%20числами/math.md)). Для точных — `Decimal`. Смешивать `Decimal` и `float` в одной операции нельзя (`TypeError`).
