Конспекты по Python и бэкенду: 219 заметок, от синтаксиса до деплоя. Каждая заметка — самостоятельный разбор темы «от простого к сложному», с примерами кода, разбором типичных ошибок и **списком источников в конце**: официальная документация, PEP, спецификации и книги.
